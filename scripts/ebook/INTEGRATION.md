# 주문 → 카페 → 명부 → 메일 연결

`worker.py`는 기존 5분 주기 수집 후 `cafe_auto_upgrade=true`일 때 연결기를 실행한다.
`live_send=true`는 카페 등업과 명부 반영이 검증된 주문의 메일 발송만 허용한다.
활성화 시각 이후 신규 결제, 취소·클레임 없음, 배송메모의 이메일 한 개가 필요하다.

- 네이버 이메일의 전체 아이디로 Studio의 **아이디 검색**을 수행한다.
- 검색 완료·검색어·결과 1명·관측된 ID 앞자리·회원 고유 태그를 함께 검증한다.
- 비네이버 주소, 미가입, 여러 검색 결과, 추가 인증, UI 변경은 검토 대기로 남긴다.
- 감사멤버면 변경하지 않는다. 그 아래 다섯 등급만 감사멤버로 변경하고 재조회한다.
- 명부 동기화 성공 후에만 주문에 완료 영수증을 기록한다. 기존 수동 명부 충돌은
  자동 덮어쓰기 없이 검토한다. 기존 계정 연결·권한을 직접 변경하지 않는다.
- `MANUAL_SENT`, `SMTP_ACCEPTED`, `UNKNOWN`은 자동 재발송 대상이 아니다.
- 매 주기 한 주문을 처리한다. 검토 실패는 30분 후 다시 확인한다.

서버 설치 파일: `/opt/f2r-ebook/cafe_fulfillment.py`,
`/opt/f2r-cafe-runtime/order_member.py`.
전용 브라우저 폴더의 `runtime.json`에는 `{"profile":"manager"}`처럼 전용 프로필
디렉터리명만 둔다. `manager-session.json`과 실제 회원 영수증은 비공개 0600으로
보관하며 저장소에 올리지 않는다. 인증 도구에는 설치된 브라우저 경로를
`PLAYWRIGHT_BROWSERS_PATH`로 지정한다.

서비스는 다른 홈 디렉터리를 가린 상태로 전용 브라우저 폴더만 명시적으로
마운트해야 한다. 기존 PDF 해시 확인·주문 재확인·SMTP 불확실 결과 보류를 유지한다.
인증 복구는 운영자가 QR 로그인과 운영진 본인 인증을 완료해야 한다.

검증: `python3 -m unittest discover -s scripts/ebook -p 'test_*.py'`
및 `scripts/cafe-runtime` 테스트. UI 등급 선택의 건식 검증은 실제 회원의 등급을
바꾸지 않고 취소한다. 전체 신규 주문 실발송 검증과 코드 단위 검증은 구분한다.
