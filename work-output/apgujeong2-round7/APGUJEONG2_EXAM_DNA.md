## 3. EXAM DNA 요약
1. **전 문항 객관식 5지선다, 서답형 0** (2학기에도 서답 없음 — 1·2회 제작 검증서 재확인).
2. **공통지문 다문항 구조**: 1지문 2~5문항. 지문은 박스 처리, 발문은 박스 밖.
3. **어법의 두 얼굴**: (a) 지문 내 ⓐ~ⓔ 심기형(옳은 것/옳지 않은 것 양방향, 6회) (b) 독립 5문장형(옳은 것/틀린 것, 2회) (c) <보기> 개수세기(1회) (d) (A)→(B) 전환 판정(1회).
4. **어휘**: 영영풀이 양방향(정의→단어 / 단어에 없는 정의), <보기> 정의→단어, 문맥상 어색한 낱말. 학습지 word list의 영어 뜻풀이가 그대로 출제 소스.
5. **영작**: 한글 (A)를 5지 영작(미세 문법차: 수일치·품사·병렬·도치), 어순 중 n번째 단어.
6. **내용**: 일치/옳은 것 + 유추할 수 없는 것 + 가장 적절한 것. 선택지는 전부 영어 완전문장(2~3행), 주어를 동일 인명으로 반복하는 스타일.
7. **한글 선택지 0** — 발문만 한글. 예외 없이 선택지는 영어(개수세기·기호·국명 제외).
8. **배점 분산**: 유형 무관하게 3/4점 혼재. 장문 독해가 오히려 3점, 단문 어법이 4점(Q27)이기도 함.
9. **숫자 읽기·국적 표기·문화 짝짓기** 같은 암기형 지식 문항 3개가 고정 포지션(후반부).
10. **대동사·지칭·순서배열(문단)·제목·글의 목적형은 1학기 기출에 없음** — 임의 추가 금지. 단 순서배열은 삽입문장(Q8)이 근접 기능.
11. 지문 소재: 발명·과학사 + 문화(온돌/탱고/훌라/축제) — 설명문 위주, 1인칭 인터뷰 대화 1개.
12. 오답 설계 원리: (i) 사실 반전/세부 혼동 (ii) 태·전치사·수일치·품사 등 문법 미세 오류 (iii) 의미 역전(too/so/enough) (iv) 지문 단어를 쓰되 답과 무관하게 조합.
13. 난이도 곡선: 초반 평이(사실일치) → 중반 어법·영작 4점 밀도 → 후반 장문(21~25)+전환·개수. 말미(Q26~30)는 짧고 선명한 마무리.
14. 거의 출제 안 되는 유형: 장문 순서배열, 제목, 쓰기 통합, 한국어 선지, 그림/도표 해석(표는 짝짓기 1개뿐).

## 4. 7회 적용 원칙 (출제 공식)
- 40문항 = 기출 30문항의 유형 분포를 4/3 스케일로 확장(내용 4→5, 지문내어법 6→8, 영영 3→4, 어법독립 2→3, 전환 1→2, 영작 2→3, 개수 1→1, 대화 1→2, 주제 2→2, 빈칸연결어 1→2, 삽입 1→2, 지식암기 3→3 등) + 2학기 범위 문법(간접의문문·지각동사·want/tell/ask·5형식)을 기출 스타일(ⓐ~ⓔ 심기, 독립 5문장, (A)→(B))로만 구현.
