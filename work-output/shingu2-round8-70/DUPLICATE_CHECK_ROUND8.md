## 2. 8회 신규 축 (1~7회에 없는 발문)
- T1 영영 **정의문 빈칸** 완성
- T3 **주어진 문장이 들어갈 위치** ⓐ~ⓓ (7회 Q20이 1회 사용 → 8회는 지문·추론 근거를 완전히 교체하고 2문항만)
- T4 **요약문 / 집필 의도** 선택
- T5 **4형식→3형식 전환 + 전치사**(to/for) 개수세기 — 인사이트 함정 A
- T6 **continue류 to-V / 동명사** 구분 개수세기 — 함정 B
- T7 **지각동사 O+do/doing/p.p.** 능동·수동 판단 — 함정 C
- T8 **too…to / enough to ↔ so…that 전환 정오**(시제·의미상 주어·문말 it/them) — 함정 D
- T20 **조건영작 → "조건을 모두 만족하는 문장 개수"** 객관식 변환 — DNA S21
- 어법 범위를 학교 프린트 5개 항목(목적격 관계대명사·used to·so~that·too…to/enough to·지각동사)으로 한정. **수동태·현재완료·분사구문 출제 금지**(6회가 범위 밖 어법을 사용해온 점과 차별화).
