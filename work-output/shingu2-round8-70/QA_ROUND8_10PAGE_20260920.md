## 이번 세션에서 고친 결함
1. `render_answers.mjs`의 가용 높이 계산이 **컬럼** 기준(`j===0`)이라 1페이지 우측 컬럼이
   잘리고 있었다 → **페이지** 기준(`Math.floor(j/2)===0`)으로 수정. (헤더는 전폭이므로 두 컬럼 모두 감소)
2. Chromium이 한글 음절 사이에서 줄을 끊어 `선행/사`, `가/능`, `형/태` 같은 절단이 발생 →
   `.qprompt,.cond-box,.choice-item,.choice-table th/td,.given-sentence,.group-label,.exam-header td/th`에
   `word-break:keep-all` 적용 + 표에 `table.widths`(colgroup) 도입.
3. 해설 라벨 `오답 포인/트` 절단 → `.ans dt` 15mm→18mm, `.ans dd` margin-left 19mm.
4. 해설에서 `발문` 행 제거(필수 4항목만: 핵심 근거/오답 포인트/규칙/지문 근거) → 12페이지→10페이지.

## 측정·검증 방법 (내장 브라우저 고장 대체)
- 내장 브라우저는 재시작 후에도 blank/내비게이션 타임아웃 → 측정을 헤드리스 Chrome으로 이전:
  `maker/measure.mjs` (draft HTML에 프로브 스크립트 주입 → `chrome --headless --dump-dom` → title 파싱).
  기존 내장 브라우저 측정치와 70개 단위 전부 0.0px 차이(총 15,332.6px, headerH 121.25)로 일치함을 확인.
- 인쇄는 `chrome --headless --print-to-pdf`로 실제 A4로 변환(두 문서 모두 10페이지, MediaBox 595×842pt).
- `maker/qa_pdf.py`로 전 20페이지 검사 → **RESULT: PASS**
  - 여백 침범(좌11/우199/상12/하287mm) 0, 컬럼 하한(283mm) 초과 0 → 하단 침범 0·잘림 0
  - 거터(101.5~108.5mm) 침범 0, ①~⑤ 마커 단독 줄 0, 한글 단어 절단 0
  - 문항번호 1~70 연속·무결(누락/중복 0) 두 문서 모두 PASS
- 시각 검수: 10페이지 컨택트 시트 2종 + 원해상도 페이지(paper p1/p3/p5, answers p1) 육안 확인.
  스크린 API는 뷰포트 0x0으로 여전히 사용 불가 → PDF 래스터로 대체.
