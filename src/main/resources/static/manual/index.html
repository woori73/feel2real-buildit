PART 1

홈페이지 만들기

회원가입부터 학원빌더 편집, 적용, 발행, 실제 홈페이지 확인까지 진행합니다.

영상 ①
1

회원가입 및 로그인

feel2real.co.kr에 접속하여 회원가입 후 로그인합니다.

  • 회원가입
  • 이메일 입력은 선택
  • 인증번호 없음
  • 로그인
회원가입 안내: 현재 이메일 인증번호를 입력하는 절차는 없습니다.
영상 ②
2

학원빌더

화면의 세 영역을 확인하고 필요한 기능과 내용을 편집합니다.

  • 왼쪽: 기능 선택
  • 가운데: 홈페이지 미리보기
  • 오른쪽: AI 도움
작성 팁: Chrome의 「크롬 물어보기」 기능을 활용하면 학원 소개글이나 대표 문구를 쉽게 작성할 수 있습니다.
영상 ③
3

적용 및 발행

편집을 마친 뒤 적용으로 저장하고, 발행으로 실제 홈페이지를 생성합니다.

적용→저장→발행→홈페이지 생성
적용은 저장입니다.
발행을 누르면 학원명.feel2real.co.kr 형식의 홈페이지가 생성됩니다.
영상 ④
4

홈페이지 확인

생성된 홈페이지에 접속하여 중요한 항목만 빠르게 점검합니다.

  • 소개글
  • 메뉴
  • 이미지
  • 기능
강사대시보드 · 영상관리: 60초 이하 수업영상을 업로드하면 홈페이지의 수업영상 메뉴에 자동으로 표시됩니다.
NEXT STEP

이제 수업상품을 등록합니다.

PART 2

수업상품 만들기

수업을 추가하고 기본 내용을 입력한 뒤 미리보기에서 확인하여 상품 페이지를 생성합니다.

영상 ⑤
1

수업상품 추가

강사대시보드의 수업상품 메뉴에서 새 수업을 추가합니다.

수업 추가→여러 개 생성 가능
과목이나 대상이 다른 수업은 각각 별도의 수업상품으로 만들 수 있습니다.
영상 ⑥
2

수업 작성

학부모와 학생이 수업을 이해할 수 있도록 핵심 정보만 입력합니다.

  • 수업명
  • 대상
  • 소개
  • 특징
빠른 작성: 기존 학원 자료를 활용하고, Chrome의 「크롬 물어보기」로 소개글 작성을 도움받을 수 있습니다.
개발 예정: 교재 사진 또는 수업 소개·OT 영상 업로드 기능이 추가될 예정입니다.
영상 ⑦
3

미리보기 후 생성

입력한 내용을 미리보기에서 확인하고 수업상품을 생성합니다.

미리보기→내용 확인→생성
수정 가능: 생성 후에도 수업명, 소개, 특징 등을 언제든 다시 수정할 수 있습니다.
