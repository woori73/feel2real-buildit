# BUILD IT WEEKLY 문제지 제작 기준

AI는 WEEKLY 생성 시 이 문서를 최우선 제작 규칙으로 사용한다.

## 기본
- 고3 WEEKLY: 14문항, A4 세로, 2단.
- Fixed Typography + Fixed Margin + Flexible Pagination.
- 폰트·행간·페이지 여백·단 간격은 고정한다.
- 페이지당 문항 수는 고정하지 않고 보통 3~4문항을 문항 전체 높이에 따라 배치한다.
- 문항번호+발문+지문/제시문+각주+선택지를 하나의 분리 불가능한 단위로 취급한다.
- 공간을 맞추려고 폰트/여백을 축소하거나 고정 Grid에 문항을 강제로 넣지 않는다.

## 문항 순서
1. 수능 21번형 함축 의미
2. 제목
3. 수능 29번형 어법
4. 수능 30번형 문맥상 어휘
5~8. 빈칸 추론
9~10. 글의 순서
11~12. 문장 삽입
13~14. 공통지문 2문항

## 표시
- 1번: 실제 영어 표현에 얇고 연한 단일 밑줄.
- 3번 어법: 번호가 아니라 실제 판단 대상 영어 단어/표현에 단일 밑줄.
- 4번 어휘: 번호가 아니라 실제 판단 대상 영어 단어에 단일 밑줄.
- 밑줄은 약 0.65~0.7px의 연한 단일선. 이중 밑줄 금지.
- 빈칸: 원문을 읽어 실제 생략 위치에 둔다. HTML 블록 경계만 보고 추측하지 않는다.
- 순서/삽입 제시문: 일반 지문과 같은 폰트·크기·굵기. 볼드 금지.
- 삽입 위치: `( ① )` 형식.
- 공통지문: 한 번만 출력하고 바로 뒤에 13번, 14번을 배치한다.
- `(a)~(e)` 판단형: 표지가 아니라 실제 대상 단어에 밑줄.
- 짧은 ①~⑤ 선택지는 공간이 충분하면 서로 충분히 벌린다.
- OCR 잔여 문자·정답 표시·내부 메타데이터를 문제지에 노출하지 않는다.

## Pagination
왼쪽 단에 다음 문항 전체가 들어가지 않으면 오른쪽 단 상단으로 이동하고, 오른쪽 단에도 들어가지 않으면 다음 페이지 왼쪽 단으로 넘긴다. 지문과 선택지를 부자연스럽게 분리하지 않는다.

## Context 우선순위
1. 이 `WEEKLY_GENERATION_STANDARD.md`

3. 이번 HALF/원문 자료

규칙과 실제 원문을 임의로 섞거나 원문 내용을 추측하지 않는다.
