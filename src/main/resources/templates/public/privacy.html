Feel2Real 서비스별 개인정보 안내

개인정보처리방침

시행일: 2026년 9월 25일 · 대상: NewStart Chrome Agent (FSS 안내) 확장 프로그램 v0.4.0

1. 확장 프로그램의 목적

NewStart Chrome Agent는 금융감독원(www.fss.or.kr) 민원 신청 화면에서 URL·페이지 제목·버튼 텍스트·라벨 등 구조적 정보만 읽어 사용자가 지금 어느 단계에 있는지 판단하고 다음 절차를 화면 카드로 안내하는 읽기·안내 전용 확장입니다. 화면 조작, 자동 입력, 자동 제출 기능은 없습니다.

2. 사용하는 Chrome 권한과 접근 사이트

항목내용용도
권한 storage확장 로컬 저장소 1종만 사용 마지막으로 판별한 단계 번호·근거 카테고리 라벨·확장 버전만 기기 내부에 저장. 서버로 전송하지 않음

cookies, history, downloads, clipboard, webRequest, debugger, <all_urls> 등 그 외 권한은 요청하지 않습니다.

3. 처리하지 않는 정보

  • 화면의 입력창(text·textarea·password)에 입력한 값은 읽지도 저장하지도 전송하지도 않습니다.
  • 공동인증서, OTP, CAPTCHA, 주민등록번호 등 본인인증 정보를 수집·저장하지 않으며, 인증 화면에는 안내만 표시하고 조작하지 않습니다. 인증은 사용자가 직접 수행합니다.
  • 쿠키·로그인 세션·히스토리·북마크를 읽지 않습니다.
  • 민원을 자동 제출하지 않습니다. 최종 제출은 사용자가 직접 수행합니다.

4. 데이터 전송

이 확장은 어떤 개인정보나 화면 내용도 외부 서버로 전송하지 않습니다. 내부적으로 페이지 스크립트와 확장 백그라운드 사이에서 오가는 메시지는 단계 번호·서브상태·카테고리 라벨·버전과 같은 구조 판별 결과뿐이며, 네트워크 요청을 통한 데이터 반출은 존재하지 않습니다.

6. NewStart 웹 서비스와의 관계

확장 없이도 NewStart 금감원 민원 도우미 웹 화면(인터뷰·초안 생성·수동 안내)은 그대로 사용할 수 있습니다. 웹 화면의 인터뷰 내용은 민원 초안 생성을 위해 AI 처리 시스템으로 전송되며 NewStart 데이터베이스에 저장되지 않습니다. 이 방침은 Chrome 확장 프로그램에 한정된 안내이며, 웹 서비스 계정의 개인정보는 feel2real.co.kr의 별도 정책에 따릅니다.
