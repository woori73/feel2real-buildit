미리보기를 준비하고 있습니다저장된 Academy 데이터를 불러오면 실제 공개 페이지가 표시됩니다.
저장되었습니다

수업대상 수정

공개 페이지의 대상 배지와 검색 필터에 반영됩니다.

과목 수정

공개 페이지의 주력 과목과 검색 필터에 반영됩니다.

지역 수정

최대 3개 지역을 선택할 수 있습니다. 구/군을 비우면 전 지역으로 저장됩니다.

대표 수업 선택

등록된 수업 중 히어로에 보여줄 수업을 최대 4개까지 선택해 주세요.

로고 이미지 수정

JPG, PNG, WebP, GIF 이미지를 업로드할 수 있습니다. 최대 2MB까지 허용합니다.

발행 전에는 미리보기에만 반영되고, 발행 버튼을 누르면 이미지가 학원 데이터와 함께 저장됩니다.

히어로 영상 수정

영상 보관함에서 업로드 영상을 고르거나 YouTube 링크를 사용할 수 있습니다.

새 영상은 영상 관리에서 업로드할 수 있습니다.

원장 소개 영상 수정

영상 보관함에서 업로드 영상을 고르거나 YouTube 링크를 사용할 수 있습니다.

새 영상은 영상 관리에서 업로드할 수 있습니다.

공개 주소 수정

학원 공개 페이지의 서브도메인 주소(handle)를 설정합니다.

3~30자 소문자/숫자/하이픈만 사용할 수 있고, 시작과 끝은 소문자 또는 숫자여야 합니다.

미리보기: handle.feel2real.co.kr

외부 URL 수정

네이버 블로그와 네이버 지도 URL을 학원 공개 페이지에 연결합니다.

http:// 또는 https://로 시작하는 URL 하나만 등록할 수 있습니다.

상담 연락처 수정

방문자가 `상담 신청`을 누르면 여기 입력한 전화·이메일로 바로 연결됩니다.

footer 사업자 정보의 전화·이메일과 같은 값입니다. 비워 두면 해당 연락 수단은 표시되지 않습니다.
