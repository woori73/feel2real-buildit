자동수집 연결

수집한 실거래는 바로 F2R 장부에 저장됩니다. 계정이 불확실한 거래는 미분류·검토로 저장되고, 검토함에서 정리합니다.

실제 기관 연동은 기관 계약·키 등록·검증이 끝난 기관만 "연결됨"으로 표시됩니다. 그 전에는 "연동 준비 중"으로 보이며 자동수집이 실행되지 않습니다.

은행 계좌 연결 등록

계좌 비밀번호·공동인증서·OTP는 입력받지 않습니다. 은행 인증은 CODEF 계정 등록으로 받은 연결 ID(connectedId)로만 참조합니다.

연결 목록

수집 이력

수집 N / 장부 저장 N / 기존 중복 N / 미분류·검토 N / 분류 완료 N / 실패 N. "응답 수신"과 "장부 저장 완료일"은 다른 단계입니다.
