    안전 규칙

      대신 파일로 넣기 ›

      은행 계좌 자동 연동 등록 (계약 후 사용)

      계좌 비밀번호·공동인증서·OTP는 입력받지 않습니다. 자동 연동은 기관 계약이 끝난 뒤에만 동작합니다.

      연결된 기관

      기관수집 방식상태마지막 수집장부에 들어간 건수

      수집 이력

      파일로 넣기 (엑셀·CSV)

      1. 기관 고르기
      2. 파일 올리기

        첫 줄에 「거래일」「금액」 칸이 있는 CSV 파일. 엑셀 파일은 「다른 이름으로 저장 → CSV」로 바꿔 올려 주세요.

      3. 미리보기

        파일을 고르면 앞부분을 보여 드립니다.

      4. 장부에 저장

      고급 설정 (개발용)

      CODEF 등 유료 자동 연동은 계약·키 등록·검증이 끝난 기관만 "연결됨"이 됩니다. 그 전에는 실행되지 않습니다. 은행 인증은 CODEF 계정 등록으로 받은 연결 ID(connectedId)로만 참조합니다.

      사용안내

      • 자동 연결이 안 되는 기관은 '파일로 넣기'로 넣으면 같은 장부에 저장됩니다.
      • 같은 카드를 홈택스와 카드사에서 둘 다 연결하면 거래가 두 번 들어갈 수 있습니다.
      • 확실하지 않은 거래도 먼저 장부에 저장되고, 검토함에서 정리합니다.
      • 비밀번호·공동인증서·OTP는 이 화면에 입력하지 않습니다.
