회차 빠른 이동
컷 번호로 이동

콘티 보드

등록한 이미지와 설명만 표시합니다. 컷을 선택한 뒤 이전·다음 버튼 또는 좌우 방향키로 이동하세요.

자료와 수정 이력

버전은 200개씩 더 불러올 수 있습니다. 컷 현황은 최신 버전 전체를 별도로 조회합니다. 정본·AI 제안·사용자 승인본을 구분합니다.

작품의 기록을 선택하세요

실제 자료가 없는 회차와 컷은 업로드 대기입니다.

프로젝트 공동 작업 기억

사람과 AI가 같은 결정·자료·다음 작업을 확인합니다. 새 세션에서도 서버에 기록한 최신 상태를 불러옵니다. 이 기록은 자동 실행 지시가 아닙니다.

작업 기억 갱신

저장하면 기존 결정을 보존한 새 버전을 만듭니다. 다른 사람이 먼저 갱신했으면 최신 상태를 다시 불러오세요.

사용자 승인 대기함

보관용 출처 목록은 제외하고 최신 수정 후보를 보여줍니다. 실제 승인은 상세 화면에서 사람이 결정합니다. 반려본과 이전 이력은 자료 탭에 보존합니다.

캐릭터 갤러리

원본 보관함

PDF · HTML · JSON · MD · ZIP · PNG · MP4 / 파일당 최대 100 MiB. 원본은 덮어쓰지 않으며 프로젝트 내 SHA-256으로 중복을 확인합니다.

보관한 JSON 또는 manifest.json 포함 ZIP의 1~68컷을 새 버전으로 등록합니다. 원본·이전 버전·기존 승인 이력은 보존하며, 새 버전은 개별 검수 전 미승인입니다.

버전 비교

r14·r2·r3·r4 등 등록된 버전을 선택하세요. 비교는 승인 상태를 변경하지 않습니다.

작품 자료와 대화

등록한 제목·본문·대사·연출에서 근거를 찾아 보여줍니다. 외부 AI 호출 없이 작동하며, 생성형 답변은 연결한 ChatGPT·Claude에서 이용하세요.

작업·검수·승인 이력

제작 담당자 권한

관리자만 기존 회원의 사용자 ID에 권한을 부여하거나 폐기할 수 있습니다.

이미지 확대

화면용 파생 이미지 · 원본 다운로드는 상세 화면에서 가능합니다.

승인본 · 수정 후보

자료 버전 등록

저장하면 새 이력이 만들어집니다. AI 제안은 자동 승인되지 않습니다.

사용자 검수 결정
원본은 보존하고, 제안은 구분하고, 승인은 사람이 결정합니다.
