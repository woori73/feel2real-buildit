AI 자료 조회 연결

에서 사용할 자료 범위를 선택하세요.

연결된 AI는 현재 계정이 조회할 수 있는 자료만 읽습니다. 학생·회원·금융·상담 자료는 필요한 목적의 범위만 선택하세요. 연결을 통해 자료 수정·삭제·승인·배포를 할 수 없습니다. 단, 아래 '제작소 검수 의견·수정 작업·새 버전 등록'을 따로 선택한 경우에만 AI AGENT 제작소에 검수 보고서·수정 작업·새 버전 파일을 추가할 수 있습니다. 기존 파일과 승인본은 바뀌지 않고, 승인·공개는 사람이 결정합니다.

offline_access는 최대 30일 동안 재인증 없이 연결을 갱신합니다. access token은 15분 후 만료됩니다.

관리자 자료의 외부 제공 주의

학생·회원·금융·상담 범위를 선택하면 관리자 권한으로 볼 수 있는 민감정보가 연결한 외부 AI에 전달될 수 있습니다. 업무에 필요한 최소 범위만 선택하세요. 금융은 사업체별 월 합계만 제공하며 원문·거래처·증빙은 제외합니다.

제작소 등록 권한 주의

제작소 등록 권한은 기본 해제되어 있습니다. 선택하면 연결한 AI가 이 계정 이름으로 제작소에 검수 의견·수정 작업·새 버전 파일을 추가합니다(삭제·덮어쓰기·승인·공개 불가). 모든 등록은 연결 이름과 함께 기록되며 연결 관리에서 언제든 끊을 수 있습니다.

원본 파일의 외부 제공 주의

원본 제공 권한은 기본 해제되어 있습니다. 선택하면 PDF·이미지·ZIP·영상 등의 민감정보가 마스킹 없이 외부 AI에 전달될 수 있습니다. 원본을 먼저 확인하고 필요한 경우에만 허용하세요. 서비스별 기존 접근 권한도 계속 적용됩니다.
