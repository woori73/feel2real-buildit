금감원 민원 도우미는 PC의 Google Chrome에서 사용하는 기능입니다.
NewStart Chrome Agent 확장프로그램을 설치하면 금융감독원 민원 신청 과정에서 현재 단계에 맞는 작성 안내를 받을 수 있습니다.

사용 방법 — 4단계

  1. PC에서 Google Chrome을 실행합니다.
  2. NewStart Chrome Agent를 설치합니다. (Chrome Web Store · PC Chrome)
  3. NewStart의 「금감원 민원 도우미」를 실행합니다. — 지금 이 화면입니다.
  4. 금융감독원 사이트에서 화면 안내에 따라 민원을 작성합니다.

왜 Chrome 확장프로그램이 필요한가요?

일반 NewStart 웹사이트는 금융감독원 사이트의 현재 화면을 직접 확인할 수 없습니다. Chrome 확장프로그램을 사용하면 사용자가 보고 있는 금감원 페이지의 진행 단계를 인식하여, NewStart가 그 단계에 필요한 안내를 제공할 수 있습니다. 확장프로그램은 안내용 화면 인식에만 쓰이며, 대신 입력하거나 제출하지 않습니다.

자동으로 하지 않는 것

  • 공동인증서/금융인증서 인증을 대신하지 않습니다.
  • 비밀번호를 입력하거나 저장하지 않습니다.
  • OTP/CAPTCHA를 대신 처리하지 않습니다.
  • 민원을 자동 제출하지 않습니다.
  • 최종 제출은 사용자가 직접 확인하고 진행합니다.

개인정보 안내

민원 작성 중 비밀번호 등 민감한 입력값은 확장프로그램이 읽거나 저장하지 않습니다. 확장프로그램이 보는 정보와 저장 여부는 개인정보처리방침에서 확인할 수 있습니다.

Extension을 설치하지 않아도 이 화면의 인터뷰·초안·수동 안내는 그대로 사용할 수 있습니다.

연결이 안 될 때 — 진단

연결된 Agent 버전: 연결 안 됨
