한국신용정보원 공식서비스 연결

내 채무·연체정보 확인

새출발기금 대상 여부를 대신 판단하지 않습니다. Credit4U에서 본인 신용정보를 직접 조회하고, 확인한 내용을 아래 순서대로 내 채무상황에 정리하세요.

Credit4U 실전 확인 순서

  1. ① Credit4U 접속 아래 버튼으로 한국신용정보원 공식서비스에 이동합니다.
  2. ② 본인인증 공식사이트에서 본인이 직접 인증합니다. NewStart는 인증 정보를 받지 않습니다.
  3. ③ 일반신용정보 선택 Credit4U 메인 메뉴에서 일반신용정보를 고릅니다.
  4. ④ 신용정보 등록현황 확인 등록현황 안에서 신용도판단정보·공공정보·개인대출정보·개설·발급정보·채무보증정보를 차례로 봅니다.
  5. ⑤ 신용도판단정보 세부내역 연체로 등록된 내용이 있는지, 어떤 기관에 어떤 채무가 잡혀 있는지 확인합니다.
  6. ⑥ 개인대출정보 확인 대출기관별 잔액·연체 여부를 확인하고 메모합니다.
  7. ⑦ 채무보증정보 확인 남의 채무를 보증 선 내역이 있는지 확인합니다.
  8. ⑧ 채권자 변동정보 확인 내 채권이 대부업자·채권추심회사 등으로 넘어갔는지(채권자 변경) 확인합니다.
  9. ⑨ 대출채권소각정보·개인회생 신청 등 정보 소각된 채권이나 회생·워크아웃 관련 등록 정보도 함께 확인합니다.

확인 후 이렇게 적으세요

  • 채권기관(어느 회사 채무인지)
  • 채무 종류(대출·카드·보증 등)
  • 현재 잔액
  • 연체 여부와 연체 관련 등록정보
  • 보증채무
  • 채권자 변경 여부
  • 확인한 날짜

장기연체 등록, 언제 확인하나요 (전자책 실전 가이드 — 운영자 경험)

연체는 납부일 다음 날부터 1일 차입니다. 장기연체 등록은 정확히 90일째가 아니라 "연체 시작월의 3개월 후 같은 날"에 되는 경우가 많고, 공휴일이 끼면 95~100일 이상 걸리기도 했습니다. 신용도판단정보에서 연체 관련 등록 내용을 확인하세요. 토스·카카오페이·네이버페이 같은 금융 앱의 [대출] 항목에서도 연체 여부와 일수를 무료로 볼 수 있습니다.

Credit4U에 표시되는 정보는 본인의 채무·신용정보를 확인하기 위한 자료입니다. 실제 새출발기금 지원대상 여부는 새출발기금의 현재 공식 기준과 심사 결과에 따릅니다. 특정 표시·코드로 자격을 단정하지 마세요.

NewStart는 ID, 비밀번호, 인증번호, 공동·금융인증 정보를 받거나 Credit4U에 대신 로그인하지 않습니다.

새출발기금 공식서비스 연결

부실차주 신청 준비

실제 신청과 본인인증은 새출발기금 공식사이트에서 진행합니다. 이 화면은 신청 전 확인할 순서를 정리하는 도우미입니다.

  1. 공식 기준에서 신청 대상과 협약기관 여부를 확인합니다.
  2. 채무상황과 준비할 자료를 정리합니다.
  3. 공식 신청 절차와 영상 안내를 확인합니다.
  4. 공식사이트에서 본인인증 후 신청합니다.

자격·대상채무·준비서류는 바뀔 수 있습니다. 이 페이지의 안내보다 공식 신청 화면의 현재 기준을 우선하세요.

신청 결과·진행상태 확인

NewStart는 신청 결과를 조회하거나 저장하지 않습니다. 신청 후에는 공식 결과조회에서 본인인증 후 표시되는 현재 안내를 확인하세요.

  1. 신청 여부와 추가 확인 요청이 있는지 봅니다.
  2. 공식 화면에 표시된 진행 단계와 안내를 확인합니다.
  3. 제출·연락·추가정보 요청은 공식 안내 기준으로 대응합니다.
