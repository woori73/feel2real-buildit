개인워크아웃 카페 연결

새출발기금 부실차주 라이브러리 카페에 정리한 자료를 올립니다.

1. 네이버 계정 연결

네이버 계정이 연결되어 있습니다.

글을 올릴 운영자 네이버 계정을 연결해 주세요.

서버 설정이 먼저 필요합니다.

연결 해제 후 새 글은 등록되지 않습니다. 이전 발행 이력은 보존됩니다. 네이버 앱 권한 자체는 네이버의 연결된 서비스 관리에서 해제할 수 있습니다.

네이버 앱 설정에 필요한 주소

카페 글쓰기 API 권한을 선택하고 다음 주소를 Callback URL로 등록합니다.

2. 게시판 연결

카페에서 각 게시판을 열고 주소의 menus/ 뒤 숫자를 입력합니다. 게시판 이름과 번호를 함께 확인해 주세요.

글은 멤버공개·검색 비허용으로 등록됩니다. 카페 게시판의 읽기 권한도 함께 적용됩니다.

3. AI에서 사용하기

기존 Feel2Real MCP 연결을 다시 인증하며 카페 글 등록 범위를 선택하세요. 새 권한은 기존 연결에 자동으로 추가되지 않습니다.

자료의 출처·기준일을 표시하고, 개인 사례는 개인정보를 제거한 요약으로 올리세요. 이 기능은 새 글 등록용입니다.

최근 등록 이력

POSTED는 등록 성공입니다. PENDING·UNKNOWN은 카페에서 실제 등록 여부를 확인하세요. 같은 글은 자동으로 다시 전송하지 않습니다.
