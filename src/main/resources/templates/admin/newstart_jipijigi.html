지피지기 Agent — 수동 명령 (V1)

운영자가 지시하면 Agent가 STEP1 우리 DB/RAG → STEP2 신복위 → STEP3 부실차주 카페 → STEP4 공식 검증 → STEP5 추가 기관 순서로 조사해 초안을 만듭니다. 게시 주체는 언제나 운영자 지피지기이며, V1에서 서버는 NAVER 실제 게시를 수행하지 않습니다.

지식 자원 실측 (inventory)

Agent가 실제로 읽을 수 있는 근거 규모. 추측이 아니라 조회 값입니다.

    질문 수집 현황

    질문은 실제 수집본만 저장합니다(발명 금지). 본문 확인 실패는 UNREADABLE로 남깁니다.

      작성 명령 기록

        초안 검토함

        DRAFT → 검토요청(READY_FOR_REVIEW) → 승인(APPROVED) → 게시. 게시는 allowlist 게시판 확인 후 운영자가 수행합니다.

          게시 대상 allowlist 게시판

          이 테이블의 enabled 행만 게시 대상으로 인정됩니다. menuid를 NAVER에서 확인하기 전에는 게시 준비가 완료되지 않습니다.
