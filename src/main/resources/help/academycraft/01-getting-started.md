AcademyCraft는 학원의 학생·반·출결·상담·공지를 한곳에서 관리하는 서비스입니다. 별도 가입 없이 기존 Feel2Real 로그인으로 들어갑니다.

## 시작하는 방법
1. Feel2Real에 기존 계정(ADMIN 또는 TUTOR)으로 로그인합니다.
2. 공용 대시보드에서 [AcademyCraft 출결·학원관리] 카드를 누릅니다.
3. 화면 위쪽 메뉴에서 학생·반·출결·상담·공지로 이동합니다.

> 주의 AcademyCraft용 계정을 따로 만들지 않습니다. 접속이 풀리면 기존 Feel2Real 로그인으로 다시 들어옵니다.

## 이용 가능한 사람과 권한
- ADMIN: 관리자가 승인한 여러 학원 중 하나를 선택해서 관리합니다. 모든 학원에 제한 없이 접근하는 것은 아닙니다.
- TUTOR: 연결된 자기 학원의 데이터만 이용합니다. 다른 학원으로 바꾸는 선택기는 없습니다.
- 학원 연결(소속 승인)은 관리자가 보호된 설정으로 관리합니다. 사용자가 직접 만들거나 바꿀 수 없습니다.
- 메뉴가 보인다고 모든 동작이 허용되는 것은 아닙니다. 권한은 서버가 매번 검사합니다.

## 지금 쓸 수 있는 기능과 상태
- 운영 중: 학생 관리, 반 관리, 출결 관리, 상담(1:1 기록), 공지사항.
- 개발 완료·미배포: 주간 시간표 메뉴 연결 수정, AI 업무 비서(계획·미리보기·승인), 설명서 안내 AI.
- 제공하지 않음(미구현): 수납·결제, 실제 첨부파일 업로드, 상담 본문 덮어쓰기 수정, 학생 비활성화 화면 버튼, 종료한 반을 화면에서 다시 활성화.
- 검증 필요: 모바일 390px·PC 1440px 실제 서비스 화면, 출결 시각의 한국 시간대 표시, 외부 알림(SMS·푸시) 실제 도착.

## 처음 사용할 때 권장 순서
1. 학생을 등록합니다. [학생 관리](/help/academycraft/students)
2. 반을 만들고 담당 강사를 정합니다. [반·수업 관리](/help/academycraft/classes)
3. 반 상세에서 학생을 배정합니다.
4. 출결을 기록합니다. [출결 관리](/help/academycraft/attendance)
5. 필요할 때 공지와 상담을 남깁니다. [공지사항](/help/academycraft/notices) · [상담 관리](/help/academycraft/consultations)

> 주의 화면의 캡처·문서·채팅에 학생 인증키나 연락처를 남기지 마세요.
