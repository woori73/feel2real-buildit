공지는 학원 전체 대상과 특정 반 대상을 나눠서 작성합니다. 공지 등록·목록·상세 조회는 실제 계정으로 확인했습니다.

## 공지 작성하기
1. 위쪽 메뉴의 [공지]에서 [공지 작성]을 누릅니다.
2. 대상에서 [전체공지 (학원 전체)] 또는 [반소식 (특정 반)]을 고릅니다.
3. 반소식이면 반을 선택합니다.
4. 제목과 내용을 입력하고 화면 아래의 [공지 등록 · 알림 발송]을 누릅니다. 모바일에서는 아래로 스크롤해야 버튼이 보입니다.
5. 등록 후 목록과 상세 화면에서 내용을 확인합니다.

## 공지 수정하기
1. 공지 상세 위쪽의 [공지 수정]을 누릅니다.
2. 제목과 내용을 확인하고 고친 뒤 저장합니다. 중간의 [취소]는 저장 요청을 중단합니다.

공지 수정과 수정 내용 반영을 로컬에서 직접 실행해 확인했습니다. (로컬 실행 확인 2026-10-20)

## 공지 삭제(비활성화)
공지 상세의 [삭제]는 활성 목록에서 제외하는 처리입니다. 화면에서 되돌리는 기능이 없으므로 학원, 제목, 대상 반을 확인하고 승인된 경우에만 실행하세요. 삭제 뒤 목록에서 사라지는 것을 로컬에서 직접 실행해 확인했습니다. (로컬 실행 확인 2026-10-20) 공지 작성·수정·삭제는 원장과 일반 강사 모두 할 수 있으므로 다른 사람이 쓴 공지를 지우지 않도록 주의하세요.

## 첨부파일
첨부파일 이름과 키는 정보만 저장됩니다. 실제 파일 업로드는 지원하지 않습니다. (미구현) 작성자 회원 ID는 로그인한 사용자로 정해지므로 바꾸거나 다른 사람의 ID를 입력하지 마세요.

## 알림 발송
공지 등록 시 알림 발송이 함께 요청됩니다. 외부 알림(SMS·푸시)이 실제로 도착하는지는 확인되지 않았습니다. (검증 필요)

## 이용 권한
- 공지 작성·수정·삭제: 원장과 강사 모두 가능합니다. 삭제는 되돌릴 수 없으니 확인 후 진행하세요.
