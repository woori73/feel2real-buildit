상담 메뉴의 작성 링크는 화면 제목이 [아이소식 작성]인 1:1 기록 화면으로 연결됩니다. 상담 작성·목록·상세 재조회는 실제 계정으로 확인했습니다.

## 상담 기록 작성하기
1. 위쪽 메뉴의 [상담]에서 [+ 상담 기록 작성]을 누릅니다.
2. 왼쪽에서 학생을 선택하고 받는 대상 이름을 확인합니다.
3. 제목과 내용을 입력하고 [1:1 전송]을 누릅니다.
4. 전송 후 [상담] 목록에서 제목을 눌러 저장된 내용을 확인합니다.

> 주의 현재 상담 작성은 비공개 초안 저장이 아니라 1:1 전송입니다. 저장 성공 메시지는 외부 SMS·푸시가 실제로 도착했다는 뜻이 아닙니다. 보내기 전에 대상과 내용을 확인하세요. 상담 작성 화면에는 별도 취소 버튼이 없으며, 전송 전에 다른 메뉴로 나가면 전송되지 않습니다.

## 상담 목록 보기
목록 위쪽의 [전체], [미답변], [답변완료], [종료]로 상태를 나눠 봅니다. 학원이 보낸 아이소식도 전체 목록에 표시됩니다.

## 잘못 보낸 내용 보완하기
기존 본문을 덮어쓰는 수정 기능은 없습니다. (미구현) 오류가 있으면 같은 대화에 후속 메시지를 남겨 이력을 보존합니다. 후속 메시지 전송은 로컬에서 직접 실행해 확인했습니다. (로컬 실행 확인 2026-10-20)

## 상담 종료
1. 대화의 [상세]에서 [상담 종료]를 누르고 확인합니다.
2. 종료된 상담에는 메시지를 더 쓸 수 없습니다.
3. 종료한 상담의 메시지는 삭제되지 않고 보존됩니다.

상담 종료와 "종료 뒤 메시지 거부"를 로컬에서 직접 실행해 확인했습니다. (로컬 실행 확인 2026-10-20) 원장과 강사 모두 상담을 작성할 수 있습니다.

## 알림 도착
상담 전송 후 외부 알림(SMS·푸시)이 실제로 도착하는지는 확인되지 않았습니다. (검증 필요)

## 이용 권한
- 상담 작성·후속 메시지·종료: 원장과 강사 모두 가능합니다.
