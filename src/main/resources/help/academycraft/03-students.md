학생 메뉴에서 이름 검색, 신규 등록, 기존 정보 수정을 시작합니다. 학생 등록과 조회는 실제 계정으로 확인했습니다.

## 학생 찾기
1. 위쪽 메뉴의 [학생]을 누릅니다.
2. 이름 검색란에 이름을 입력하고 [검색]을 누릅니다.
3. 이름을 비우고 검색하면 활성 학생 목록 전체를 볼 수 있습니다.

## 학생 등록
1. [학생] 화면에서 [+ 학생 등록]을 누릅니다.
2. 학생 이름(필수), 학년, 학부모 이름, 연락처를 입력합니다.
3. [등록]을 한 번만 누릅니다. 완료 알림이 나오면 목록에서 이름을 확인합니다.
4. 등록 양식의 [취소]는 입력창을 닫습니다. 저장되지 않습니다.

> 주의 등록 완료 알림에는 학생 인증키가 표시됩니다. 화면 캡처·채팅·공유 문서에 인증키나 연락처를 남기지 마세요. 등록 버튼을 연속으로 누르면 같은 학생이 중복 등록될 수 있습니다.

## 학생 정보 수정
1. 학생 목록에서 해당 학생의 [상세·수정]을 누릅니다.
2. 이름, 학년, 학교, 학부모 이름, 연락처 순서로 입력창을 확인하고 고칩니다.
3. 마지막으로 저장합니다. 수정 중 입력창의 [취소]를 누르면 저장 요청이 진행되지 않습니다.

학생 정보 수정은 원장 권한이 필요하며, 일반 강사 권한으로는 서버가 거부(403)합니다. 원장 수정 저장과 강사 거부를 로컬에서 직접 실행해 확인했습니다. (로컬 실행 확인 2026-10-20)

## 학생 비활성화와 삭제
- 학생 비활성화는 서버 기능은 있지만 현재 화면에 버튼이 없습니다. (화면 미구현)
- 학생을 삭제하는 화면 기능은 제공하지 않습니다. 반 상세의 [제외]는 반 배정만 해제하며 학생 등록은 유지됩니다.

## 이용 권한
- 학생 등록·조회: ADMIN, TUTOR(원장 역할 또는 일반 강사 역할 모두 가능).
- 학생 정보 수정·반 배정: 원장 역할만 가능합니다. 일반 강사는 거부됩니다.
