# 수정 예산 및 추진 일정 (Mobile MCP 반영)

- 작성일: 2026-11-19
- **원칙**: 기존 사업비 **총액은 바꾸지 않는다.** 새 항목은 기존 항목(주로 하드웨어) 안에서 조정해 마련한다.
- **한계**: 사업계획서 원본(v7)의 항목별 금액이 저장소에 없어 **기존 금액 칸을 비워 두었다.** 원본을 주시면 금액을 채워 확정한다. 아래 개발 규모(인·주)는 설계서 기준 추정이다.

## 1. 개발 규모 추정 (새로 반영할 항목)

| 항목 | 내용 | 규모(인·주, 추정) |
|---|---|---|
| Mobile MCP 계층 | 기기 인증, 명령 접수, 기기 요청 큐, `f2r_*`·`mobile_*` 도구, 승인 화면, 학생 명부 연결 | 6 |
| Android 앱 | 자동 로그인, 음성·문자, 카메라(품질 점검), 작업·승인 화면, 카카오톡 공유, 폴드 화면 대응 | 8 |
| PC Agent | 등록·연결 유지, Claude Code·Codex 실행, 결과 업로드, 대기·복구 | 4 |
| 인증·보안 | 기기 토큰·Keystore·DPAPI, scope·권한 검사, 감사 로그, 보안 점검(내부) | 3 |
| 통합 테스트 | M1~M10 실기기 시험, 회귀, 교습소 시범 운영 | 3 |
| **합계** | | **24인·주(약 6인·월)** |

- 선택 항목: 외부 보안 점검(모의 해킹) 1회. 견적을 받아 결정한다.
- **AI 사용료**: 시험 단계는 API 키 사용 시 월 상한 50달러로 둔다(설계서 추정 월 25~75달러). 구독 경로는 추가 비용이 없다.
- **인프라**: 기존 서버·DB를 쓴다. 사진 보관(30일) 비용은 월 1달러 미만으로 추정한다.
- **기기**: 갤럭시 Z 폴드6와 지정 PC는 보유 기기를 쓴다. 구입하지 않는다.

## 2. 변경 예산표 (총액 고정)

| 비목 | 세부 항목 | 기존 금액 | 변경 금액 | 증감 | 사유 |
|---|---|---|---|---|---|
| 인건비 또는 외주 개발비 | Mobile MCP 계층·Android 앱·PC Agent·보안·통합 테스트(24인·주) | (원본) | (원본) + **D₁** | +D₁ | 모바일 연동 체계 신규 |
| 클라우드·AI 사용료 | 시험 단계 API 사용료(월 상한) | (원본) | (원본) + **D₂** | +D₂ | 모델 실행비. MCP는 비용을 부담하지 않음 |
| 보안 | 외부 보안 점검(선택) | (원본) | (원본) + **D₃** | +D₃ | 모바일 인증 점검 |
| **하드웨어** | 로봇 팔·관련 장비 구입 | (원본) | (원본) − **H₁** | −H₁ | 로봇 팔은 2028 이후 연구 단계로 조정 → 1R에서는 구입 시기를 늦추거나 수량을 줄임 |
| **하드웨어** | 스마트폰 탑재형 로봇 시제품(회전 거치대·스피커 등) | (원본 또는 0) | **H₂** | +H₂ | 보유 폴드6 활용, 저가 시제품 1대 |
| **하드웨어** | 시험용 휴대기기·PC | (원본) | (원본) − **H₃** | −H₃ | 보유 폴드6·학원 PC 사용으로 신규 구입 불필요 |
| **합계** | | **(원본 총액)** | **(원본 총액)** | **0** | **D₁ + D₂ + D₃ + H₂ = H₁ + H₃** |

- 하드웨어 항목 이름은 원본 계획서의 비목에 맞춰 바꾼다.
- 감액할 하드웨어 항목이 부족하면 Android 앱 범위를 단계로 나눈다. 1차는 문자·카메라·승인·공유, 2차는 음성 고도화·푸시다. 그만큼 D₁을 줄이고, 그래도 총액을 맞추지 못하면 보고한다.
