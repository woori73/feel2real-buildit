# F2R Mobile MCP — 통합 테스트 계획

> **상태: 미실행(구현 전).** 실행하지 않은 항목은 완료라고 보고하지 않는다.
> 환경: 로컬 또는 시험 서버, Galaxy Z Fold6, 지정 PC 1대. **학생은 가명 데이터만 쓴다**(동명이인 확인용 `시험민수` 2명 포함).
> 기존 Coordinator 시험 T1~T5([../F2R_Integration_Tests.md](../F2R_Integration_Tests.md))는 이 계획에 포함된다.

## 자동화 범위

- **서버**(CI)
  - given/when/then 단위 테스트: 기기 토큰, 기기 요청 만료, scope 필터, 가명화, 중복 requestId
  - MySQL 통합 테스트: 출결 중복 방지, 승인 후 실행, 해지 기기 거부
- **PC Agent**: `node --test`(임대 시간 연장, 재시도 대기 시간, 폴더 격리, Runner 인자에 셸 도구가 없는지)
- **Android**: JUnit(명령 분류·재확인·토큰 갱신). 카메라·음성·공유는 실기기 수동 점검(녹화 보관)
