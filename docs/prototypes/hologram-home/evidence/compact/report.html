변경 범위

Hyper3D 시안 커밋 2ac1b1d1에서 feat/compact-ai-assistant-20261028 브랜치를 만들었습니다. 원격 main df425588, PR #913 e458864e를 확인했으며 두 브랜치를 수정하지 않았습니다. 모든 변경은 docs/prototypes/hologram-home 안에 있습니다. 운영 홈페이지/DB/미디어를 변경하지 않았고 유료 생성·병합·배포도 하지 않았습니다.

compact.css로 크기·여백·카드 간격·HUD·그림자를 조정했습니다. 전체 페이지 transform/zoom을 사용하지 않아 글자와 클릭 영역이 함께 작아지지 않습니다. 기존 영상/포스터는 contain을 유지하고 3D canvas는 기존 ResizeObserver로 새 영역에 맞춰집니다. 캐릭터 원본·카메라/리깅·안내 문구·상태 전환 로직은 수정하지 않았습니다.

대화창에는 키보드 포커스와 compact.js의 Home/End 스크롤 처리를 추가했습니다. 대화 내용은 삭제하지 않고 제한된 높이 안에서 스크롤합니다. 전후 비교 캡처는 같은 브라우저·viewport·합성 미디어를 사용했습니다. 기본 영상/대화창 비교는 대화 스크롤을 맨 위로 맞췄고, 캐릭터 전환/3D 화면은 main의 자동 스크롤 상태입니다.

중간 검사 오류와 보완

캡처 재실행 세 차례에서 키보드 스크롤 시간 초과4건(360px 두 번, 390px 두 번)이 있었습니다. 기본 키 처리의 완료 시점과 스크롤 끝값의1px 차이를 확인했습니다. 최종 시안은 대화 영역에 포커스가 있을 때만 Home/End를 명시적으로 처리하며, 버튼·입력·브라우저 단축키는 가로채지 않습니다. 첫 결과, 두 번째 결과, 세 번째 결과, 진단 로그와 실패 캡처를 보존했습니다.

병행 회귀 실행 중360px의 안내 다시 보기 검사와1440px의 인사 음소거 상태 검사에서도 각각 한 번 실패했습니다. 전자는 이전 메뉴 응답을 새 응답으로 판단하던 대기를 메시지 수 증가 대기로 보완했고, 후자는 재생 중인 해당 인사 프레임을 찾을 때 음소거/반복 값을 함께 읽도록 보완했습니다. 3D 중간 실패와 복원 중간 실패를 보존하고 두 회귀 검사를 순차 재실행했습니다. 안내·영상·3D 제품 로직은 수정하지 않았습니다. 최종 결과와 중간 실패는 별도로 기록했습니다.

cd docs/prototypes/hologram-home

python serve.py --port 8765

별도 터미널에서 기존 npm 검사 명령을 사용할 수 있습니다. 3D 테스트의 EVIDENCE_DIR 옵션을 추가하여 이전 증거를 덮어쓰지 않고 결과를 보관했습니다. 비교 캡처 스크립트는 변경 전 서버8766, 변경 후 서버8765를 사용합니다. PLAYWRIGHT_MODULE과 CHROMIUM_PATH는 환경에 맞게 지정할 수 있습니다(캡처 스크립트 Chromium은 /usr/bin/chromium).

PHASE=before node tests/compact-capture.cjs
PHASE=after node tests/compact-capture.cjs
node tests/compact-verify.cjs
EVIDENCE_DIR=./evidence/compact/legacy npm run test:legacy
EVIDENCE_DIR=./evidence/compact/restoration npm run test:restoration
EVIDENCE_DIR=./evidence/compact/hyper3d npm run test:3d
npm run test:3d:unit

실제 캐릭터 연결 시 동일 viewport에서 얼굴·의상·전체 비율을 확인해야 합니다. 모바일 키보드가 열린 실제 기기 화면과 Safari는 후속 검증 대상입니다. 새 브랜치의 원격 CI/Java 빌드는 실행하지 않았으며, 위 로컬 자동 검사와 구분합니다.
