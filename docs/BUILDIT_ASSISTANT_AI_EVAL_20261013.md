"검증 통과 연산 비율"이 100%를 넘는 것은 `applyAsset` 한 개가 여러 연산으로 펼쳐지기 때문이다(지표 한계).

## 2. 실제 AI 브라우저 E2E (최초 생성 → 연속 수정 → 미리보기 → 되돌리기 → 승인 게시)
- 3회 실행 중 마지막 실행 **32/32 통과**, 앞선 실행은 스크립트 가정 오류(이미 적용된 효과를 다시 요청) 1건으로 30/32였으며 앱 결함은 아니었다.
- 6회 연속 수정이 모두 `AI:muse-spark`로 처리, 규칙 폴백 0건. 변경 요약 매 회 표시, 공개 홈페이지는 매 단계 불변, 전체 되돌리기로 게시 직후 상태 복원, 3기기 미리보기 가로 스크롤 없음, 승인 후에만 공개 반영, 페이지 오류 없음.
- 지연(서버 AI) 실행별로 p50 6~14초, p95 16~44초. 최초 생성은 35~71초(생성 단계의 AI 호출 포함). 진행 상태 UI가 있으나 복합 요청은 체감이 길다.
