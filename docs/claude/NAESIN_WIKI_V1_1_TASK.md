# 내신 Wiki V1.1 작업 지시서 (Claude용)

이 문서는 이번에 Claude가 당장 수행해야 할 작업만 기록합니다. 프로젝트 배경과 장기 원칙은 `BUILDIT_CLAUDE_HANDOFF.md`를 먼저 읽고 이해한 뒤 이 문서를 따르세요.

---

## 1. 현재 V1의 가장 큰 UX 문제

새로운 내신 Wiki 첫 화면은 만들어졌지만, 새 UI와 기존 Wiki 기능이 분리되어 있습니다. 예:

- 제작 문제 Word 2007 내보내기가 기존 화면에 숨어 있음
- 학생 오답 저장은 가능하지만 선택 오답 Word 내보내기가 없음
- 학교 프린트 신규 UI와, 들어간 뒤 보이는 구형 UI가 일관되지 않음
- 기존 기능들이 구형 화면 곳곳에 남아 있음
- 첫 화면에서 4 CORE가 병렬로 나타나 신규 사용자가 무엇부터 해야 할지 알기 어려움

### 중요한 개발 원칙

**새로운 기능을 만들기 전에 저장소 전체에서 기존 구현을 먼저 찾습니다.**
기존 기능을 새 UI에 재연결·재배치하는 것이 우선입니다.

---

## 2. 첫 화면을 바꾼다

현재처럼 다음을 첫 화면에서 병렬로 보여주는 것을 기본 UX로 사용하지 않습니다.

```
제작 문제 | 학교 프린트
학생 오답 | 수업 인사이트
```

처음 사용하는 원장이 무엇을 해야 할지 안내하는 **Scenario UI**로 바꿉니다.

### STEP 1 — 자료 모으기
> 시험 준비에 필요한 자료부터 모아주세요.

```
[학교 프린트 추가]
[학생 오답 추가]
```

현재 저장된 자료 개수 표시.

### STEP 2 — 수업 기록
> 수업하면서 발견한 내용이나 학교 선생님의 강조사항을 남겨주세요.

```
[수업 인사이트 기록]
```

### STEP 3 — 문제 준비
> 모아둔 자료와 출제자 Digital Twin을 활용해 시험 문제를 준비합니다.

```
[문제 만들기]
[기존 문제 변형]
[저장된 문제]
```

기존 Word 2007 내보내기 기능도 여기와 자연스럽게 연결합니다.

### STEP 4 — 시험 준비
> 지금까지 모은 자료와 문제로 최종 시험을 준비합니다.

```
[FINAL 준비]
[직보 준비]
```

즉 사용자가 위에서 아래로 읽는 것만으로 사용법을 이해할 수 있어야 합니다.

(참고: 4 CORE 구조 자체는 없애지 않습니다. Work/Claude Admin 화면인 FINAL Workspace에서는 그대로 유지합니다. 자세한 구조는 `BUILDIT_CLAUDE_HANDOFF.md` 7~8번 참고.)

## 3. 이번 Claude 개발 작업 범위

이번에는 **내신 Wiki V1.1 UI와 기존 기능 통합만** 합니다.

### 해야 할 것
- Scenario형 첫 화면 구현
- 기존 기능 조사 (repo 전체에서 숨어 있는 기능 찾기)
- 구형 UI와 새 UI 통합
- 제작 문제 선택/Word 2007 export 연결
- 학교 프린트 원본+JSON UI 통일
- 학생 오답 원본+JSON UI 통일
- 학생 오답 선택 Word export (신규 구현이 필요하면, 기존 제작 문제 Word export 구현을 최대한 재사용)
- 수업 인사이트 UI 통일
- FINAL/직보 Workspace 정리
- 기존 데이터와 기능 보존
- 테스트

### 하지 않을 것
- Hermes
- LMS
- 영상 제작
- 문법 Wiki
- 독해 Wiki
- 수능 Wiki
- 대형 RAG
- DB 전면 재작성
- Digital Twin 재개발
- 불필요한 API 추가
- 미래 기능 과설계

## 4. 작업 순서 및 완료 보고

`BUILDIT_CLAUDE_HANDOFF.md` 12번(GitHub 작업 규칙)을 그대로 따릅니다.

```
최신 main 확인 → 기존 구현 검색 → 작업 branch → 코드 수정 → 테스트 → GitHub에 push
```

Claude는 배포하지 않습니다. 작업 완료 후 다음만 보고합니다.

```
1. Branch
2. Commit SHA
3. 변경 파일
4. 변경 내용
5. 기존 기능 재사용 내용
6. DB/API 변경 여부
7. 테스트 결과
8. Work가 병합/배포할 때 주의할 점
```
