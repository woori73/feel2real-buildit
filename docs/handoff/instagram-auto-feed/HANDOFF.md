## 1. 한 줄 요약

로보MD(robomd.io)에서 돌리고 있는 인스타그램 자동 피드 3개 규칙을, feel2real 관리자 영역 안의 자체 기능으로 옮긴다. 매일 정해진 시간에 이미지와 문구를 만들어 목록에 쌓고, 사람이 검토한 뒤 발행한다.

## 3. 지켜야 할 원칙

1. **로보MD 복제 금지.** 로보MD의 코드·내부 API·프롬프트·화면 디자인을 분석하거나 베끼지 않는다. 이 문서에 적힌 기능 흐름만 참고하고 화면은 F2R 디자인으로 새로 만든다.
2. 기존 서비스 기능·디자인·DB 데이터는 삭제하거나 바꾸지 않는다. 새 테이블 6개와 새 관리자 화면만 추가한다.
3. 저장 방식 기본값은 **목록 저장(검토 후 발행)**. 자동 발행은 1차에서 켜지 않는다.
4. 문구는 과장되거나 광고처럼 들뜬 표현을 쓰지 않는다(대표 고정 지침).
5. 작업은 단계별로 묻지 말고 브랜치 → 구현 → 테스트 → PR → 병합 → 운영 배포까지 진행한 뒤 끝에 한 번 보고한다.

## 4. 범위

1차(이번 작업): 개발 단계 1~3.

1. **기반**: Meta 앱 연동 코드, 인스타그램 계정 연결 화면, DB 테이블 6개, 관리자 화면 틀
2. **생성**: 브랜드 프리셋, 이미지·문구 생성, 시험 생성 1장, 생성 기록, 월 상한
3. **예약·검토**: 예약 실행, 콘텐츠 목록, 문구 수정, 수동 발행

이번 범위 밖: Threads 발행, 카드뉴스(여러 장), 성과 리포트, 자동 발행 켜기.

## 8. 외부 연동과 비용 통제

- **인스타그램**: Meta 공식 Graph API(콘텐츠 게시). 하루 게시 한도 등은 개발 시점의 최신 공식 문서로 확인.
- **이미지 생성**: 엔진을 바꿀 수 있게 어댑터로 분리. 참고 이미지 기반 생성이 되는 엔진을 쓰고, 승인된 캐릭터 얼굴이 유지되는지 시험해서 고른다.
- **문구 생성**: 브랜드 프리셋 + 최근 주제 목록을 넣어 호출.
- **월 상한**: 전체·규칙별 상한을 환경변수로 둔다(예: `SNS_MONTHLY_BUDGET_KRW`). 값이 없거나 0이면 생성하지 않는다. 상한에 닿으면 멈추고 홈에 알린다.
- **실패**: 1회만 재시도, 그다음은 실패 탭에 사유 기록. 무한 재시도 금지.
- **보안**: 토큰·API 키는 암호화해 서버에만 저장, 화면·로그에 노출 금지.

  - 목적: 홍보. 드라마 《AI AGENT》의 세계관과 캐릭터(서수니, 세븐)를 조금씩 소개해 관심을 모으고, 이 드라마를 만드는 Feel to Real과 홈페이지를 자연스럽게 알린다.
  - 상세 지시:
    - 글 하나에 한 가지만 소개한다(서수니의 성격, 세븐의 역할, 두 사람의 관계, AI와 인간에 대한 질문 등).
    - 서수니: 평소에는 귀엽고 친근하지만 작전에서는 강렬한 여전사. 무적이 아니라 위기를 이겨내는 사람.
    - 세븐: 차분하고 지적인 바이오 AI 에이전트. 길 안내자가 아니라 계획과 재계획을 세우는 전략가.
    - 결말, 악역의 정체·이름, 반전은 절대 쓰지 않는다. 작품에 없는 설정·인물·공개 날짜를 지어내지 않는다.

    - 과장되거나 가벼운 광고 말투는 피하고, 짧고 여운 있는 문장으로 쓴다.
    - 마지막에 한 줄로, F2R 홈페이지에서 세븐·서수니를 AI 비서로 만날 수 있다는 점을 연결한다.
