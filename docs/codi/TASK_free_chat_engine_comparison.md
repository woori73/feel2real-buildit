# [기획 임무 요청서 → Codex] 코디 자유대화용 무료/국산 AI 엔진 비교·선정

발행: 2026-11-28 KST · 요청: 차원연산4 · 수행: Codex · 검수: 차원연산4

## 1. 배경·목적
코디 제품은 엔진을 업무별로 나눈다(멀티 프로바이더 어댑터):
- **자유대화(텍스트)** → **무료/저비용 국산 엔진** (우리 비용 최소화)
- 정형업무(채점·기출·출결·장부, 과금) → Claude(텍스트)
- 음성 대화 → OpenAI Realtime

이 요청은 **자유대화 + 저난도 업무에 쓸 "무료/국산 엔진"을 비교·선정**하는 기획이다. 결과는 코디 어댑터의 1차 엔진 결정과 로드맵에 쓰인다.

## 1.5 난이도 기반 엔진 라우팅 (제품 결정, 2026-11-28)
- **저난도 업무(상담 응대·출결 기록/확인·간단 안내·확인) → 무료 국산 소형 엔진(카나나 등)**
- **고난도 업무(문제 제작: 기출·학습지·시험문항) → Claude(과금)**
- 음성 대화 → OpenAI Realtime
→ 따라서 이 비교는 **저난도·자유대화를 감당할 "소형 무료 엔진"** 선정에 초점(대형 불필요). 카나나는 HF 오픈웨이트(예: `kanana-2-3b-instruct`, `kanana-nano-2.1b-instruct`) 기준으로 평가.

## 2. 비교 대상 (4종)
1. **카카오 카나나(Kanana)** — 오픈소스 경량 모델 + "카나나 오픈 라이선스"(상업 이용 허용) / 카나나-o API CBT는 종료.
2. **업스테이지 Solar**
3. **LG 엑사원(EXAONE)**
4. **모두의 AI**(과기정통부·NIPA, 12월 정식 출시 목표, 개발자 API 개방 여부 불확실)

## 3. 비교 기준 (표로 작성)
각 모델에 대해:
| 축 | 확인할 것 |
|---|---|
| 접근 방식 | 공개 API(종량/무료) vs 오픈웨이트(자체 호스팅) |
| **라이선스** | **상업 이용 가능 여부 + 핵심 조항**(제한·귀속·재배포). 공식 출처 링크 필수 |
| 비용 | API 요금(있으면) 또는 자체호스팅 GPU/운영비 추정 |
| 성능 | 한국어 대화·지시수행·컨텍스트 길이·멀티모달 여부(공개 벤치/후기 근거) |
| 자체호스팅 난도 | 파라미터 규모·GPU VRAM 요구·서빙 스택(vLLM 등)·운영 부담 |
| 가용성·일정 | 지금 쓸 수 있나 / 베타·대기·출시예정 |
| 데이터·개인정보 | 국내 처리 여부, 해외 전송 가능성(자유대화엔 개인정보 미투입 전제이나 확인) |

## 4. 요구 산출물
1. **한눈 비교표**(위 축 × 4모델).
2. **권고**: 자유대화 **1차 엔진 1개** + **예비 1개**, 이유(비용·라이선스·가용성 우선).
3. **어댑터 통합 메모**: 코디 자유대화 어댑터에 어떻게 꽂는지(공개 API 호출형 vs 자체호스팅형), 전환 조건(예: 모두의AI API 열리면 전환).
4. **불확실성 표기**: 라이선스·가용성은 **공식 출처(각 사 사이트/깃허브/정부 공고)**로 확인하고, 불확실하면 "확인 필요"로 명시.

## 5. 제약·주의
- **라이선스는 추정 금지** — 상업 이용 가부는 공식 라이선스 원문으로 확인(특히 엑사원·카나나·Solar 조항 차이).
- 코디 자유대화는 **비용 0 지향** — API 유료면 "자체호스팅 가능한 오픈웨이트"와 원가 비교.
- 성능은 **한국어 대화·학원 안내 톤** 기준(일반 벤치보다 실사용 적합성).
