## 0. 핵심 차별성 — 피클/범용 에이전트가 못 하는 것 (해자)
피클 같은 범용 AI 에이전트는 전화·쇼핑·예약은 하지만 **학원 업무 시스템과 데이터가 없다.** 코디의 해자:
- **F2R 업무 통합**: 채점·출결·장부·학생부·기출제작이 **실제 시스템에 연결돼 기록으로 남음**(범용 에이전트 불가).
- **학원 도메인 데이터**: 학생부·내신 Wiki·기출·시간표 — **현장에서만 쌓이는 데이터**(외부 접근 불가).
- **정확한 기록 귀속**: 채점사진→맞는 학생부, 출결→맞는 반 (학원 데이터 모델 필요).
- **신뢰·보안**: 학생 개인정보 **최소권한·국내처리·동의·AI고지**(피클은 광범위 권한·해외·무단발신으로 사고).
→ 경쟁 전략: 범용 기능으로 겨루지 말고 **"학원 업무에 깊이 박힌 AI"**로. **P1(F2R연결·기록 보안연결)이 이 해자를 만든다.**

## 1. 엔진 라우팅 (업무별, 2026-11-28 갱신)
| 업무 | 엔진 | 비용 |
|---|---|---|
| **문제 제작**(기출·학습지·직보) ·핵심 | **Claude Opus 5.5** | 높음(품질우선, 2,000원+ 허용) |
| **빠르고 정확한 채점**(Vision) | **Sonnet 5.5 기본 + 애매 시 Opus 승격** | 중(Sonnet)+소수 Opus |
| **그 외 F2R 기능**(출결·복식장부·안내문·상담·확인) | **Claude Sonnet 5.5** | 중 |
| **일반 대화(자유대화)** | **모두의 AI API**(12월 출시) | 무료 |
| **그 외·음성**(비F2R) | **ChatGPT GPT-6.x — Terra(기본, 균형·저가 ~$1/$5) / Sol(고성능 ~$2/$10)** | 종량(공식가격 재확인) |
| **카톡 문구 포장**(말로→포장→공유) | **카나나(무료)** | ~0 (실측: 무료·글 잘 다듬음) |
| 마스코트(새싹 코디) | UI(엔진 아님) | 전 화면 유지 |
- 요약: **Claude(핵심2=Opus / 나머지 F2R=Sonnet) + 모두의AI(자유대화) + ChatGPT GPT-6.x(그 외·음성) + 카나나(카톡 문구 포장).** 전부 교체형 어댑터.
- **핵심 고가=문제제작(Opus). 채점=Sonnet 기본(+애매시 Opus 승격)으로 원가 완화.** → 요금제 단가·한도 재산정 대상.

## 2. 기능 백로그 (우선순위)
### P0 — 지금 (수익 토대 + 앱 복구)
- **Phase 1 안내문 계량**(과금 토대, 관찰 전용) — `PHASE1_BUILD_SPEC`.
- **앱 M1**(마스코트 + 작동 대화, 옛 깨진 화면 폐기) — `M1_APP_BUILD_SPEC`.

### P1 — 다음 (핵심 수익 + 이번에 추가된 2영역)
- **문제 제작 자동 파이프라인 (고난도·핵심 수익)**: 기출+시험범위 → **Claude Opus 5.5 자동생성(예상문제·직보)** → 다른 **3곳 검수**(`f2r_pc_task_review`) → **내신위키/원장 지정 업로드**. 기존 `f2r_pc_task_*` 제작공장 흐름을 **매끄럽게 연결 + 자동화**. 저작권 규칙(평가요소만 읽고 지문·선지 새로, F2R 로고) 준수. 과금=기출세트(채택 문항 1건, Phase2). 비용: Opus 고가→생성 Sonnet/검수 Opus 혼합 등 원가 최적화.
- **F2R ↔ 앱 연결 UX (편하고 빠르게)**
  - 빠른 로그인(자동/생체/원터치 학원계정), 세션 끊김 복귀.
  - 앱↔서버 **데이터 동기 속도**(느린 로딩·403 튕김 제거 — M1에서 1차 해결).
  - **업무 1스텝**(말/탭 한 번 → F2R 반영), 약한 네트워크 대응.
- **학원 기록: 보안 + 연결 (편리·정확)**
  - **보안**: 학생 개인정보(실명·연락처·성적) 암호화·접근통제·공개캡처 가림, 권한(원장/강사), 감사로그. **외부 무료엔진(카나나 등)에 개인정보 미투입** 보장(자유대화·저난도도 비식별).
  - **연결(정확)**: 기록이 **정확한 학생·반·과목·날짜에 자동 귀속**(채점사진→맞는 학생부, 출결→맞는 반, 장부→맞는 거래). 동명이인 구분, 중복·오귀속 방지(= Phase1 멱등·귀속 정확과 동일 원칙 확장).
