## 3. 대화 엔진 (M1 = Claude, 작동 우선)
- **M1은 지금 작동하는 Claude API로 실제 답변**: 앱 → **우리 서버 엔드포인트** → 서버가 키 보유(비밀저장소) → Claude 호출 → 답변.
  - 서버: `anthropic.enabled=true` + `ANTHROPIC_API_KEY`(콘솔 키, 잔액 $5 확인됨). 기존 `ClaudeChatService` 경로 재사용 가능.
  - ⚠️ **M1 한정 인터메디엄**: 자유대화를 Claude로 돌리면 우리 비용 발생(파일럿 소액). **M1.5에서 무료 국산 API(업스테이지/엑사원→모두의AI)로 어댑터 교체**해 비용 0로. → 엔진 호출부는 **교체형 어댑터 인터페이스**로 설계(엔진 종속 금지).
- 개인정보/업무 데이터는 자유대화에 넣지 않음(안내 문구).

## 4. 마스코트
- 상단 고정 아바타. 포즈 반응: 대기(idle) → 듣는 중(헤드셋)/처리 중(태블릿) → 완료. 캐릭터 선택(새싹/세븐/서수니)은 메뉴에.

## 5. 검수 기준 (연산4) — 전부 통과해야 M1 완료
1. **폴드6 커버 화면**에서 앱 아이콘 → 로그인 → **마스코트 + 대화창**이 바로 뜸(튕김·403·'접근 권한' 없음).
2. 메시지 전송 → **실제 AI 답변** 수신(데모 503 아님).
3. 마스코트가 처리 중/완료 포즈로 반응.
4. **좁은 폭(폴드6 커버)·키보드 올라온 상태**에서 입력창·전송 버튼 보임(게이트1-1/1-5).
5. 엔진 호출이 **어댑터 경유**(나중에 무료 API로 바꿔도 화면 변경 0).
