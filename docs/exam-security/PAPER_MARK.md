# F2R 종이 시험지 보안 무늬 — 설계 (v0.1, 2026-11-21)

> 원장님 지시: 시험지 종이에 **수험생 눈에는 안 보이지만 AI(카메라로 찍은 사진)에는 영향을 주는** 부정행위 방지 코드·방식을 고안하고, 다이내믹 덴서티·양자화·차원연산을 적용한다.
> 결론부터: **사진에서만 드러나는 좌석 코드(추적)**는 원리상 만들 수 있고 계산 모형에서 동작한다. **AI가 오답을 내게 만드는 것(교란)**은 확실한 방법이 없어 측정할 가설로만 둔다([LIMITS.md](LIMITS.md) L20). 코드: `scripts/exam_security/paper_mark.py`(시뮬레이션, 테스트 `test_paper_mark.py`).

## 1. 목표를 두 개로 나눈다

| 목표 | 뜻 | 가능성 | 이번 설계 |
|---|---|---|---|
| **A. 추적(주 목표)** | 시험지를 찍은 사진이 밖으로 나가면 **어느 좌석 시험지인지** 사진에서 읽는다 | 원리상 가능(복사 방지 'VOID' 무늬와 같은 계열). 계산 모형에서 동작 | 구현(시뮬레이션) |
| **B. 교란(보조)** | 사진을 받은 AI가 문제를 덜 정확히 읽거나 풀게 한다 | 불확실. 숨은 지시문은 여러 AI가 무시했고(R1), 미세 무늬로 AI를 속이는 방법은 모델마다 달라 업데이트되면 사라진다 | 측정 계획만 |

A가 알려지는 것만으로도 "찍으면 내 좌석이 드러난다"는 억지 효과가 있다. B는 효과를 잰 뒤에만 쓴다. 목표 B를 장치로 구체화한 고안은 [AI_ANSWER_GUARD.md](AI_ANSWER_GUARD.md)(2026-11-22).

## 2. 원리: 사람 눈과 카메라가 다르게 섞는 무늬

같은 잉크 양(25%)으로 두 가지 무늬를 인쇄한다.

| 무늬 | 모양(1200dpi 기준) | 사람 눈(30㎝) | 휴대폰 카메라 |
|---|---|---|---|
| 바탕(base) | 1×1점을 2칸마다(점 간격 약 0.04㎜) | 고른 회색 | 픽셀이 점을 섞어 고른 회색 → 대비 강화로 **더 밝아짐** |
| 표시(mark) | 3×3점을 6칸마다(점 간격 약 0.13㎜) | 고른 회색(같은 잉크 양) | 점이 픽셀보다 커서 남음 → 대비 강화 뒤 **더 어두움** |

사람 눈은 시력 한계(약 0.09㎜) 아래의 점을 평균 내어 보므로 두 무늬가 같은 회색이다. 카메라는 ① 픽셀로 나눠 담고 ② 문서 사진에 대비를 세게 걸고 ③ 8비트로 자른다. 이 **비선형 단계**에서 두 무늬의 평균 밝기가 달라져, 표시 무늬로 찍은 칸만 사진에서 어둡게 드러난다.

## 3. 양자화 적용 — 카메라와 AI가 거치는 세 번의 양자화

| 단계 | 양자화 | 보안 무늬에서 쓰는 법 |
|---|---|---|
| ① 카메라 픽셀 | **공간 양자화**: 종이를 픽셀 격자로 나눔(A4를 가득 찍으면 1픽셀 ≈ 인쇄 2~3px) | 바탕 점은 픽셀보다 작게(사라짐), 표시 점은 픽셀보다 크게(남음) |
| ② 밝기 처리 | **밝기 양자화**: 대비 강화 + 0~255 정수로 자름 | 고른 회색은 밝은 쪽으로 잘리고, 큰 점의 검정은 0에 남음 → 평균 차이 발생 |
| ③ AI 입력 | **입력 축소**: AI는 사진을 줄여 받음 | 표시 칸을 크게(48px 이상) 해 줄인 뒤에도 칸 단위 밝기 차이가 남게 함 |

계산 모형 결과(`test_paper_mark.py`, 실제 휴대폰 아님):

| 조건 | 결과 |
|---|---|
| 사람 눈 모형 | 두 무늬 평균 밝기 차이 0 → 좌석 코드 **읽히지 않음** |
| 가까이 찍은 사진(픽셀 = 인쇄 2px) | 표시 칸이 약 0.1~0.15 더 어두움. 3줄로 어긋나게 인쇄하면 **격자 어긋남과 상관없이 좌석 번호를 읽음** |
| 그 사진을 AI가 4배 줄여 받은 입력 | 여전히 읽힘 |
| 멀리서 찍은 사진(픽셀 = 인쇄 3px) | 격자 어긋남에 따라 **드러나기도 사라지기도 함**(믿을 수 없음) |
| 표시 점을 4×4/8칸으로 키우면 | 멀리서도 더 잘 드러나지만, 사람 눈 모형에서 **무늬 결이 더 보임**(트레이드오프) |

부정행위로 문제를 찍을 때는 글자를 읽으려고 가까이 찍으므로, 가까운 사진에서 읽히는 것이 먼저다. 실제 휴대폰은 렌즈 흐림·노이즈 제거·선명화·JPEG 압축·기울기가 더해져 이 모형과 다르다. **실측 전에는 동작한다고 쓰지 않는다**(7장).

## 4. 좌석 코드 형식

- 14칸 띠: `[1] + 좌석 번호 10비트(0~1023) + 검사 2비트(1의 개수 mod 4) + [0]`. 앞뒤 고정 칸 덕에 좌석 0번도 읽힌다.
- 칸 하나 = 48px(약 1㎜). 띠 높이 약 1㎜, 길이 약 14㎜. 같은 띠를 **3줄, 줄마다 무늬 시작점을 0·1·2px 어긋나게** 인쇄하고, 읽을 때 가장 많이 나온 번호를 쓴다.
- 자리: 시험지 여백·머리말 아래처럼 글자가 없는 곳. 사람 눈에는 옅은 회색 띠로 보인다(잉크 25%).
- 검사 비트가 안 맞으면 "읽지 못함"으로 둔다. 잘못 읽은 번호로 사람을 지목하지 않기 위해서다.

## 5. 다이내믹 덴서티 적용 — 무늬를 어디에 얼마나 넣나

무늬를 시험지 전체에 깔면 인쇄가 탁해지고 읽기 불편해진다. 영역마다 D를 계산해 **면적 예산 안에서 D가 높은 곳부터** 넣는다(`allocate_marks`).

```
D = I · (dΨ/dt + 0.1) ÷ (V + ε)
  I     : 그 영역이 정답 결정에 주는 정보량(보기·핵심 문장 ↑, 머리말 ↓)
  dΨ/dt : 그 문항 유형을 AI가 최근 더 잘 푸는 정도(F2R 출제 평가에서 AI 정답률 증가량)
  V     : 사람이 읽는 데 주는 부담(글자가 빽빽할수록 ↑)
```

- 좌석 코드 띠(목표 A)는 D와 상관없이 여백에 늘 넣는다.
- 교란용 무늬(목표 B, 측정 후 결정)는 D 순으로 배정한다. **본문 글자 바로 위(V ≥ 1)는 D가 아무리 높아도 넣지 않는다.** 수험생의 읽기를 해치지 않는 것이 먼저다.
- dΨ/dt는 이미 운영 중인 출제 D의 재료(유형별 기출·AI 풀이 기록)를 다시 쓴다.

## 6. 차원연산 적용 — 교란 효과를 숫자로 잰다

AI는 사진을 작은 조각으로 나눠 각 조각을 수백~수천 차원의 숫자 줄(임베딩)로 바꾼 뒤 읽는다. 그래서 교란 효과를 **임베딩 공간의 거리**로 잴 수 있다.

1. 같은 시험지를 무늬 없이 / 무늬 넣고 인쇄해 같은 휴대폰으로 찍는다.
2. 학원 PC의 공개 영상 임베딩 모델(오픈 모델, 상업 이용 가능 라이선스)로 두 사진의 숫자 줄을 만든다.
3. **교란도 = 1 − 코사인 유사도.** 0에 가까우면 AI에게 두 사진은 거의 같다(교란 없음).
4. 교란도가 큰 조건만 골라, 상용 AI에 문제를 풀게 해 **정답률 차이**를 잰다(문항 수와 함께 기록).

- 임베딩 차원은 768~1,024로 시작한다([../f2r-llm/DYNAMIC_DENSITY.md](../f2r-llm/DYNAMIC_DENSITY.md) 5장, 차원·양자화 개념도).
- 이 측정은 학원 PC에서만 하고 사진은 측정이 끝나면 지운다. 학생이 찍힌 사진은 쓰지 않는다.
- 공개 모델에서 교란도가 커도 상용 AI 정답률이 그대로면 **효과 없음**으로 기록한다.

## 7. 시험 계획 (요약, 상세는 [TEST_PLAN.md](TEST_PLAN.md) 4-4)

1. 보안 무늬 견본 A4를 학원 레이저 프린터(600·1200dpi)로 인쇄한다. 잉크젯도 한 장.
2. **눈 시험:** 직원 3명이 30㎝에서 무늬 띠가 보이는지, 본문 읽기가 불편한지 적는다.
3. **추적 시험:** 휴대폰 2종으로 15·25·40㎝, 정면·15°에서 각 10장 찍어 좌석 번호가 읽히는 비율을 적는다.
4. **복사 시험:** 복사기로 복사한 시험지에서도 읽히는지 본다(복사본 유출 추적).
5. **교란 시험(목표 B):** 6장 방식으로 교란도와 AI 정답률 차이를 잰다.

## 8. 공정성·개인정보

- 수험생에게 **"시험지에 좌석 식별 표시가 인쇄되어 있다"고 미리 알린다**(결정 D13 제안). 숨은 감시보다 알리는 쪽이 억지 효과도 크고 신뢰도 지킨다.
- 좌석 코드는 좌석 번호만 담는다. 이름·학번은 넣지 않는다. 좌석 ↔ 수험생 대응표는 시험 관리자가 따로 보관한다.
- 코드가 읽혔다는 것만으로 처벌하지 않는다. "어느 시험지의 사진인지"를 알려 주는 단서이고, 확인·처리는 감독 절차가 맡는다.
- 저시력 수험생(확대경 사용)에게 무늬가 거슬리는지 시험 전에 확인하고, 필요하면 무늬 없는 시험지를 준다.

## 9. 못 하는 것과 쓰지 않는 표현

- **AI를 확실히 속인다**고 쓰지 않는다. 목표 B는 측정 전 가설이다.
- 멀리서 찍은 사진, 화면을 다시 찍은 사진, 손으로 옮겨 적은 문제는 추적하지 못한다.
- 인쇄 품질(토너 상태·용지)에 따라 무늬가 달라진다. 시험마다 견본 한 장을 찍어 읽히는지 확인한다.
- 사람이 읽는 글자 위에 무늬를 겹치지 않는다(5장).
