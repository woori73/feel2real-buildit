# F2R 시험 보안 검사대 — 사업계획서 반영안 (다이내믹 덴서티 적용)

작성일: 2026-11-20 · 대상: 1R 사업계획서 Q2 「시험 부정행위 방지 기능 개발」, Q4 「2단계 계획」([BRIEF.md](BRIEF.md))

> 사업계획서에 그대로 옮겨 쓸 수 있게 쓴 문안이다. **숫자는 출처가 있는 것만 넣었다.** F2R 성능 수치는 아직 측정 전이라 칸을 비워 두었고, [TEST_PLAN.md](TEST_PLAN.md) 측정 뒤에만 채운다.

## 1. 사업계획서용 한 문단

F2R 시험 보안 검사대는 학원·학교가 이미 가진 **휴대폰 한 대**로 시험장의 숨은 카메라 렌즈를 찾아 감독관에게 '확인 필요' 자리만 알려 주는 도구입니다. 휴대폰 플래시를 끄고 켜며 렌즈에서만 되돌아오는 빛을 찾고, F2R이 문제 출제에 쓰는 **다이내믹 덴서티(동태밀도) 원칙을 검사에도 그대로 적용**해 화면 전체는 가볍게 훑은 뒤 의심도가 높은 자리에만 정밀 분석을 집중합니다. 판정과 처리는 감독관이 하고, 사진·영상은 저장하거나 전송하지 않습니다.

## 2. 문제 (Q2 배경)

- AI 부정행위는 **찍음 → 보냄 → AI가 풂 → 받음** 순서로 일어나며, 그 시작은 숨긴 카메라 렌즈다.
- 2026년 11월 19일 수능에서 98명이 적발되었고, 그중 스마트기기를 실제로 쓴 경우가 5건이다(교육부, [BRIEF.md](BRIEF.md) 1장).
- 정부 전파 탐지기는 수능·국가시험에 먼저 들어가므로 **대학별 논술·면접, 학교 내신·수행평가, 학원 시험**이 비어 있는 시장이다. 중·고등학교 5,699곳, 고등교육기관 416곳(2026 교육기본통계).
- 비행모드 AI·유선 카메라처럼 **전파를 내지 않는 방식**이 늘어 전파 탐지만으로는 막을 수 없다([LIMITS.md](LIMITS.md) L17·L18).

## 4. 핵심 기술: 다이내믹 덴서티를 검사에 적용

F2R 다이내믹 덴서티는 **"중요한 곳에 자원을 몰아준다"**는 원칙이다. 문제 출제에서는 기출 비중이 크고 최근 늘어난 항목에 문항을 더 배정한다. 같은 식을 렌즈 찾기에 옮겼다.

```
D = I · dΨ/dt ÷ (V + ε)
  I     : 플래시를 켰을 때와 껐을 때의 밝기 차이
  dΨ/dt : 여러 번 깜빡이는 동안 같은 자리에서 다시 나타난 비율
  V     : 반사된 면의 넓이(넓게 번쩍이는 면은 렌즈가 아닐 가능성이 큼)
```

1. **1단계(전체를 가볍게):** 화면 전체를 줄여서 빠르게 훑는다. 멀리 있는 작은 렌즈를 놓치지 않도록 기준을 낮춘다.
2. **D 배정:** 후보마다 D를 계산해 높은 순으로 최대 5곳만 고른다.
3. **2단계(의심 자리만 정밀하게):** 고른 자리만 카메라 원본 해상도로 다시 확인하고, 엄격한 기준을 두 번 모두 넘은 곳만 '확인 필요'로 올린다.

기대 효과(**측정 전 가설**):
- 멀리 있어 작게 찍힌 렌즈를 덜 놓친다. 합성 이미지 시험에서 1단계만으로는 놓친 2×2픽셀 렌즈를 2단계에서 찾았다(단위 테스트).
- 반짝이 장식처럼 한 번만 번쩍인 후보를 걸러 잘못 알리는 경우를 줄인다.
- 화면 전체를 고해상도로 분석하지 않아 휴대폰에서도 빠르다.

차별점으로 쓸 때의 표현:
- "거칠게 훑고 의심 자리만 자세히 보기"는 영상 처리에서 널리 쓰이는 방식이다. **F2R의 차별점은 출제와 검사에 같은 D 원칙을 일관되게 적용한 자체 플랫폼**이라는 점이다. 원리 자체가 새롭다고 쓰지 않는다.
- 비슷한 생각의 연구 사례: DD-GNG(IROS 2019, 의심 물체 주변의 위상 구조 밀도를 높여 사다리를 실시간 검출). 참고 사례로만 인용한다.

## 4-1. 플랫폼 전체로 확장 (LLM·서버·전송 경량화)

같은 다이내믹 덴서티 원칙을 F2R 플랫폼 전체의 자원 배정에 쓴다([../f2r-llm/DYNAMIC_DENSITY.md](../f2r-llm/DYNAMIC_DENSITY.md) 5장).

| 적용처 | D가 높은 곳에 먼저 쓰는 자원 | 상태 |
|---|---|---|
| 문제 출제 | 문항 수 | 운영 중(출제 원칙 6번) |
| 시험 보안 렌즈 찾기 | 원본 해상도 정밀 분석 | 운영 배포 |
| 자체 LLM 근거 배정 | 프롬프트 토큰(컨텍스트 경량화) | 구현·단위 시험 통과, 검색 연결 전 |
| 연산 분담(기기·학원 PC·클라우드) | GPU·상용 AI 요금 | 설계 |
| 자료 전송·저장(자료 물류) | 네트워크·저장 비용 | 설계 |

사업계획서 문장(예): "F2R은 출제·검사·AI 연산·자료 전송에 같은 다이내믹 덴서티 원칙을 적용해, 한정된 토큰·연산·전송 자원을 정보 가치가 높은 곳에 먼저 배정합니다. 각 적용처의 절감 효과는 사용/미사용 비교 측정으로 검증합니다." 절감률 수치는 측정 뒤에만 넣는다.

## 8. 위험과 대응

- **못 잡는 경우:** 옷 속 기기, 렌즈를 가린 카메라, 비행모드 AI는 검사대로 못 잡는다. 기기 제출·순회 검사 절차와 한 묶음으로 제안한다([LIMITS.md](LIMITS.md)).
- **잘못 알리는 경우:** 반짝이 장식·눈동자 반사. 2단계 정밀 확인과 감독관 확인으로 줄인다.
- **법률:** 운영 전 개인정보보호법·통신비밀보호법·전파법 자문(결정 D9).
- **아이폰:** 웹에서 플래시 조절이 안 되어 1차는 안드로이드만 지원(결정 D2).

## 9. 사업계획서에 쓰지 않는 표현

- '완벽 차단', '100% 적발', 측정하지 않은 탐지율.
- 다른 연구의 수치(KAIST 94%, 듀크대 80% 등)를 F2R 성능처럼 쓰는 것. 쓸 때는 "같은 원리의 다른 연구"로 출처와 함께 쓴다.
- 다이내믹 덴서티 2단계 방식 자체를 신규 발명·특허로 주장하는 것([../f2r-llm/PLAN.md](../f2r-llm/PLAN.md) 2장 7번과 같은 원칙).
- 시험지 함정 문구, 숨은 잉크로 AI를 속이는 방법을 대책으로 쓰는 것. 조사 결과 사진으로 찍은 종이 시험지에는 확실한 방법이 없다([LIMITS.md](LIMITS.md) L20).
