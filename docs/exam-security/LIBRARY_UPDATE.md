# 부정행위 방지 기술 자료 페이지 정기 갱신 절차

공개 페이지: `https://feel2real.co.kr/exam-security` (2026-11-21 사용자 지시: "논문·기사 등을 페이지로 만들어 올리고 정기적으로 업데이트")
데이터: `src/main/resources/content/exam-security/library.json` 한 파일. 화면(`templates/public/exam_security.html`)과 코드는 건드리지 않는다.
조사 원본: [RESEARCH.md](RESEARCH.md)(출처·검증 메모).

## 주기
- 매주 1회 정기 작업(Claude Code 예약 작업)이 새 자료를 찾아 **PR만 올린다**. 병합·배포는 원장님 승인 뒤에만 한다.
- 새 자료가 없으면 PR을 만들지 않고 "변경 없음"으로 끝낸다.

## 찾는 것
1. 렌즈 찾기: 숨은 카메라·스마트안경 렌즈 탐지(빛 반사·휴대폰 센서) 논문·기술 문서·제품.
2. 종이 무늬·AI 방해: 인쇄·촬영에 견디는 워터마크, 보안 인쇄, 사진 속 문서를 AI가 읽는 것을 막거나 추적하는 연구, 숨은 지시문 실험.
3. 언론 보도: 시험 AI 부정행위(스마트기기·스마트안경·카메라) 사례와 대응, F2R 관련 보도.

## 넣는 규칙(사실만)
- 항목마다 `kind`(논문/기술 문서/제품/기사/F2R), `title`, `by`(저자·기관·매체), `date`, `summary`(쉬운 말 1~2문장), `result`(그 연구·기사가 밝힌 내용, 수치는 조건과 함께), `url`(직접 열어 확인한 주소).
- `checked`: 원문(논문 초록·기사·영상 정보)을 직접 열었으면 `"원문"`, 검색 결과 요약으로만 확인했으면 `"검색"`. 화면은 원문 확인 항목에 표시를 붙이고, 나머지는 원문 링크에서 확인하라고 안내한다.
- 출처 주소가 없거나 저자·매체·날짜가 불분명한 자료, 검색 요약끼리 서로 어긋나는 숫자는 넣지 않는다.
- 다른 연구의 수치는 `result`에만, "그 연구의 결과"로 쓴다. F2R 성능처럼 쓰지 않는다.
- F2R 성능 수치(탐지율 등)는 F2R이 직접 잰 값이 생기기 전까지 넣지 않는다.
- 과장 표현(혁신·최고·완벽 차단) 금지. 학생 이름·얼굴 사진 금지.
- `updatedAt`을 갱신일로 바꾼다. 항목은 섹션 안에서 최신이 위.
