# F2R 시험 보안 검사대 설계 지시서

> 원문 그대로 보관(2026-11-20 사용자 전달). 설계 결과물은 같은 폴더의 [README.md](README.md)에서 시작한다.

- 작성일: 2026-11-20
- 지시자: 남현석(F2R)
- 받는 사람: 코드(Claude Code 세션)
- 관련 문서: 1R 사업계획서 Q2 '시험 부정행위 방지 기능 개발', Q4 2단계 계획

## 0. 이 지시서로 할 일 (한 줄)

시험장 입구와 시험 중에 **숨긴 카메라·스마트안경·무선 기기를 찾아 감독관에게 알려 주는 'F2R 시험 보안 검사대'**를 설계한다. 이번에는 설계와 시제품 계획까지만 하고, 부품 구매·운영 배포는 하지 않는다.

## 1. 왜 만드는가 (배경)

AI 부정행위는 찍음 → 보냄 → AI가 풂 → 받음 순서로 이루어진다.

| 단계 | 실제로 확인된 장비·방식 |
|---|---|
| 찍음 | 셔츠 단추형 초소형 카메라, 볼펜형 카메라, 8㎜ 핀홀 카메라, 스마트안경 |
| 보냄 | 몸에 숨긴 스마트폰, 4G LTE 라우터, 블루투스 |
| 풂 | 생성형 AI (경희대 시범: 지문을 찍어 넣으면 10초 안에 답이 나옴) |
| 받음 | 쌀알 이어폰, 초소형 모니터, 개조한 계산기 |

최근 사례는 다음과 같다.

- 2026년 11월 19일 수능에서 98명이 적발되었다. 그중 스마트기기를 실제로 쓴 경우가 5건이고, 와이파이 신호 탐지로 잡힌 경우가 2건이다(교육부).
- 세무사 시험 수석 합격자가 초소형 카메라와 AI로 답을 받았다고 자수했다. 감독관 2명과 사후 점검 모두 잡지 못했다.
- 연세대·서울시립대 논술에서 스마트안경 부정행위가 적발되었다. 대학들은 앞치마(경희대 3만 5천 개), 가운(서울대), 단추 스티커(동국대), 귀 노출(숙명여대)처럼 사람 손으로 대응하고 있다.

시장 규모는 다음과 같다.

- 중·고등학교 5,699곳, 고등교육기관 416곳(2026 교육기본통계)
- 수능 시험장 1,312곳
- 국가기술자격 연 응시 392만 건(2025)

정부 전파 탐지기는 수능과 국가시험에 먼저 들어간다. 그래서 대학별 논술·면접과 학교 내신·수행평가가 비어 있는 시장이다.

## 2. 지금 나와 있는 탐지 방식과 한계 (설계 참고)

| 방식 | 공개된 사례·성능 | 한계 |
|---|---|---|
| 전파 탐지(BLE·와이파이) | 수능에서 와이파이로 2명 적발. 정부가 스마트안경용 이동형 탐지기 발주 | 기기 안에서 AI를 돌리거나 신호가 없는 기기는 못 잡음. 신호가 잡혀도 부정행위인지는 확정 못 함 |
| 렌즈 빛 반사(광학) | KAIST의 스마트폰 부착 LED 장치가 숨은 카메라 94% 식별(부품비 약 7달러). 같은 방식 연구 88.9%(눈으로는 46%) | 스마트안경은 반사가 약하고 들쭉날쭉하다는 공개 실험(banrays)이 있음 |
| AI 영상 외형 판별 | 듀크대가 스마트안경 80% 식별. 그렙 '모니토'가 안경 사진 대조 기능을 도입 | 알려진 모양에 의존해 새 기기는 놓침 |
| 행동 분석 | 중국 대입 시험(가오카오)의 AI 감시 영상 | 정상 행동을 오인할 수 있음 |
| 신호 차단기(재머) | 인도 의대 입시 5만 1,311대 | 국내 전파법상 금지 — 설계에 넣지 않는다 |
| 열화상·금속 탐지 | — | 소형 기기는 체온·안경과 구별이 어렵고 오탐이 많음 |

결론은 하나다. 한 가지 방식으로는 못 막는다. 광학, 영상, 전파를 묶고, 최종 판단은 사람이 한다.

## 3. 만들 물건: F2R 시험 보안 검사대

### 3-1. 구성 (1.5단계 휴대폰 도크를 그대로 활용)

| 부분 | 역할 | 설계 방향 |
|---|---|---|
| 휴대폰(눈·두뇌 연결) | 촬영, 플래시, 블루투스·와이파이 검색, F2R 서버 연결 | 원장이 쓰는 휴대폰을 그대로 씀. 특정 모델에 묶지 않음 |
| 2축 도크(고개) | 휴대폰을 좌우·위아래로 돌려 수험생의 안경·단추·펜·귀를 차례로 비춤 | 서보 2개, 블루투스 제어 보드. 기존 1.5단계 설계를 재사용 |
| 광학 모듈(선택) | 적외선(850·940nm) 또는 가시광 LED를 깜빡이며 렌즈 반사를 찾음 | 휴대폰 플래시만으로 되는지 먼저 시험하고, 부족할 때만 LED 모듈을 추가 |
| 검사 받침(물품용) | 필기구·시계·안경·계산기를 올려 두고 빛을 비춰 렌즈를 찾음 | 계획서 2단계의 '검사대 물품에 빛을 비춰 렌즈 반사를 찾는 기능' |
| F2R 서버·화면 | 결과 기록, 감독관 화면, 시험장별 기록 | 기존 F2R 서버(AWS)와 휴대폰 웹앱(PWA)을 재사용 |

### 3-2. 검사 흐름

1. 입장 검사(약 10초 목표): 수험생이 검사대 앞에 서면 도크가 안경, 단추, 귀, 손목 순서로 돌며 촬영한다. 이때 플래시를 깜빡여 렌즈 반사를 찾고, AI 영상으로 스마트안경 모양을 대조한다.
2. 물품 검사: 필기구, 계산기, 시계, 안경을 받침에 올려 렌즈 반사를 찾는다.
3. 무선 검색: 검사하는 동안 블루투스 광고 신호와 주변 와이파이를 검색한다. 알려진 스마트안경 제조사 신호가 잡히면 표시한다.
4. 시험 중(선택): 휴대폰을 교실 앞에 두고 무선 신호의 변화를 기록한다. 행동 분석은 이번 설계에서는 '검토'로만 둔다.
5. 결과: '의심 없음 / 확인 필요'만 감독관 화면에 띄운다. 부정행위라고 판정하지 않는다. 감독관이 확인하고 처리한다.

### 3-3. 반드시 지킬 원칙

- 재머(신호 차단)는 쓰지 않는다. 국내 전파법 위반이다.
- 판정은 사람이 한다. 기계는 '확인 필요'만 알린다.
- 개인정보: 얼굴 영상은 저장하지 않는 것이 기본이다. '확인 필요' 장면만 감독관이 확인하는 동안 잠시 보관하고, 보관 기간과 삭제 방식을 설계서에 적는다. 수험생 실명은 서버에 보내지 않는다.
- 성능 표기: 다른 연구의 94%·88.9%·80%를 F2R 성능처럼 쓰지 않는다. F2R 성능은 직접 만든 시험 세트로 잰 값만 쓴다.
- 문구: 과장 표현을 쓰지 않는다('완벽 차단', '100% 적발' 금지).

## 4. 이번에 낼 결과물

- 설계서(md): 구성도, 검사 흐름, 화면 흐름, 서버 데이터 구조(F2R 기존 구조 재사용 방식), 개인정보 처리 방식
- 부품표(BOM): 부품명, 사양, 구입처 후보, 2026년 11월 가격, 수량, 합계. 휴대폰은 보유품이라 0원. 1차 시제품 총액 목표는 50만원 이하
- 시험 계획서: 아래 5장 기준
- 위험과 한계 목록: 못 잡는 경우(신호 없는 기기, 기기 안에서 도는 AI, 몸 안쪽에 숨긴 기기 등)를 솔직하게 적음
- 휴대폰 쪽 최소 시연 코드(선택): 플래시 깜빡임 + 카메라 촬영으로 렌즈 반사 후보를 표시하는 웹앱 화면. 기존 F2R 웹앱 안의 새 화면으로, 운영 배포 전 승인 필요

## 5. 성능 시험 방법 (직접 재기)

- 시험 세트: 일반 안경 10개, 시판 스마트안경 사진·영상(구매 전에는 공개 자료로), 단추형·볼펜형 카메라 견본(구매 시 승인), 카메라 없는 일반 단추·볼펜 각 10개
- 조건: 밝은 교실, 어두운 교실, 거리 30·60·100㎝
- 기록 항목: 찾아낸 비율, 잘못 알린 비율(일반 물건을 의심으로 표시), 한 명 검사 시간
- 완료 기준(1차 목표): 한 명 검사 30초 이내, 잘못 알린 비율 기록. 목표 탐지율은 첫 측정 후 정한다.

| 시기 | 할 일 |
|---|---|
| 1주 | 설계서·부품표·시험 계획서 작성, 휴대폰 플래시만으로 렌즈 반사가 보이는지 확인 |
| 2주 | 휴대폰 웹앱 최소 시연 화면, 블루투스 검색 시험 |
| 3~4주 | 도크 결합(1.5단계 부품 재사용), 교습소에서 직원·자원자 대상 시험 |
| 다음 라운드 | 대학 논술·면접 시범 제안용 자료, 외부 보안 점검 |

## 7. 작업 방식

- 평소 규칙대로 설계·코드·테스트·문서 작업은 끝까지 진행하고 마지막에 한 번 보고한다(완료 작업 · 시험 결과 · PR/배포 상태 · 남은 문제와 필요한 결정).
- 먼저 물어볼 것(한 번에 모아서): 부품·견본 구매, 유료 크레딧 사용, 운영 배포, AWS 자원 추가, 개인정보가 들어가는 촬영 시험
- 도구·보안 권한 요청을 우회하지 않는다.
- 결과물은 F2R 저장소의 문서 폴더(예: docs/exam-security/)에 PR로 올리고, 이 지시서도 같은 폴더에 BRIEF.md로 함께 둔다.
