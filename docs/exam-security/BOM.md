# F2R 시험 보안 검사대 — 1차 시제품 부품표 (BOM)

> **가격은 2026년 11월 구매 전 추정값이다.** 이 세션에서는 쇼핑몰 가격을 직접 조회하지 못했다. 국내 부품몰 평소 가격대로 적었고, **실제 구매 전에 견적을 다시 확인**한다. 구매는 승인 뒤에만 한다([README.md](README.md) 결정 D6).
> 목표: 1차 시제품 총액 50만원 이하. 휴대폰은 보유품이라 0원으로 잡는다.
> 원칙: 시판 탐지 장비(금속 탐지기·전파 탐지기·열화상·몰래카메라 탐지기)는 사지 않는다. 여기 적은 것은 F2R 검사대를 직접 만드는 부품과 성능을 재는 시험용 물건뿐이다([README.md](README.md) 원칙).

- 22 스마트안경은 40만원대 이상이라 1차 예산에 넣지 않았다. 사면 광학·BLE 시험의 신뢰도가 크게 오른다([결정 D6](README.md#결정-필요)).
