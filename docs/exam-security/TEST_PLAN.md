# F2R 시험 보안 검사대 — 성능 시험 계획서

> 원칙: **F2R 성능은 이 계획으로 직접 잰 값만 쓴다.** 다른 연구의 94%·88.9%·80%는 비교 참고로만 적고, F2R 성능처럼 쓰지 않는다. 결과 문구에 '완벽 차단', '100% 적발'은 쓰지 않는다.

## 1. 무엇을 재나

| 항목 | 뜻 | 계산 |
|---|---|---|
| 찾아낸 비율 | 카메라가 있는 물건을 '확인 필요'로 올린 비율 | 확인 필요로 올린 카메라 물건 시도 ÷ 카메라 물건 전체 시도 |
| 잘못 알린 비율 | 카메라 없는 물건을 '확인 필요'로 올린 비율 | 확인 필요로 올린 일반 물건 시도 ÷ 일반 물건 전체 시도 |
| 한 명 검사 시간 | 좌석 입력부터 결과 표시까지 | 화면이 기록한 `duration_ms` 중앙값·최댓값 |
| 위치 맞음 | 표시한 원이 실제 렌즈 자리에 있는지 | 맞음 ÷ 확인 필요로 올린 카메라 물건 시도 |

- 모든 비율은 **시도 수와 함께** 적는다(예: "12/15, 80%"). 시도가 30회 미만이면 비율보다 숫자 그대로를 앞에 쓴다.
- 결과표에는 조건(밝기·거리·물건)을 반드시 붙인다. 조건 없이 "탐지율 n%"만 쓰지 않는다.

## 2. 시험 세트

| 묶음 | 물건 | 개수 | 비고 |
|---|---|---|---|
| A. 카메라 있음 | 단추형 카메라, 볼펜형 카메라, 8㎜ 핀홀 모듈 | 각 1 | **구매 승인 필요**(BOM 19~21). 전원을 켠 상태·끈 상태 둘 다 |
| B. 카메라 없음 | 일반 단추 10, 일반 볼펜 10, 일반 안경 10 | 30 | 잘못 알린 비율용 |
| C. 스마트안경 | 공개 사진·영상(제품 홍보 영상, 리뷰 사진) | 10장 이상 | 구매 전에는 화면에 띄워 모양 대조만 시험. 광학·BLE는 실물이 있어야 잴 수 있음 |
| D. 방해물 | 금속 시계, 반짝이 단추, 휴대폰 화면, 안경 렌즈 코팅 | 각 1 | 반사가 비슷해 헷갈리는 물건 |

A의 견본 1개씩은 개수가 적다. 같은 물건을 **위치·각도를 바꿔 10회씩** 시도해 시도 수를 늘린다. 그래도 "견본 1개 기준"임을 결과에 적는다.

## 3. 조건

| 조건 | 값 |
|---|---|
| 밝기 | 밝은 교실(형광등 전부 켬, 약 500lx 안팎) / 어두운 교실(창 가리고 전등 절반, 약 100lx 안팎). 휴대폰 조도 앱으로 잰 값을 기록 |
| 거리 | 30㎝ · 60㎝ · 100㎝ (휴대폰 렌즈~물건, 줄자로 측정) |
| 각도 | 정면, 좌우 15°, 좌우 30° |
| 광원 | 휴대폰 플래시만 / (선택) LED 링 추가 |
| 휴대폰 | 원장 휴대폰 1대(기종·크롬 버전 기록). 가능하면 다른 안드로이드 1대 추가 |

## 4. 절차

### 4-1. 1주차 — 플래시만으로 반사가 보이는지 (물건만, 사람 없음)

1. 시연 화면 `/easy/exam-security/lens`를 원장 휴대폰 크롬으로 연다(ADMIN 로그인).
2. **플래시 조절 확인:** [카메라 켜기]를 눌러 "준비됐습니다"가 나오는지 본다. 안 나오면 기종·브라우저를 적고 중단한다.
3. 무광 검정판 위에 물건 1개를 올리고, 거리·밝기·각도 조건마다 [렌즈 찾기]를 10번 누른다.
4. 매번 '의심 없음/확인 필요', 원 위치가 맞았는지, 걸린 시간을 기록표에 적는다.
5. A·B·D 묶음을 모두 돈다. A 견본이 아직 없으면 **B·D로 잘못 알린 비율만 먼저** 잰다.
6. 기준값(밝기 차이 60, 켠 밝기 200, 면적 0.2%)이 맞지 않으면 바꿔 다시 잰다. 바꾼 값과 이유를 적는다.

### 4-2. 2주차 — 블루투스·와이파이 (보드 구매 후)

1. 보드 펌웨어로 빈 교실 기준(30초)을 잰다.
2. 직원 휴대폰 핫스팟을 켰다 끄며 "새 와이파이"가 몇 초 안에 잡히는지 10회 잰다.
3. 스마트안경 실물이 있으면 전원 켜기·페어링·쓰는 중 세 상태에서 제조사 신호가 잡히는지 각 10회 잰다. 실물이 없으면 **"미측정"으로 남긴다.** 다른 연구 값으로 채우지 않는다.

### 4-3. 3~4주차 — 도크 결합, 사람 대상 (촬영 시험 승인 후)

- 대상: 교습소 직원·성인 자원자만. **학생·미성년자는 이번 시험에서 제외**한다.
- 서면 동의를 받는다(촬영 목적, 영상 저장 안 함, 결과 문장만 보관).
- 견본 카메라는 자원자가 셔츠 단추 자리·주머니에 달고, 일반 단추·볼펜과 섞어 무작위로 바꾼다. 검사하는 사람은 어느 쪽인지 모르게 한다.
- 5자세 입장 검사를 1인당 5회 반복하고, 한 명 검사 시간을 잰다.

## 5. 기록표 (예시)

| 회차 | 날짜 | 휴대폰·크롬 | 물건 | 카메라 유무 | 밝기(lx) | 거리 | 각도 | 광원 | 결과 | 위치 맞음 | 시간(초) | 메모 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 11-2x | ○○ / 13x | 볼펜형 카메라 | 있음 | 480 | 60㎝ | 정면 | 플래시 | 확인 필요 | 예 | 3.1 | |
| 2 | 11-2x | ○○ / 13x | 일반 볼펜 #3 | 없음 | 480 | 60㎝ | 정면 | 플래시 | 의심 없음 | — | 3.0 | |

결과 요약은 조건별 표로 낸다(밝기 × 거리 × 물건 묶음). 각 칸에 "맞힌 수/시도 수"를 적는다.

## 6. 완료 기준 (1차 목표)

| 기준 | 목표 |
|---|---|
| 한 명 검사 시간 | **30초 이내**(설계 목표 10초) |
| 잘못 알린 비율 | **기록 완료**(목표값은 첫 측정 뒤 정함) |
| 찾아낸 비율 | 조건별로 **기록 완료**. 목표 탐지율은 첫 측정 뒤 원장님과 정함 |
| 보고서 | 조건별 표 + 못 잡은 경우의 사진 없는 설명 + 기준값 변경 이력 |
