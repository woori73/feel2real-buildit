# F2R 시험 보안 검사대 (설계 단계)

시험장 입구와 시험 중에 숨긴 카메라·스마트안경·무선 기기를 찾아 **감독관에게 '확인 필요'만 알려 주는** 도구의 설계 묶음이다. 판정과 처리는 감독관이 한다.

> **원칙: 검사대에는 F2R이 직접 만드는 기능만 넣는다.** 시판 금속 탐지기·전파 탐지기·열화상·몰래카메라 탐지기처럼 이미 있는 장비는 넣지 않는다. 보드·서보·LED는 검사대를 만드는 부품으로만 쓴다. 기존 장비로만 막을 수 있는 경우는 한계 목록과 운영 절차에 적는다.

## 이번에 만든 시연 화면

- 주소: `/easy/exam-security/lens` (ADMIN 로그인 전용, 원장 휴대폰 크롬). 원장 휴대폰 앱 첫 화면(`/easy/app`)의 「렌즈 찾기」 타일로 들어간다.
- 하는 일: 휴대폰 플래시를 끔·켬 3번 바꿔 찍고, 켰을 때만 작게 빛나는 점에 원을 그린다. 결과는 '의심 없음 / 확인 필요'만 표시한다.
- 저장·전송 없음: 사진·영상을 서버로 보내지 않고 휴대폰에도 저장하지 않는다(테스트로 확인).
- 파일:
  - `src/main/resources/templates/easy/exam_security_lens.html`
  - `src/main/resources/static/js/exam_security_lens.js`
  - `src/test/js/exam_security_lens.test.js`
- 운영 배포는 승인(결정 D3)을 받아 2026-11-20에 했다(PR #1127).

## 결정 필요

지시서 7장대로 한 번에 모았다. 이 목록 전에는 아무것도 사거나 쓰거나 배포하지 않았다.

| # | 결정할 것 | 제안 |
|---|---|---|
| D1 | **1.5단계 2축 도크 실제 사양** — 저장소에서 설계 문서를 찾지 못해 일반 구성(서보 2개 + ESP32-S3)으로 적음 | 1.5단계 부품표·보드 이름을 알려 주시면 BOM과 연결 규칙을 맞춤 |
| D2 | **휴대폰 범위** — 웹에서는 안드로이드 크롬만 플래시·블루투스 연결이 됨 | 1차는 안드로이드로 확정. 아이폰은 앱 개발 때 |
| D3 | **운영 배포**(시연 화면) | 물건 대상 시연을 원장 휴대폰으로 해 보려면 배포 필요. 화면은 ADMIN 전용·저장 없음 |
| D4 | **유료 크레딧**(외부 영상 AI로 안경 대조) | 1차는 쓰지 않음(휴대폰 안 모델 + 대조 카드) |
| D5 | **검사 기록 보관 기간** | 시험 종료 후 30일 자동 삭제 |
| D6 | **부품·견본 구매**(BOM 약 37~41만원, 스마트안경은 미포함) | 본체·받침·시험 세트 먼저. 스마트안경(약 40만원 이상 추정) 구매 여부는 따로 결정 |
| D7 | **사람 촬영 시험**(3~4주차) | 직원·성인 자원자만, 서면 동의, 영상 저장 안 함. 학생 제외 |
| D8 | **AWS 자원 추가** | 필요 없음(기존 서버·DB 사용). 기록 표 2개는 구현 단계에서 마이그레이션 |
| D9 | **법률 검토** | 운영 전 개인정보보호법·통신비밀보호법·전파법 자문 |
| D10 | **운영 절차 함께 제안**(DESIGN.md 9장: 일괄 검사, 기기 제출·보관·반환, 감독관 기기 미지참, 전담자 확인, 이의 제기) | 유선 카메라·비행모드 AI는 검사대로 못 잡으므로, 학원·학교 안내 자료에 검사대와 절차를 한 묶음으로 넣기 |
| D11 | **무선 이어폰용 보드** — ESP32-S3는 최신 방식 블루투스(BLE)만 들어 일부 이어폰의 기존 방식 신호를 못 들음 | 1차는 ESP32-S3 그대로 두고 ESP32(약 1만원, BOM 25)를 함께 사서 2주차에 비교한 뒤 하나로 정하기 |
| D12 | **귀 확인(F2R 자체 기능)** — 귀 자리 확대 + 끔·켬 반사 비교 + 이어폰 대조 카드. 귓속 깊이 넣은 초소형 이어폰은 못 잡음 | 1차는 대조 카드 + 감독관 확인, 1주차 물건 시험 결과로 2차 분류 모델을 만들지 결정. 보청기 사용자는 사전 신고 |
| D13 | **종이 시험지 보안 무늬 운영 방식**([PAPER_MARK.md](PAPER_MARK.md)) — 사진에서만 드러나는 좌석 코드를 넣을지, 수험생에게 알릴지 | 견본 인쇄·촬영 시험(TEST_PLAN 4-4) 뒤 결정. 넣는다면 "좌석 식별 표시가 있다"고 미리 알리기 권장. 코드만으로 처벌하지 않음 |
