## 확인한 원인과 한계

- 사용자 제보: 운영 하단 개인정보 내용이 비어 보임. 이번 연결에는 운영 도메인 브라우저가 없어 운영 DOM/HTTP/캐시·화면을 직접 재현하지 못했다. 공백의 직접 원인은 미확정이다.
- 현재 운영 JAR은 읽기 전용 SHA-256 조회와 배포 보관 영수증 대조 결과 `38f40090e49f6cd2641865ce538aebea033546ef`에 해당한다. `10e53a7b`는 아직 운영 버전이 아니다.
- `38f40090` 공통 푸터의 `/privacy`는 내용이 있는 NewStart Chrome Agent v0.4.0 **확장 전용** 정책이다. 홈페이지 전체 정책이 아니다. 이용약관은 href 없이 `comingSoon()` 알림만 표시한다.
- 최신 main에서도 `app.home.exam-seller-confirmed=false`이면 같은 경로/알림을 사용한다. true일 때만 신청 정책으로 연결되어 탐색이 판매자 확인 여부에 종속되어 있었다. PC1440·모바일360/390/430에서 이를 로컬 재현했다.
- 최신 main의 `/exam-service/privacy`, `/exam-service/terms`는 운영 활성화 전 검토안이다. `/privacy` git 이력은 확장 정책/연락처/사업자/SEO 변경이며, 홈페이지 전체 정책 승인 원문을 찾지 못했다.
- 연결된 프로젝트 자료 검색에서도 현재 정책 승인 기록과 최신 사업자 증명서를 확보하지 못했다. 검색 범위 내 미확보이며 문서가 어디에도 없다는 뜻은 아니다.

## 보완 범위

- `/policies`는 신청·계좌 공개·판매자 확인 플래그와 무관한 공개 안내다. 개인정보, 이용·취소·환불, 사업자·문의의 범위와 미확정 항목을 명시한다. 공통 푸터를 `/policies#privacy`, `/policies#terms`로 연결한다.
- `/privacy`의 기존 주소·본문·시행일 보존. 범위 안내 링크와 누락된 문의 모달·스크립트만 추가한다.
- 기존 신청 정책 검토안의 버전·동의·환불 로직, 판매자 데이터, 계좌 설정, 2주·4회·160문항·20,000원 조건은 변경하지 않는다.
- 새 안내는 `noindex,nofollow`이며 미승인 내용을 시행 중인 정책으로 표시하지 않는다. 홈페이지 공통 정책의 최종 원문 복원 또는 법적 검토 완료로 간주할 수 없다.
