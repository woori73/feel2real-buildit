## 환불 정책 1차 법령 대조

2026-10-28 조회. [국가법령정보센터 전자상거래법 제17~19조(2026-07-21 시행)](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029561303), [시행령 제21조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0021&lsiSeq=288143&urlMode=lsScJoRltInfoR)를 확인했다.

- 청약철회 기간의 기산점은 계약 서면/공급 시점 등에 따라 달라지므로 단순히 구매 후7일로만 고정하지 않는다.
- 제공이 시작된 디지털콘텐츠와 아직 제공하지 않은 가분적 부분을 구분해야 한다. 4회 상품의 미제공분을 일괄 환불 불가로 처리하지 않는다.
- 주문 제작이라는 이유만으로 제한하지 않는다. 예외 요건, 별도 사전 고지와 동의 여부를 검토해야 한다.
- 광고/계약과 다르게 제공한 경우의 권리, 환급 기한과 청약철회 제한 고지도 별도 검토한다.

15,000원 정액 환불/5,000원 자동 공제는 적용하지 않았다. 제작 시작/일부 전달/완료/사업자 귀책별로 접수·검토할 수 있게 했고, 법률 전문가 검토와 최종 정책 승인 전 금액 승인을 차단한다. 이는 1차 자료 조사이며 법률 적합성 최종 승인 또는 모든 소비자분쟁해결기준의 검토 완료가 아니다. 개인정보/미성년자 동의·보존/삭제 정책 역시 활성화 전 확정 대상이다.

## 외부 연동 및 영상

- Muse: 사용자 설명상 개인 에이전트에 알림용 개발자 API 없음. 저장소 Muse Spark는 모델 호출용이다. 모델 호출을 알림 수신 API로 사용하지 않았다.
- Dots: 서비스 식별/공식 API 자료 미확인. 임의 연동하지 않았다.
- SMTP: 기존 JavaMailSender를 별도 opt-in으로 재사용하는 fallback. 합성 발송 대역으로 실패·재시도 검증, 실제 메일 발송 미실행.
- 20초/5컷 영상: 최종 파일 미제공. P0가 승인 영상 전환 슬롯과 오류 복귀만 준비했으며 새 영상 생성/덮어쓰기 없음.
