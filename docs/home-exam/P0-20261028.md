## 이메일

기존 홈은 Clipboard API의 비동기 거절을 처리하지 않았고 API가 없어도 “복사했습니다”를 표시했다. 390px 실제 클릭을 통한 합성 재현에서 거절 시 `NotAllowedError`와 거짓 성공 표시를 확인했다. mailto 자체의 주소와 이벤트 기본 동작은 유효했다.
새 작성 링크는 native mailto를 유지하고 별도 복사 버튼은 완료를 기다린다. 거절/미지원이면 수동 복사 안내를 한다. /exam의 “이메일 문의” 복사 전용 버튼도 작성/복사로 구분했다.
운영 브라우저의 기본 메일 앱 설정·실제 발송·팝업 정책은 확인하지 못했다. 모든 기기에서 mailto만으로 발송이 된다고 주장하지 않는다.

## 승인 자산과 홍보 영상

캐릭터 파일 및 `/agent-media/public/{seven,suni}/...` 선택 로직을 보존했다. 신규 사용자는 서수니부터 표시하며 저장된 사용자의 선택은 유지한다.
자기소개 UI 반복 문구는 제거했다. 기존 승인 인사 영상의 음성/얼굴/의상은 수정하지 않았다.
`app.home.exam-promo-path` 기본 빈 값. 승인된 `/video/landing/<영숫자-이름>.mp4`만 허용한다. 실제 서수니 idle 프레임이 표시된 다음 음소거/controls/playsinline 영상 슬롯을 한 번 재생한다. 실패·차단·종료·캐릭터 변경 시 슬롯을 닫아 기존 콘텐츠를 유지한다. 광고용 9:16 영상과 AI AGENT 드라마 자산은 별개다.
최종 20초 영상 미수령 상태에서 활성화하지 않는다. 기존 화보 PNG/WebP는 페이지 하단에 그대로 보존했다.

## 미확인/후속

공개 샘플은 개별 파일 승인 전 게시하지 않는다. 은행명·계좌·예금주도 미확인 상태라 표시하거나 임의 입금을 유도하지 않는다.
Muse는 사용자 확인상 개인 에이전트 알림 API가 없고 저장소 Muse Spark는 모델 호출이다. 알림 수신을 구현했다고 표시하지 않는다. Dots 식별/공식 연동 문서는 미확보.
운영 도메인 및 실제 캐릭터 자산의 현재 응답·운영 캐시·성능은 이 환경에서 미검증이다. 로컬 브라우저 미디어 테스트는 명시된 TEST FIXTURE만 사용한다.
P1 신청/비공개 업로드/수동 입금/수정/환불/알림은 별도 PR. 운영 DB와 저장소 활성화, 배포는 별도 승인 대상이다.
