# BUILD IT 중등 문제지 자동 조판 표준

이 폴더는 신구중2 70문항 제작에서 검증한 Chromium 기반 자동 조판 파이프라인을 중등 내신 문제지의 공통 제작 표준으로 고정하기 위한 자료다.

## 적용 원칙

앞으로 중등 문제지를 새로 제작하거나 기존 문제지를 재편집할 때, HTML에 페이지별 spacer나 고정 높이를 수작업으로 넣어 페이지를 맞추지 않는다. 문항 내용은 `units.json` 구조로 작성하고 `build_exam.js`를 실행해 최종 HTML/PDF를 생성한다.

파이프라인은 실제 Chromium에서 각 조판 단위의 렌더 높이를 측정하고, A4 2단 컬럼 예산 안에서 최대한 채운 뒤, 각 컬럼에 남은 여백을 그 컬럼 내부 문항 사이에 균등 재분배한다. 이후 overflow와 footer clearance를 다시 측정한다. 목표는 '상단에 문항이 몰리고 하단이 크게 비는 편집'과 '하단 잘림을 피하려고 문항을 지나치게 붙이는 편집'을 동시에 방지하는 것이다.

## 에듀홀릭 로고 규칙

1페이지 시험 제목에는 제공된 **EduHolic academy** 로고를 반드시 사용한다. 이 저장본은 사용자가 제공한 JPG를 `build_exam.js` 안에 data URI로 임베드해 외부 파일 경로에 의존하지 않는다.

배치는 다음과 같다.

`[EduHolic academy 로고]   [2026학년도 ... 시험 제목]`

로고는 제목의 왼쪽에 두고 제목과 수직 중앙 정렬한다. 제목 행 밖의 별도 장식 이미지로 두지 않는다. 이후 페이지의 running header에는 로고를 반복하지 않는다.

## 제작자가 지켜야 할 입력 구조

- 단일 문항: 문항 전체를 하나의 unit으로 만든다.
- 공통 지문: 공통 안내 발문 + 실제 지문 박스를 **같은 child 문자열**에 넣고, 뒤에 해당 문항들을 같은 group unit으로 묶는다.
- 공통 안내 발문은 지문 박스 밖에 있어야 하지만, 지문과 멀리 떨어지면 안 된다. 같은 child에 묶는 이유가 이것이다.
- `<보기>` 제목은 박스 상단 중앙 정렬한다.
- 밑줄은 실제 지문 속 질문 대상 단어/어구에만 적용한다.
- 발문 옆에 영어 지문/예문을 붙이지 않고 다음 줄의 독립 블록으로 둔다.
- `(A) (B)` 선택형은 선택지 위에 열 머리글을 한 번만 둔다.
- `gap:0`, 수동 `<div style="height:...">`, 페이지를 채우기 위한 spacer 등은 금지한다.
- 페이지 수를 먼저 고정하고 글자 크기를 줄여 맞추지 않는다. 가독성과 안전영역을 우선한다.

## 실행

최초 1회:

```bash
npm install
npx playwright install chromium
```

시험지 생성:

```bash
node build_exam.js my_config.json my_units.json
```

출력:

- `<outputBaseName>.html`
- `<outputBaseName>.pdf`
- 콘솔: 컬럼별 배치, qgap, overflow, footer clearance

## 자동 QA 최소 기준

- overflow 0건
- footer와 마지막 문항/선택지 겹침 0건
- 각 컬럼의 문항이 상단에만 몰리지 않고 남는 공간이 문항 사이에 균등 분배
- 공통 안내 발문과 지문 박스가 분리되지 않음
- 한 문항/공통지문 group이 컬럼 경계에서 잘리지 않음

자동 측정 PASS만으로 최종 승인하지 않는다. 생성된 PDF를 실제로 1페이지부터 마지막 페이지까지 확인하여 `<보기>`, underline, blank, 선택지 wrap, 좌우 컬럼 균형, 하단 안전영역을 시각 검수한다.

## AI/OpenCode/Claude 문제 제작 시 필수 워크플로

1. 학교별 실제 기출과 학교자료를 분석하여 문제 내용과 기출 DNA를 확정한다.
2. 문제/정답/해설을 독립 검수한다.
3. 최종 문제 내용을 `units.json`으로 변환한다.
4. 이 폴더의 `build_exam.js`로만 최종 문제지 HTML/PDF를 조판한다.
5. 자동 overflow/footer 검사를 통과시킨다.
6. 실제 PDF 전 페이지를 시각 검수한다.
7. 콘텐츠 수정으로 높이가 달라지면 수동 spacer를 넣지 말고 파이프라인을 다시 실행한다.

즉 **문제 제작과 페이지 조판을 분리**한다. AI는 문제 내용을 만들고, 최종 페이지 배치는 이 파이프라인이 담당한다.

## 파일

- `build_exam.js` — Chromium 측정/배치/검증/HTML·PDF 생성. 에듀홀릭 로고 임베드 포함.
- `style.css` — A4 2단 문제지 공통 스타일 및 로고 배치.
- `config.sample.json` — 시험 제목/학교/회차 설정 예시.
- `units.sample.json` — 신구중2 실제 형식 기반 입력 예시.
- `README.md` — 원 제작 파이프라인 설명.
- `STANDARD.md` — BUILD IT에서 앞으로 적용할 제작 표준(이 문서).

## 변경 금지 원칙

학교별 문제 내용과 기출 DNA는 달라도 조판 엔진의 기본 원칙은 임의 변경하지 않는다. 특정 문제지가 맞지 않는다고 파이프라인을 우회해 수동 spacer를 추가하지 말고, unit 구조나 실제 문항 내용의 높이를 검토한 뒤 다시 자동 조판한다. 엔진 자체를 수정할 필요가 있을 때는 기존 신구중2 샘플을 회귀 테스트하여 overflow/레이아웃이 악화되지 않는지 확인한다.
