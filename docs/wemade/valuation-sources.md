- **핵심 수치 (보고서 직접 인용)**:

  - 누적 창출 가치 3,700억 위안 초과, 2026년 400억 위안量级 전망, 향후 1,000억 위안+ 성장 잠재
  - 2025년 정품(正版) 비중 약 70%, 모바일 비중 80%+
  - 산정 근거: 공개 자료 + 게임사 재무제표 + 정품 제품 매출 DB + 3,000명+ 유저 조사 기반 모델 측산
- **한국어 번역 (핵심)**: "2025년 '传奇' IP 시장 규모는 355.5억 위안에 달했고 수년째 300억 위안 수준을 유지했다. IP 권리관계 명확화로 성취(盛趣)·킹넷 중심의 'IP 라이선스-개발-발행' 체인이 안정화되며 정품 비중이 크게 올랐다. 누적 창출 가치는 3,700억 위안을 넘었고 2026년에는 400억 위안 수준으로 신기록이 예상되며 향후 1,000억 위안 이상의 성장 잠재력이 있다."
- **한국 공시와 대조**: 위메이드 4Q25 실적에 '미르의 전설2/3 중국 라이선스 계약금' 반영 (위메이드 발표) — 중국 보고서의 "권리관계 명확화 → 정품 비중 상승" 서술과 방향 일치. 단, 위메이드의 공식 로열티율·계약 조건은 미공개이므로 보고서 수치로 위메이드 몫을 직접 산정하지 않았다 (SOTP에서는 증권사 라이선스 매출 기반 시나리오 가정만 사용).
