# r8 rev3 소품 결정 반영 및 변경 기록

## 확정 반영(사용자)
1. **의상 A 오른쪽 허벅지 파우치**: 일반 장비 파우치로 유지, 권총집 아님. 의상 A 컷 전체에 기록(`suni_equipment_note`), 프롬프트에서 `holster` 사용 안 함
2. **컷 49 회중시계**: 가슴 주머니 밖으로 사슬 끝만. **컷 50**: 주머니 속 시계 위에 놓인 손(시계 자체는 보이지 않음). 목걸이식 사용 금지(r5 연출 우선). 이전 rev2의 "사용자 확인 대기"가 확정으로 바뀜
3. S3·S4 승인 이미지, 서수니 기존 승인 시트, S1·S2, 리더 v2는 변경 없음(SHA-256 일치, 연속성 X02)
4. 의상 B 권총집은 오른쪽 허리, 전신·와이드 49·53·61에서만 작게, 상반신 비표시(유지)

## S5·S6
후보(CANDIDATE)로 접수. 검토서 `SUNI_S5_S6_CANDIDATE_REVIEW_r8_rev3.md` 참조. **승인 문구 전까지 APPROVED가 아님**, 컷 맵에서 상처 참조로 사용하지 않음.
