# 서수니 좌측면·전신 후보 제작 명세 (r7)

> 상태: **명세만 완성, 이미지 미생성.** 만들어진 후보는 사용자 검수 전에는 확정하지 않으며, 승인된 얼굴(`CH_SUNI`)을 바꾸지 않습니다. 유료 생성은 별도 승인 전까지 하지 않습니다.

## 1. 입력 (모든 후보 공통)
- 첨부: `references/suni/SUNI_APPROVED_SHEET_original.png`(SHA-256 `461926ff…3be6`) 또는 정면·3/4·우측 얼굴 크롭
- 고정: 눈매·코·입술·얼굴형·피부 질감, 낮은 포니테일+잔머리, 흉터·피어싱·안경 없음, 자연 질감
- 금지: 거울 반전으로 좌측면 대체, 나이·키 암시(키 눈금·비교 인물 금지, 168cm는 미확정), 얼굴 변경
- 시트 문구: "나이·신장·직업 미확정 / 제작 가정용 시안"을 유지

## 2. 후보 목록
| 번호 | 후보 | 의상 | 구성 | 상태 |
|---|---|---|---|---|
| S1 | 좌측면 얼굴(흉상) | A | 승인 우측면과 같은 조명·거리, 왼쪽 옆얼굴과 귀, 포니테일 묶음 방향 확인 | 미생성 |
| S2 | 전신 정면 + 우측면 + 뒷모습 | A (야간·비) | 3면 전신, 비에 젖은 질감 | 미생성 |
| S3 | 전신 정면 + 측면 | B (낮·복도) | 3면 중 정면·측면 | 미생성 |
| S4 | 전신 정면 + 측면 | C (점퍼 탈의 후) | 정면·측면 | 미생성 |
| S5 | 왼쪽 옆구리 부상 상태 상반신(선택) | A, 컷 22~42 | 재킷 찢김·칼 자국. **좌측은 [제안], 미확정** | 미생성 · 부상 쪽 확정 후 제작 |
| S6 | 지혈 붕대 상태(선택) | A, 컷 43~48 | 붕대 위치만 | 미생성 · S5와 같은 쪽 |
S5·S6는 부상 방향(좌측 여부)을 사용자가 정한 뒤 제작합니다.

## 3. 의상 지시 (승인 시트 기준 + 필요한 소품만)
- A: 검은 후디형 방수 재킷, 하네스 끈, 비에 젖음. 주황 클립·주황 장갑 끈은 **추가하지 않음**(시트에 없고 필수 아님)
- B: 네이비 재킷 + 밝은 상의. 컷 49에서 점퍼 가슴 주머니 밖으로 보이는 **회중시계 사슬 끝**만 소품으로 추가
- C: 크림색 긴팔 + 어깨 끈. 점퍼 없음. 컷 62 회중시계는 손에 쥐는 소품으로 별도
- 권총집: 컷 60에서 권총을 책상에 두는 연출이 있어 B에 권총 소지가 전제됨. 허리 권총집을 B에 추가할지는 사용자 확인 항목(제안: 상반신 컷에서는 보이지 않게, 전신 S3에만 작게 표시)
- 이 소품들은 사용자 확인 전까지 후보 문구에서 제외 가능

## 4. ChatGPT용 요청 문구 (S1 + S2 예시)
```
첨부한 서수니 승인 시트의 얼굴(눈매·코·입술·얼굴형·피부 질감)과 낮은 포니테일+잔머리를 그대로 유지하고, 같은 사람으로 아래만 새로 만들어줘. 얼굴을 바꾸지 말 것.
S1) 좌측면 얼굴 흉상. 승인 우측면과 같은 거리·같은 조명(야간 비, 차가운 청록 키라이트). 거울 반전이 아니라 실제 왼쪽 옆얼굴, 왼쪽 귀가 보이게.
S2) 의상 A 전신: 검은 후디형 방수 재킷+하네스 끈, 비에 젖은 모습. 정면·우측면·뒷모습 3컷. 어두운 단색 배경.
시트 형식은 기존 승인 시트와 같게, 하단에 "나이·신장·직업 미확정 / 제작 가정용 시안" 문구. 흉터·피어싱·안경·과한 메이크업 없음. 키를 암시하는 눈금이나 비교 인물 넣지 말 것.
```
S3·S4는 위 문구에서 의상 줄만 B·C 지시로 바꿉니다.

## 5. 검수 기준
- 승인 시트와 같은 사람인가(정면·3/4·우측 얼굴 크롭과 나란히 비교)
- S1의 포니테일·귀·헤어 라인이 우측면과 이어지는가
- 전신 비율이 부자연스럽지 않은가(키 수치는 판단 근거로 쓰지 않음)
- A/B/C 구간 의상이 시트와 구분되는가
- 위반 시 재생성. 승인 전에는 컷 맵·핸드오프에서 **후보**로만 표기
