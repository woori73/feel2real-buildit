## 1. 11월 GPU 환경 (ComfyUI / Wan)
- 입력: `SHOT_MANIFEST_v2.json`의 컷별 `video_plan` (목표 길이, 첫 프레임 참조 = 러프 패널, 앵커, 보류 플래그)
- 확인 필요(11월 환경에서 검증): Wan 모델 종류·버전, 1회 생성 가능 길이와 해상도, 워크플로 노드 구성, VRAM 한계. 현재 이 값들은 비어 있으며 추정하지 않았습니다.
- 목표 길이가 1회 생성 길이를 넘는 컷은 분할 생성 후 편집으로 잇는다는 방침만 정했고, 분할 기준은 위 검증 후 확정합니다.
- 러프 패널은 구도 참조용입니다. 최종 캐릭터 아트가 확정되기 전에는 인물 얼굴이 나오는 컷의 첫 프레임으로 쓰지 않습니다.

1. A군 6컷(1, 2, 8, 15, 18, 57): 얼굴·원본 충돌 이슈가 없어 환경 테스트용으로 적합
2. 캐릭터 디자인 확정 후 B군 50컷
3. 원본 충돌 해소 후 C군 12컷(검수서 참조)
- 컷 49를 기준 프레임으로 53·61을 만든다. 컷 38 얼굴 앵커는 65에 재사용한다(흉터 없이).

## 4. 후반 합성 전용 (AI 생성 금지)
자막·시각·'HNL…' 일련번호·태블릿 문구·세븐 화면 글자. 특히 컷 41 자막, 52 CCTV 시각, 59 대사 텍스트는 원본 확정 전이라 비워 둡니다.

## 5. 기존 B01~B09 패널 원본이 확보되면 (컷 1~42)
1. 원본을 `originals/B0x/`에 따로 저장하고 MD5를 기록한다. 현재 러프 패널은 그대로 둔다.
2. 컷별로 나란히 비교: 구도, 인물 위치, 소품, 조명, 시선 방향, 컷 길이.
3. 원본이 더 정확하면 `panels_v2/`에 교체본을 두고 매니페스트의 `panel.status`만 바꾼다. 원본 패널의 서술에 없는 사건·대사는 넣지 않는다.
4. 원본에 B01 프롬프트의 2.39:1 잔존(O-12)이 있으면 16:9로 통일해야 하는지 사용자에게 확인한다.
5. 교체 결과는 컷별 비교표(교체/유지/불일치 사유)로 보고한다.

## 6. 부족한 원본 자료
v5 JSON, B01~B09 패널/PDF/ZIP, 문서 A/B/C v3.1, 심사평 v1, 통합 설정집, 68컷 정식 원본 파일.
