## 컷 38·65 같은 얼굴 기준
두 컷은 같은 얼굴 함수로 그렸고 흉터 없이 다음 요소로 식별한다.

| 식별 요소 | 값(머리 높이 = 1) |
|---|---|
| 얼굴 폭 | 약 0.80 |
| 눈썹 | 굵고 낮음(눈 위 약 0.09~0.10), 눈 사이 간격은 얼굴 폭의 약 44% |
| 귀 | 폭 약 0.12 × 높이 0.22, 눈높이 아래쪽에 위치 |
| 턱 | 각진 선, 턱끝 폭 약 0.38 |
| 입 | 얇고 곧은 선, 폭 약 0.24 |
| 머리 | 짧게 깎음, 양 이마 선이 올라간 형태 |
컷 65에서는 헬멧과 올린 바이저로 이마 윗부분이 가려지므로, 눈썹·귀·턱·입 네 요소가 같아야 한다. 이는 이후 GPU 시험의 합격 기준 초안이다([제안]).
