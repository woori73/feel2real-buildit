# ComfyUI/Wan 준비 (r4)

생성·유료 크레딧 사용 없음. 모델·워크플로·해상도·1회 생성 길이는 11월 GPU 환경에서 확인할 값이라 비워 두었다.

- `AI_AGENT_EP01_ANCHOR_SPEC_r4.json`: 컷별 첫 프레임(러프 패널), 캐릭터 참조(r3 도식 + r4 의상 C), 조명 보드, 앵커, 금지 항목, r4 상태
- `REFERENCE_PACK_INDEX_r4.json`: 참조 이미지 전체 목록과 sha256, 용도
- `AI_AGENT_EP01_SHOT_MANIFEST_r4.json`: r3 매니페스트 + `r4` 필드(컷별 확정 문안과 상태)

규칙
1. 첫 프레임은 러프 패널이며 구도 참조 전용이다.
2. 컷 49 첫 프레임을 53·61의 앵커로, 컷 38 얼굴을 65에 재사용한다.
3. 컷 14·15는 사격 3명, 49·50은 시계를 소품으로만 둔다.
4. 보류 컷(9·34·38·41·42·45·55·65·67)은 대사·시각 문구를 프롬프트에 넣지 않는다.
5. 눈썹 흉터, 세븐 음성, 화면 글자는 생성하지 않는다.
6. 참조 이미지는 모두 도식·컨셉 보드라 identity 고정이 되지 않는다. 사용자가 시안 방향을 승인한 뒤 교체한다.
