# ComfyUI/Wan 영상 생성 준비 (r3)

생성·유료 크레딧 사용 없음. 모델·워크플로·해상도·1회 생성 길이는 11월 GPU 환경에서 확인한 뒤 채운다(현재 미정).

## 파일 구성
- `AI_AGENT_EP01_ANCHOR_SPEC_r3.json`: 컷별 첫 프레임(러프 패널), 캐릭터 참조 파일, 의상 블록, 앵커, 금지 항목, 보류 사유
- `AI_AGENT_EP01_SHOT_MANIFEST_r3.json`: r2 매니페스트 + r3 판정(`r3` 필드) + `video_plan`
- `character_refs/`: 도식 시안(구도·의상 참조용)
- `panels_preserved_68/`: 러프 패널 68장 복사본(구도 참조 전용)

## 사용 규칙
1. 컷 49의 첫 프레임을 53·61의 앵커로 쓴다. 컷 38 얼굴을 65에 재사용한다.
2. 보류 컷(9·34·38·41·42·43·45·52·55·59·65·67)은 대사·시각 텍스트를 프롬프트에 넣지 않는다.
3. 흉터·세븐 음성·화면 글자는 만들지 않는다.
4. 도식 시안만으로는 인물 일관성이 보장되지 않는다. 시안 승인 → 후보 선택 후 교체한다.
5. Kling은 핵심 장면 후보(8, 31~35, 67·68)만 표시, 사용은 별도 승인.
