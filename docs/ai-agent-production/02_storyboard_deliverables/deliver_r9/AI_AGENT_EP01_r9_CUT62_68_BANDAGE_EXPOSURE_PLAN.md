## 2. 기본안 (제안)
- 62~68 모두 크림 상의 아래 붕대가 **보이지 않게** 한다. 위치만 왼쪽 옆구리로 고정
- 컷 62가 몸통을 잡는 구도가 될 때에 한해, 상의 아래 아주 약한 두께감(옵션)을 둘 수 있으나 붕대 색·혈흔은 보이지 않게 한다 [제안, 승인 필요]
- 컷 62 이후 붕대를 보이게 하면 새 연출 정보가 되므로 별도 승인 후에만 적용
