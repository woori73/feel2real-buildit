### 1.4 의상 구간 (구간만 확정, 세부는 확인 필요)
| 구간 | 컷 | 조건 | 시트 시각 기준 | r5 도식 설명(구) | 상태 |
|---|---|---|---|---|---|
| A | 1~48 | 야간·비·현장 | 검은 후디형 방수 재킷+하네스 끈 | 짙은 남회색, 주황 장갑 끈·클립, 권총집 | 차이 → 사용자 확인 |
| B | 49~61 | 낮·복도 | 네이비 재킷+밝은 상의 | 청회색 경찰 점퍼+흰 셔츠 | 차이 → 사용자 확인 |
| C | 62~68 | 점퍼 탈의 후 | 크림색 긴팔+어깨 끈 | B에서 점퍼 제거 | 차이 → 사용자 확인 |
r6에서는 어느 쪽도 임의로 고르지 않았습니다. 사용자가 정하기 전까지 생성 시 의상은 "시트 크롭 + 구간 조건(A 비·야간, B 점퍼 착용·낮 복도, C 점퍼 없음)"으로만 지정합니다.

### 1.6 얼굴 일관성 규칙 (검수 기준)
1. 눈매·코·입술·얼굴형이 승인 시트와 같은 사람으로 보일 것
2. 낮게 묶은 포니테일과 잔머리 구조 유지
3. 흉터·피어싱·안경 없음, 과한 메이크업 없음
4. 조명이 달라도(야간 청록 / 낮 복도 / 어둠+폰 청백광) 얼굴 구조는 동일
5. 같은 컷 안에서 얼굴이 두 사람처럼 보이면 재생성
