# r5 → r6 변경 사항 보고서

## 1. 한 줄 요약
r5의 대사·사건·컷·러프 패널은 그대로 두고, 승인된 서수니 시각 참조를 등록했으며 리더 디자인 명세와 컷별 참조 연결표를 새로 만들었습니다.

| `AI_AGENT_EP01_CHARACTER_BIBLE_r6.md` | 서수니 기준표(표정·의상·부상·소품 연속성), 리더·기타 인물 상태 |

## 3. r5 대비 달라진 판단
| 항목 | r5 | r6 |
|---|---|---|
| 서수니 외형 | 코드 도식 시안, 제작 프롬프트(턱 길이 머리·주황 클립) | **승인 시트가 시각 기준**. 도식과 r5 서수니 프롬프트는 참조에서 제외(파일 보존) |
| 서수니 헤어 | 턱 길이, 목덜미에서 묶음 | 낮은 포니테일+잔머리(시트 기준) |
| 서수니 의상 | A 남회색+주황, B 청회색 경찰 점퍼 | 구간(A/B/C)만 유지, 색·재단은 차이를 승인 항목으로 올림 |
| 리더 | 도식·텍스트 설명 | 실사용 명세·프롬프트 + 시안 9종 계획(전부 미생성) |
| 컷별 참조 | 55컷 요구 목록(`needs`) | 68컷 연결표, 서수니 51컷(얼굴 29 / 실루엣 22), 리더 13컷, 대표 컷 10 |

## 4. 변경하지 않은 것
- r14 원본, deliver ~ deliver_r5 전체와 러프 패널 68장(전후 MD5 비교는 `preserved/preservation_check_r6.md` 참조)
- 컷 14·15 3명 사격, 컷 42·45 대사 보류, 컷 52 3분 공백(시각 없음), 컷 59 잠정+V1, 컷 67 세븐 음성 없음
- 모든 컷 `pass_confirmed=false`, 정식 원작 대조 0컷
- 서수니 나이·키·직업 미확정

## 5. 이미지 생성 여부
이번 단계에서 Claude가 만든 이미지는 없습니다. 크롭은 사용자가 승인한 시트에서 잘라낸 것이고, 서수니 추가 각도·리더 시안·68컷 새 패널은 모두 미생성입니다.
