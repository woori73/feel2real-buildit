## 5. 확인이 필요한 사항 (사용자 판단 전에는 어느 쪽도 확정하지 않음)
1. **의상 색·재단 차이.** 시트와 r3~r5 도식 설명이 다릅니다.
   - A: 시트 = 검은 후디형 방수 재킷 + 하네스 끈(비). r5 = 짙은 남회색 방수 재킷, 주황 장갑 끈·하강 하네스 주황 클립·오른쪽 엉덩이 권총집
   - B: 시트 = 네이비 재킷 + 밝은 상의. r5 = 청회색 경찰 점퍼 + 흰 셔츠
   - C: 시트 = 크림색 긴팔 + 어깨 끈. r5 = B에서 점퍼만 벗은 상태
   - 제안: 얼굴·헤어는 시트 기준으로 고정하고, 의상은 시트의 모습을 시각 기준으로 삼되 r5 소품(권총집·주황 클립·경찰 점퍼 여부)을 반영할지 사용자가 정해주세요.
2. **왼쪽 측면.** 시트에는 우측면만 있습니다. 부상은 왼쪽 옆구리 [제안: 좌측, 미확정]이라 왼쪽 면 참조가 필요할 수 있습니다. 왼쪽 면 후보는 승인 얼굴을 참조해 별도 제작하며 거울 반전으로 대체하지 않습니다(헤어 묶음 방향·귀 위치가 달라질 수 있음).
3. **포니테일 길이.** r5 프롬프트의 "어깨선(턱 길이) 머리를 목덜미에 묶음"은 시트의 긴 포니테일과 다릅니다. r5 헤어 설명은 폐기하고 시트 기준을 따릅니다.
