# r8 rev2 승인 반영 및 변경 기록

## 반영한 승인
1. 사용자가 전달한 S3·S4 이미지를 승인("전달 이미지는 승인") → APPROVED — CHARACTER VISUAL REFERENCE로 등록
2. 원본 바이트 보존, SHA-256 `89cc41faa3318279ed9728be993c99c886055105038359f480b10bdc507add0b`
3. 기존 승인 시트 3종(서수니 기준, S1·S2, 리더 v2) 변경 없음
4. 바이블·컷 맵·연속성·ComfyUI 참조 목록 갱신

## 해석한 부분(사용자 확인 요망)
승인 문구가 "전달 이미지는 승인"이라 검토서의 (가) 그대로 승인으로 처리했습니다. 이미지를 수정하지 않고 차이를 허용했으며, 컷 제작 규칙은 다음과 같이 적용했습니다.
- 컷 49·50 회중시계는 r5 컷 규칙(사슬 끝만) 우선, S3의 목걸이식 시계는 쓰지 않음
- S4 양쪽 어깨 끈은 그대로 의상 C 기준
다르게 정하시려면 알려주세요.

## 변경 전후
| 항목 | r8 | r8 rev2 |
|---|---|---|
| S3 의상 B, S4 의상 C | 후보(접수 전) | 승인 참조 |
| 컷 맵 | 의상 A만 전신 연결 | A·B·C 전신 연결(A 한정 S2, B 49~61 S3, C 62~68 S4) |
| 연속성 검사 | 59항목 | 68항목 통과(+9), 내부 정합 기준 |

## 사용자 확인 대기
1. 의상 A 오른쪽 허벅지 다리 파우치(권총집 여부)
2. 컷 49·50 회중시계 처리
3. S5·S6 제작(다음 단계)
