# 운영 읽기 전용 조사 (2026-10-31)

AWS SSM의 기존 운영 인스턴스에서 `exam-intake-preflight.py --env-file /etc/f2r/env`를 실행했다. 비밀값·고객 데이터는 이 기록에 포함하지 않는다.

- 서비스: active
- 스키마 조사: ok, readOnly=true
- Flyway 최대 적용 버전: 1096, 실패 이력: 0
- 저장소 main 최대 버전: 1096
- 신청 테이블: 0개 (8개 이름 모두 부재)
- SMTP·비공개 저장소·검사기·검토 정책 버전: 실행 환경에 미설정

이 근거로 V1097 신규 테이블 설치 파일을 준비했다. 기존 Flyway·운영 데이터는 변경하지 않았다. 신청 CI는 제안 SQL의 사전 설치를 제거하고 실제 Flyway 경로를 검증하도록 수정했다.

운영 DB 설치, 설정 활성화, 배포, 실제 메일 수신은 아직 완료되지 않았다. 배포 직전 Flyway 및 main 버전을 다시 확인한다.
