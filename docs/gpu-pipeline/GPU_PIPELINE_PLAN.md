# GPU AI 콘텐츠 제작 파이프라인 준비 (2026-10-18)

> 목표: **11월 1일 runyour.ai GPU 개통 후 실제 재생 가능한 샘플** — (A) 영문법 인강 1편(30~60초), (B) 《AI AGENT》 웹툰 컷→영상 1장면(국문·영문). 설치·기술 보고서는 완료 기준이 아니다.
> 운영 원칙: BuildIt 운영 서버·DB와 **완전 분리**(별도 GPU 인스턴스, 운영 자격증명·DB 접근 없음). 산출물만 파일로 주고받는다.

## 2. 공통 엔진: ComfyUI + 모델 후보

ComfyUI를 단일 실행 엔진으로 쓴다(API 모드로 샷 단위 작업 제출, 워크플로 JSON을 저장소에서 버전 관리). 모델은 VRAM에 따라 선택한다. 아래는 **후보이며 설치·품질·라이선스는 개통 후 검증**한다.

| 단계 | 24GB급(RTX 4090 등) | 48GB급(L40S 등) | 80GB급(A100/H100) |
|---|---|---|---|
| 캐릭터 이미지 일관성 | 이미지 모델 + 캐릭터 LoRA(또는 참조 이미지 방식) | 동일, 해상도↑ | 동일, 배치↑ |
| 이미지→영상 | 경량 I2V 모델(짧은 클립, 저해상도 우선) | 중형 I2V 모델 | 대형 I2V 모델·긴 클립 |
| 음성(TTS, 한/영) | 오픈 TTS(다국어, 보이스 클로닝 가능 모델) — 상업 라이선스 확인 | 동일 | 동일 |
| 입 모양 동기화 | 립싱크 모델(필요 시) | 동일 | 동일 |
| 자막·편집 | Whisper 계열 정렬 + ffmpeg(GPU 불필요) | 동일 | 동일 |

선택 기준: ① 캐릭터 일관성(서수니·AI Agent, 선생님·학생) ② 샷당 생성 시간 ③ 상업 이용 가능 라이선스 ④ 한국어 발음 품질.

## 3. 파이프라인 A — 영문법 인강

대본(교재 단원 기반, MASTER·BOOSTER) → 캐릭터·음성 고정(선생님 1, 학생 N) → 장면 이미지(교실, 칠판 문법 표 삽입) → 샷별 영상 → 음성 합성·립싱크 → 자막(문법 포인트 하이라이트)·편집.
- 교재 문법 표/예문은 **이미지 생성에 맡기지 않고** 칠판 오버레이로 직접 합성(오탈자 방지).
- 입력 규격: `gpu-pipeline/samples/grammar_lecture_sample.json`(대본 JSON: title·lang·characters·scenes), 도구: `shotlist.py`(테스트: `python3 -m unittest discover -s gpu-pipeline/tests`).

## 4. 파이프라인 B — AI AGENT

원고(SF 스릴러) → 장면 분해·컷 지시 → 캐릭터 시트(서수니, AI Agent) → 웹툰 컷 이미지 → 컷→영상 → 한국어/영어 두 버전(음성·자막) → 영어 학습용 음성·자막 재활용(문장 단위 분리 파일 출력).
- 캐릭터 일관성은 시트(정면·측면·표정·의상)와 고정 시드/LoRA로 관리.
