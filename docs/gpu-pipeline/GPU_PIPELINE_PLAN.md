## 2. 공통 엔진: ComfyUI + 모델 후보

ComfyUI를 단일 실행 엔진으로 쓴다(API 모드로 샷 단위 작업 제출, 워크플로 JSON을 저장소에서 버전 관리). 모델은 VRAM에 따라 선택한다. 아래는 **후보이며 설치·품질·라이선스는 개통 후 검증**한다.

| 단계 | 24GB급(RTX 4090 등) | 48GB급(L40S 등) | 80GB급(A100/H100) |
|---|---|---|---|
| 캐릭터 이미지 일관성 | 이미지 모델 + 캐릭터 LoRA(또는 참조 이미지 방식) | 동일, 해상도↑ | 동일, 배치↑ |
| 이미지→영상 | 경량 I2V 모델(짧은 클립, 저해상도 우선) | 중형 I2V 모델 | 대형 I2V 모델·긴 클립 |
| 음성(TTS, 한/영) | 오픈 TTS(다국어, 보이스 클로닝 가능 모델) — 상업 라이선스 확인 | 동일 | 동일 |
| 입 모양 동기화 | 립싱크 모델(필요 시) | 동일 | 동일 |
| 자막·편집 | Whisper 계열 정렬 + ffmpeg(GPU 불필요) | 동일 | 동일 |

선택 기준: ① 캐릭터 일관성(서수니·AI Agent, 선생님·학생) ② 샷당 생성 시간 ③ 상업 이용 가능 라이선스 ④ 한국어 발음 품질.

## 6-1. RTX A5000(24GB) 기준 선택 방향 (11/1 전 가정, 개통 후 실측으로 확정)

- **24GB 구간만 사용**한다(§2 표 첫 열). On-Demand 대안으로 Tesla V100 32GB(V100은 구세대라 최신 모델 호환·속도가 불리할 수 있음)와 CPU/RAM이 큰 A5000 구성이 있으나, 기본은 A5000.
- A5000은 Ampere 세대라 FP8 하드웨어 가속이 없다. 큰 모델은 **fp16/bf16 + 양자화(GGUF 등)** 또는 경량 모델로 구성한다.
- 영상은 **짧은 클립(수 초) × 샷 단위**로 만들고 편집으로 잇는다. 해상도는 낮게 시작(예: 480p급)해 품질·시간을 실측한 뒤 올린다. 업스케일은 후처리로 분리한다.
- 이미지(웹툰 컷)는 24GB에서 무리 없는 이미지 모델 + 캐릭터 LoRA/참조 방식으로 시작한다.
- TTS·자막·편집은 GPU 부담이 작거나 불필요하다. 음성은 TTS를 우선 처리하고, 립싱크는 샘플 품질을 본 뒤 도입 여부를 정한다.
- ACE-Step 음악 제작과 인스턴스를 **동시에 돌리지 않는다**(VRAM 24GB 경합).
