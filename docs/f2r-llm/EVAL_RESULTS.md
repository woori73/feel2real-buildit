## 기록 방법
- 평가 하니스(T08)가 낸 결과 JSON을 요약해 아래 표에 한 줄씩 추가한다. 원본 JSON은 `training/eval/results/`에 같이 커밋한다(가중치·GGUF는 저장소에 넣지 않는다).
- 같은 평가 세트끼리만 비교한다. 평가 세트 이름에 학교·학년·시험과 날짜 기준을 적는다.
- 숫자는 실제로 돌린 결과만 적는다. 돌리지 않은 칸은 `-`로 둔다.

## 지표
| 지표 | 뜻 |
|---|---|
| 정답률 | 정답 키가 맞는 문항 비율 |
| 근거 일치율 | 인용 근거 id·지문 문장이 실제 자료와 일치하는 문항 비율 |
| 형식 준수율 | 문항 계약 검사(`question_contract`)를 통과한 비율 |
| 독립 풀이 불일치율 | 다른 모델의 재풀이 답이 정답 키와 다른 비율 |
| 자동 통과 실제 오답률 | 자동 통과 문항 중 샘플 오딧에서 교사가 오답으로 판정한 비율 |
| 문항당 토큰·지연 | 입력+출력 토큰, 생성 시간(초) |
