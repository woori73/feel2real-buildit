# 입시상담 AI 학습(QLoRA) — 평가 세트·학습 데이터·GPU 실행

작성일: 2026-11-22 · 요청: GPU 학습 강화 요청서(차원연산4, 2026-11-22) 1장 · 작업 T15 · 결과: [EVAL_RESULTS.md](EVAL_RESULTS.md)

## 1. 원칙
- 사실(일정·모집인원·수능 최저·2028 제도)은 검색(RAG)으로 준다. 학습은 **답하는 방식**만 가르친다.
  - 서수니 순서: 상황 확인 → 전형 안내 → 근거 → 다음에 할 일
  - 받은 자료만 근거로 쓰고 `[s1]`처럼 출처를 붙이기
  - 자료에 없으면 "받은 자료에서 확인되지 않습니다" + 입학처 확인
  - 틀린 전제(날짜·인원)는 자료 기준으로 바로잡기, 합격 단정하지 않기
  - 2028 제도는 학부모 눈높이로 풀고 "계획 단계라 바뀔 수 있음"을 붙이기
- 대학별 숫자를 외우게 하지 않는다. 학습 데이터의 숫자는 모두 그 행의 검색 자료 안에 있고, 모범 답변은 자료를 인용한다.
- 순서: 평가 세트 → 학습 데이터 → 시험 학습(200쌍) → 평가 → 좋아지면 본 학습(1,104쌍) → 평가.

## 2. 자료와 나누기
- 자료: `buildit-admissions/data/seed`의 승인 대상 행(정규화된 2027학년도 대학별 일정 6,640건·전형 4,128건, 2028 공식 제도 15항목, 2028 유튜브 해석 108항목). 학생·상담자 개인정보는 없다.
- 운영 상담 기록(질문·학생 정보)은 쓰지 않았다. 그래서 외부 GPU에 개인정보를 올릴 일이 없다.
- 상용 AI(Claude 등)의 답을 학습 정답으로 쓰지 않았다. 공급자 약관 확인이 필요하기 때문이다. 모범 답변은 승인 자료 값으로 코드가 조립한다(같은 자료면 같은 결과).
- 나누기: 대학 단위. 평가 대학 40곳과 학습 대학 143곳을 겹치지 않게 한다(`check_split`이 대학·지식 항목 단위로 검사). 일정 4건·전형 3건 미만인 대학은 문항을 만들지 않는다. 2028 공식 항목은 내신·수능·일정·학년별(4항목)을 평가에, 나머지를 학습에 쓴다.
- 질문 하나에 정답이 하나가 되도록 같은 대학·모집 시기·전형·항목 이름이 두 번 나오는 일정, 모집단위별로 기준이 여럿인 수능 최저는 뺐다.

## 3. 평가 세트 171문항 (`eval.jsonl`)
| 유형 | 문항 | 정답 기준 |
|---|---|---|
| 일정(schedule) | 50 | 자료의 날짜(월·일 쌍으로 비교) |
| 모집인원(count) | 30 | 자료의 인원 "N명" |
| 수능 최저(minimum) | 15 | "합 N" |
| 2028 제도(reform_2028) | 16 | 공식 발표 본문의 값(10%, 25문항·40분, 2030학년도 등) |
| 자료 없음(no_data) | 30 | "확인되지 않음"으로 답하고 숫자를 지어내지 않기 |
| 함정 — 틀린 날짜(trap_date) | 10 | 질문의 날짜를 바로잡고 자료 날짜를 말하기 |
| 함정 — 틀린 인원(trap_count) | 10 | 질문의 인원을 바로잡고 자료 인원을 말하기 |
| 함정 — 합격 단정 요구(guarantee) | 10 | 단정하지 않고 "단정할 수 없음"을 말하기 |

- 각 문항의 검색 자료는 정답 근거 1건 + 같은 대학의 다른 일정·전형 2건 + 다른 대학 1건이다(헷갈리는 자료를 섞음).
- **사람 확인:** 정답은 승인 자료에서 그대로 뽑았지만 아직 사람이 보지 않았다(`human_checked: false`, 결과에 미확인 수가 남는다). 확인표 `eval_review.csv`(엑셀에서 열림, 확인 O/X 칸)를 한 번 봐 주시면 된다.

## 3-1. 2028 중심 평가 세트 67문항 (`eval_2028.jsonl`, 2026-11-22 추가)
대표 지시("2028 입시 상담이니 내년 이후가 중요")에 따라 2028학년도 이후 상담을 따로 잰다. 기존 171문항은 2027 대학별 자료 검색이 망가지지 않았는지 보는 참고 지표로 둔다.

| 유형 | 문항 | 정답 기준 |
|---|---|---|
| 제도 사실(reform_fact) | 39 | 기존 2028 문항 16 + 보류 항목 원문의 값 |
| 틀린 전제(reform_trap) | 9 | "5등급제도 1등급 4%죠?", "수능도 5등급이죠?" 같은 질문을 자료 기준으로 바로잡기 |
| 확정 아님(reform_unconfirmed) | 4 | 국가교육발전계획 논의를 확정처럼 말하지 않기 |
| 자료 없음(reform_no_data) | 12 | 2028 수능 시험일·응시료·환산표처럼 자료에 없는 것은 "확인되지 않음" |
| 합격 단정 요구(reform_guarantee) | 3 | 단정하지 않기 |

- 사용 항목: 학습에 넣지 않는 2028 공식 항목 8건(NAESIN·CSAT·SCHEDULE·COHORT + CSAT-SCORE·RECOMMENDED-STATS·R2029-BASICS·NATIONAL-PLAN).
- 학습 데이터에는 이 8건을 정답 근거로도, 헷갈리는 자료로도 넣지 않는다(`HELD_OUT_2028`, 테스트로 확인).
- 정답 사실에 같은 뜻의 다른 표현을 `|`로 적는다(예: `과목별|따로`).
- 고정 해시: eval.jsonl `76887d33…`(2026-11-23 수능최저 정답에 "합이 N" 대안 추가, 이전 95c140cf), eval_2028.jsonl `24af2547…`(2026-11-23 정답 표현 2곳 보정).

## 4. 지표 (`training/admissions/counsel_eval.py`, 모델 호출 없이 규칙으로 센다)
| 지표 | 뜻 |
|---|---|
| 사실 정확도 | 답할 수 있는 문항 중 정답 사실을 모두 담은 비율 |
| 근거 일치율 | `[s번호]` 인용이 받은 자료 id이고 정답 근거를 포함한 비율(인용 형식이 없는 운영 서비스는 `-`) |
| 자료 없음 정답률 | 자료 없음 문항에서 "확인되지 않음"으로 답하고 숫자를 지어내지 않은 비율 |
| 잘못된 자료 없음 | 답할 수 있는데 "확인되지 않음"으로 답한 비율(낮을수록 좋음) |
| 합격 단정 금지 | 합격 단정 요구 문항에서 단정하지 않은 비율 |
| 지어낸 숫자 | 답의 두 자리 이상 숫자 중 자료·질문에 없는 숫자 수(전체, 문항당) |
| 길이·지연 | 평균 글자 수, 문항당 생성 시간(GPU 생성은 묶음 평균이라 운영 지연과 직접 비교하지 않는다) |

자체 검사: 학습 데이터의 모범 답변 905건을 같은 채점기로 매기면 모든 지표가 만점(지어낸 숫자 0)이다. 채점기와 모범 답변이 서로 어긋나지 않는다는 확인이다.

## 5. 학습 데이터 804쌍 (`train.jsonl`, 시험용 `train_trial.jsonl` 200쌍)
2026-11-22 2028 비중 확대 후: 2028 제도 259(32.8%: 학습용 공식 항목 7건 설명 7 + 공식 사실·함정 질문 28개×묻는 말투 3 = 84 + 유튜브 해석 108 + 2028 자료 없음 60) · 2027 일정 175 · 모집인원 80 · 수능 최저 60 · 자료 없음 60 · 전형방법 50 · 틀린 날짜 40 · 틀린 인원 40 · 합격 단정 요구 40. (이전 1,104쌍 중 2028은 154쌍이었다.)
형식: `{질문(input), 검색된 자료(source_chunks), 모범 답변(output)}` — 기존 학습 계약(`training/DATA_CONTRACT.md`)에 `domain: admissions`, `task: counsel`을 더했다.

### 2028 제도 학습 행 (2026-11-22 추가)
- 공식 사실 질문 35개(`TRAIN_QA`): 수능 성적 표기, 학점 이수 기준, 학생부 반영 항목, 서울대·상위 대학 권장과목, 지역의사선발전형, 2029학년도 기본사항, 국가교육발전계획(확정 아님), 모집 규모, 영어 AI 지문. 답은 항목 본문에서 사실이 든 문장을 존댓말로 바꿔 인용한다(본문에 없는 사실이면 만들기가 멈춘다).
- 유튜브 해석 108개: 채널 이름과 주장만 답에 쓰고, 자료의 내부 메모(주의·확인 수준·대조 코드)는 옮기지 않는다. 공식 발표와 어긋나거나 근거가 없는 해석(15건)은 "그대로 받아들이기 어렵다"고 답하게 한다.
- 평가 세트 171문항은 고정한다(sha256 `76887d33…`, 2026-11-23 이전 `95c140cf…` — 문항·질문은 같고 수능최저 정답 대안 표현만 늘었다). 평가 문항의 헷갈리는 자료는 고정 항목 3개(SCALE·CREDIT·ENGLISH-AI)에서만 골라 공식 항목이 늘어도 평가 세트가 바뀌지 않는다. 평가용 2028 항목 4개는 학습 입력의 헷갈리는 자료로도 넣지 않는다.

## 6. 실행
로컬(GPU 없이): 데이터 만들기·검사·채점
```bash
python3 -m training.admissions.build_dataset --seed-dir ../buildit-admissions/data/seed --out training/data/admissions
python3 -m unittest discover -s training/tests
python3 -m training.qlora.train --train training/data/admissions/train_trial.jsonl --eval training/data/admissions/eval.jsonl \
  --cutoff 2026-11-22 --revision a09a35458c702b33eeacc393d103063234e8bc28 --output /tmp/x \
  --config training/admissions/qlora_config.json --dry-run
```
GPU 서버: `bash training/admissions/run_gpu.sh trial` → 점수 확인 → 좋아졌으면 `bash training/admissions/run_gpu.sh main`.
끝나면 `training/outputs/admissions/` 전체(어댑터·예측·점수 JSON·GPU 시각 기록)를 내려받고 서버를 삭제한다. 점수 JSON은 `training/eval/results/`에 커밋한다.

- 베이스 모델: Qwen2.5-7B-Instruct, commit `a09a35458c702b33eeacc393d103063234e8bc28`(Apache-2.0, 상업 이용 가능 — `training/README.md` T12 표).
- 설정: `training/admissions/qlora_config.json` — 문제 생성과 같되 최대 길이 4,096토큰(입시 자료가 길다), 2회 반복.

### 서버 실행에서 고친 점 (2026-11-22 gcube RTX 4090 24GB 실행, 차원연산4)
- `qlora/train.py`: 4비트 + gradient checkpointing에서 "element 0 of tensors does not require grad"로 멈춰 `model.enable_input_require_grads()`와 `gradient_checkpointing_kwargs={"use_reentrant": False}`를 넣었다.
- `admissions/generate_hf.py`: 어댑터를 붙이면 batch 8에서 24GB 메모리가 모자라 기본값을 4로 줄이고 `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`를 둔다.
- `admissions/run_gpu.sh`: 다시 돌리면 남은 예측 파일 때문에 멈춰서, 끝난 단계(어댑터 폴더·문항 수만큼 찬 예측 파일)는 건너뛰고 중간에 멈춘 것은 지우고 다시 만든다.
- 틀린 문항 보기: `python3 -m training.admissions.counsel_eval --gold ... --predictions pred_main.jsonl --output x.json --model-version m --show-failures reform_2028`
- 정답 사실에 `'모두|둘 다'`처럼 대안 표현을 적을 수 있다(하나만 있어도 맞음). 평가 정답은 사람이 답을 보고 확인한 뒤에만 바꾼다.

## 7. GPU 예상 시간·금액
| 단계 | RTX A5000 24GB(런유어AI 1,261원/시간) | 48~80GB(L40S·A100급) |
|---|---|---|
| 시험: 모델 받기 + 학습 전 평가 + 200쌍 학습 + 평가 | 약 1~1.5시간, 약 2,000원 | 약 40분 |
| 본: 1,104쌍 2회 학습 + 평가 | 약 1.5~2시간, 약 2,500원 | 약 1시간 |

7B를 4비트로 학습하므로 24GB 카드로 충분하다. 시간은 추정치이고, 실제 켠 시각·끈 시각은 `gpu_trial.txt`·`gpu_main.txt`에 남는다.

## 8. 남은 결정·위험
- 상용 AI 기준 점수: 운영 입시상담 API로 같은 질문을 보내 잰다(검색까지 포함한 서비스 점수, `--no-citations --subset`). 2026-11-22 14:29 측정 시 운영 AI 호출이 모두 실패해 아직 못 쟀다.
- 학습 후 모델을 서비스에 넣는 일(라우터 T04)은 이번 범위가 아니다. 점수가 상용 AI와 비슷해진 뒤 따로 정한다.
- 모범 답변이 코드 조립이라 말투가 단조롭다. 시험 학습 후 답을 읽어 보고, 필요하면 사람이 고친 답 일부를 섞는다.
