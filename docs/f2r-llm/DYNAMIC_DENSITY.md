# 다이내믹 덴서티(동태밀도, D) — 정의·적용·검증

작성일: 2026-11-08 · 관련: [PLAN.md](PLAN.md) 4-2, 4-3

## 1. 정의

원형(대표님 원문):

```
D(t) = I(t) · dΨ(t)/dt / (V(t) + ε)
```

| 기호 | 원문 정의 | F2R 출제에서 계산하는 값 |
|---|---|---|
| I(t) | 입력된 원시 정보량 | 그 항목(단원·문법 태그)이 해당 학교 과거 기출에서 차지한 비중(0~1) |
| dΨ/dt | 시간에 따른 정보의 변화율 | 최근 2회 시험의 비중 − 그 이전 비중. 줄었으면 0 |
| V(t) | 정보가 차지하는 가상 점유 공간(노이즈 크기) | 범위 분량. 청크 단위에서는 길이 × 반복 문구·서식 문자·형식적 서두 비율 |
| ε | 연산 붕괴를 막는 최소 안정 상수 | 1e-3 |

세 값은 **저장된 데이터에서 계산한다.** 사람이 입력값으로 넣지 않는다(v7 기록의 info_rate·noise_volume 입력 방식은 쓰지 않는다).

## 2. 적용

### 2-1. 출제 원칙 6번 (운영 중, 위키 MCP 프롬프트)
`problem-generator/wiki-src/src/lib/mcpPrompt.ts`의 예상문제 원칙 6번:

> 범위 안 항목(본문·문법)마다 동태밀도 D = 기출 출제 비중 × 최근 증가량 ÷ (범위 분량 + ε)를 계산해, D가 높은 항목에 문항을 더 배정하고 계산표를 함께 보고한다.

- 지금은 생성 모델이 프롬프트 안에서 직접 계산한다. 결과 계산표는 문항 보고에 함께 남긴다.
- 클로드와 자체 LLM v0를 비교할 때 두 모델 모두 같은 원칙 문구를 받는다.

### 2-2. 검색 재정렬 (계획, `density.py` → `retrieval.py`)

```python
def density_score(chunk, stats, eps=1e-3):
    I = stats.exam_share(chunk.tags)                                        # 기출 비중
    psi = max(0.0, stats.recent_share(chunk.tags) - stats.prior_share(chunk.tags))  # 최근 증가량
    V = noise_ratio(chunk.text) * len(chunk.text) / 1000                    # 분량·노이즈
    return I * (psi + 0.1) / (V + eps)   # 0.1: 변화가 없어도 비중은 반영
```

- `stats`는 기출 문항의 태그 집계로 만든다. 기출에 태그가 없으면 AI로 태그를 붙이고 사람이 확인한다.
- 색인할 때 계산해 `context_chunks.d_score`에 저장하고, BM25+임베딩 순위 합성(RRF) 뒤 재정렬에 쓴다.
- D는 **순위만 바꾼다.** 근거가 없는 항목을 D로 끌어올려 출제하지 않는다(유사도 기준 미만이면 "근거 없음 → 답 보류").

## 3. 검증

D가 실제로 도움이 되는지 확인되기 전까지는 "효과 있다"고 쓰지 않는다.

| 모드 | 설명 |
|---|---|
| `D` | BM25+임베딩 → D 재정렬 |
| `bm25` | BM25만 |
| `embedding` | 임베딩만 |
| `hybrid` | BM25+임베딩(RRF), D 없음 |

- 같은 시험 컨텍스트·같은 출제 원칙·같은 모델로 네 모드를 돌려 [EVAL_RESULTS.md](EVAL_RESULTS.md) 지표로 비교한다.
- 추가로 보는 값: 실제 시험 유사 문항 비율(시험 후 실제 시험지와 대조), 근거 청크 수와 토큰 수.
- 평가 세트는 시험 날짜 기준으로 나눈다. 평가할 시험보다 늦은 자료는 stats 계산에도 넣지 않는다.
- `D`가 `hybrid`보다 낫지 않으면 `hybrid`로 고정하고 이 문서에 결과를 남긴다.
