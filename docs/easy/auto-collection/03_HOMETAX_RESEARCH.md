### ② 현금영수증 매출(발급)/매입(수취)
- 공식 API 없음 ✅. 발행은 지정대리인/ASP 대상 별도 절차 ✅ ([국세청](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2462&cntntsId=7788))
- CODEF: 「현금영수증 발행정보 API」 slug `popbill-cashbill-Info` → **팝빌 배대 상품** ✅
- 팝빌: 홈택스수집 범위 내 (웹훅 `htcashbill`) ✅
- 파일: 홈택스 발급내역 엑셀/인쇄 ✅ (가이드 다수)

### ③ 신용카드 매출(카드매출전표) & ④ 사업용 신용카드
- **홈택스 내 공식 OpenAPI 없음** ✅. 원천 데이터는 사실상 **매통조(02번 문서)** — 팝빌 홈택스수집도 "신용카드" 범위 제외 명시 ✅
- → **설계 확정: 카드매출 수집은 매통조 OpenAPI/엑셀. 홈택스('신용카드매출전표등 발행수신세액' 등)는 부가세 신고검수·대사용으로만 사용.**
- CODEF에 홈택스 기반 '신용카드 매출자료 조회'(KR_PB_NT_071) 상품 존재 ✅(06번 문서) — 승인번호 단위 디테일 ❓
- 사업용카드 수신세액 명세 엑셀 다운로드 정확 경로 ❓ (사이트 로그인 확인 과제)

### ⑤ 기타 부가세 자료
- 공식 API 없음 ✅. 부가세 신고도움자료 엑셀 다운로드 존재 🟡, 전산매체(엑셀) 제출 프로그램 ✅ ([국세청 공지](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?nttSn=85088&mi=2544))

## 2. 로그인/인증 제약 요약
- 수단: 공동인증서·금융인증서(로그인 팝업 실재 ✅), ID 로그인은 2025-07-31부터 2차 인증(주민번호 앞 7자리) ✅
- 발행류는 공동인증서 서명 필수 ✅ / 조회류는 ID+2차인증 또는 인증서
- CAPTCHA 구체 방식 ❓, 과도 호출 IP 차단(CODEF 경고 원문 ✅)
- **무인 재로그인 안정성 없음 → 커넥션 만료·재인증 UX가 수집 레이어 1급 요구사항**
