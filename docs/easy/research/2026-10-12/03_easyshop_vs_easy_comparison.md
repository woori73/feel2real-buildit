# 이지샵 vs EASY 기능 비교표

기준일: 2026-10-12  
분류: **A** 즉시 재사용, **B** 일부 수정 재사용, **C** 신규 개발, **D** 외부 API·제휴·법적 검토 선행  
기간은 2 BE + 1 FE + QA/기획 파트타임 팀의 달력 기준 거친 범위다. 비용은 개발 인건비를 제외한 외부비용이며 공개 단가가 없으면 `견적 필요`로 표시했다.

## 핵심 해석

- **A의 가치가 크다.** 원장, import, 수집 lifecycle, 검토·승인, 감사로그를 새로 만들 필요가 없다.
- **B가 첫 출시의 중심이다.** 현재 내부 admin 도구를 tenant-safe 사업자 제품으로 바꾸고 실복식·카드 검토를 정리하면 빠른 MVP가 가능하다.
- **C는 신고보다 장부 품질부터다.** 증빙과 급여·세무서식은 데이터모델과 규정 버전 관리가 필요해 별도 스트림으로 잡아야 한다.
- **D는 코드보다 계약이 선행된다.** 금융·홈택스·세금계산서·4대보험은 기술 착수 전 데이터 제공권한, 자격증명 처리, 위탁/대리 범위를 확정해야 한다.

## 권장 1차 출시 범위

`사업체 멤버십 + 수입/비용 + CSV/파일수집 + 분류 추천 + 사용자 승인 + 실복식 원장 + 증빙 검토 + 월 손익/현금흐름 + 세무사용 내보내기`까지를 1차로 한다. 신고 제출·급여·공공/금융 실수집은 뒤 단계로 분리한다.
