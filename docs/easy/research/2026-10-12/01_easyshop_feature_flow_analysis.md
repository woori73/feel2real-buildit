# 이지샵 기능 및 사용자 흐름 분석서

조사 기준일: 2026-10-12 (KST)  
조사 범위: 공개 홈페이지·약관·도움말, 사용자가 제공한 정상 계정의 로그인 후 화면(조회만), 공개 JavaScript/DOM 구조  
제외: 결제, 신규 회원가입 완료, 사업자·금융정보 입력, 자동수집 실행, 신고 제출, 설정 변경, 인증 우회

## 1. 판정 기준

- **[실제 확인]** 브라우저에서 화면·메뉴·URL·표 구조를 직접 확인했다.
- **[공식 설명]** 이지샵 공식 홈페이지·약관·도움말의 문구를 확인했다.
- **[기술적 추정]** 관찰된 화면과 공개 설명으로 요구사항을 도출했으나 내부 구현은 확인하지 못했다.
- **[미확인]** 계정 변경·제출·결제·실데이터 입력이 필요해 실행하지 않았다.

## 2. 가입부터 사업자 등록까지

1. **무료회원 가입 시작** — 가입 화면에서 이름, 주민등록번호 앞 7자리, 휴대폰 번호와 통신사를 받고 SMS 또는 KB인증서 본인확인을 제공한다. 필수 약관은 서비스 이용, 개인정보, 제3자 제공, 통합매출관리 제3자 제공, 휴대폰 본인확인이다. **[공식 설명·공개 화면]**  
   근거: [회원가입/약관 화면](https://www.easyshop.co.kr/taxMebs/taxMebsMbership.kicc?_method=agreeForm&goods=011)
2. **회원 유형·계정 생성** — 약관에는 개인, 개인사업자, 법인사업자의 필수 항목이 구분되어 있고 ID·비밀번호, 상호·사업자등록번호·법인등록번호 등이 열거돼 있다. 본인확인 뒤 실제 입력 단계는 완료하지 않았다. **[공식 설명, 다음 단계 미확인]**
3. **사업주·사업장 기초정보 등록** — 로그인 첫 화면에서 `정보등록`이 첫 작업으로 배치되고 회원정보, 사업장정보, 사업용계좌, 매입카드, 거래처, 기초잔액 순서를 제시한다. **[실제 확인]**
4. **거래 자동수집원 등록** — `거래자동수집 > 카드/계좌 등록하기`에서 카드사·은행·국세청 사이트 로그인 정보를 등록한다는 안내가 노출된다. **[실제 확인]**
5. **무료 사용→정회원 전환** — 가입 월 장부를 무료로 사용한 뒤 계속 사용하려면 정회원 및 장부 상품을 구매하는 구조다. **[공식 설명]**  
   근거: [처음 이용 가이드](https://www.easyshop.co.kr/taxCustCntr/taxCustCntrNotice.kicc?_method=view&ntt_sn=127187537)

요구사항으로 환원하면 온보딩은 `본인확인 → 회원 유형 → 사업장 → 과세유형/업종 → 계좌·카드·홈택스 연결 → 기초잔액 → 첫 수집 → 검토 → 장부 생성`의 체크리스트형 마법사가 적절하다.

## 4. 기능별 분석

### 4.1 매출·매입·경비와 자동장부

- **[실제 확인]** 수입 화면은 날짜, 거래처, 품목, 면세공급가액, 합계, 카드수수료, 대금수령방법을 한 행에 입력하는 표 형태다.
- **[실제 확인]** 비용 화면은 날짜, 거래처, 항목, 품목, 공급가액, 부가세, 면세공급가액, 합계, 지불방법을 제공한다.
- **[실제 확인]** 월 선택, 매출/비용/고정자산/입출금 탭, 복사·삭제·저장, 계산기·엑셀·인쇄가 한 화면에 있다.
- **[공식 설명]** 일상 용어로 고른 항목을 세무 계정으로 변환하고, 한 줄 입력으로 간편·복식장부를 작성한다고 설명한다.  
  근거: [자동장부 소개](https://www.easyshop.co.kr/taxBooks/taxBooks.kicc)
- **[기술적 추정]** UX의 핵심은 회계 전표가 아니라 거래 행을 먼저 보여 주고 내부적으로 분개를 생성하는 것이다.

### 4.2 카드·은행·국세청 거래 자동수집

- **[실제 확인]** 카드/계좌 등록, 실시간수집, 장부로 보내기, 월별 수집현황과 입금·출금 합계 화면이 존재한다.
- **[공식 설명]** 카드매출·카드비용·전자세금계산서·현금영수증·은행계좌 거래를 자동 수집한다고 설명한다. 약관은 금융기관, 홈택스, 여신금융협회 계정정보 이용을 명시한다.
- **[실제 확인]** 대시보드와 재무리포트에는 POS·배달플랫폼·카드 입금예정·실시간 다시 수집하기가 노출된다.
- **[미확인]** 각 기관별 인증 방식, 수집주기, 실패 재시도, 자격증명 저장 방식, 실제 API/스크래핑 공급사는 확인하지 않았다.

### 4.3 간편장부와 복식부기

- **[실제 확인]** 안내 영역이 간편장부와 복식장부를 별도 절차로 제공하고, 복식 영역에는 수입·비용·고정자산·입출금이 있다.
- **[실제 확인]** 재무제표 영역에 손익계산서, 재무상태표, 제조원가명세서, 시산표, 계정별원장, 총계정원장, 분개장, 전표수기입력이 있다.
- **[공식 설명]** 같은 거래 입력과 자동수집 결과가 간편장부 또는 복식부기장부로 작성된다고 설명한다.
- **[미확인]** 기존 장부를 다른 유형으로 전환하는 실제 마이그레이션 규칙, 소급 분개, 잠금/재개방 정책은 변경 실행 없이 확인할 수 없었다.

### 4.4 세무신고

- **[실제 확인]** 부가세, 종합소득세, 원천세, 일용근로 지급명세서, 근로·퇴직 지급명세서, 간이지급명세서, 면세사업장현황 메뉴가 있다.
- **[실제 확인]** 신고 화면은 기간 선택, 신고 결과, 파일형식 검증, 내용 검증, 제출서류, `신고하기`, `전자신고파일 다운로드`, `국세청 홈택스 바로가기`를 제공한다.
- **[공식 설명]** 장부로 세무서식을 자동 생성하고 전자신고파일을 만들어 홈택스로 전송하는 흐름을 안내한다.
- **[미확인]** 실제 신고 버튼 이후 본인인증, 홈택스 연계, 제출 완료·접수번호 수신은 실행하지 않았다.

### 4.5 세금계산서·현금영수증·증빙

- **[공식 설명]** 전자세금계산서 작성·국세청 전송·거래처 이메일 전송, 거래명세서 작성과 전자세금계산서 전환을 지원한다.
- **[실제 확인]** 전자세금계산서 최초 진입은 별도 서비스 약관, 개인정보, 제3자 제공, 선택적 SMS/이메일 알림 동의 화면이다.
- **[실제 확인]** 수입·비용 입력은 카드, 현금영수증, 현금, 세금계산서 등 증빙/결제 수단별 요약을 보여 준다.
- **[미확인]** 영수증 이미지 OCR, 파일 첨부, 증빙 원본 보관·다운로드 정책은 이번 화면 조사에서 확인하지 못했다.

### 4.6 급여·직원·4대보험

- **[실제 확인]** 직원정보, 정규직·일용직 급여, 퇴직금, 사업소득, 기타소득, 연말정산 메뉴가 있다.
- **[공식 설명]** 지급액을 입력하면 4대보험·소득세·비과세를 계산하고 급여명세서를 출력한다고 안내한다.
- **[실제 확인]** 원천세·지급명세서·연말정산과 4대보험 취득·피부양자·상실·보수총액 신고 흐름이 안내된다.
- **[미확인]** 실제 계산식 버전관리, 공단 전송 방식, 소급정산·중도입퇴사 예외는 검증하지 않았다.

### 4.7 대시보드·현금흐름

- **[실제 확인]** 한눈에 장부관리, 오늘/주/월 매출, 비용, 입금, 카드 입금예정, 곧 나갈 카드값, 최고 매출 요일·시간, 객단가, 전월 대비를 제공한다.
- **[실제 확인]** 재무리포트는 일·주·월 전환, POS/배달/카드/현금영수증/계산서 채널 필터, 매출·비용·입출금·실적 분석을 제공한다.
- **[공식 설명]** 자동수집된 수입·비용·입출금을 실시간 사업현황으로 보여 주고 현금흐름 예측을 제공한다고 홍보한다.
- **[기술적 추정]** 사용자 가치가 큰 것은 복잡한 재무비율보다 `오늘 들어올 돈/곧 나갈 돈/누락된 수집`의 행동형 카드다.

## 6. 초보자 UX의 재사용 가능한 원칙

1. `거래 입력 → 자동 분류 → 검토 → 장부 반영 → 신고 준비`를 메뉴 순서 자체로 가르친다.
2. 회계 용어 대신 수입·비용·입금·출금·카드값 같은 생활 용어를 앞에 둔다.
3. 핵심포인트, 쉬운 화면설명, 동영상 강의, 원격지원, 상담을 각 작업 화면 가까이에 둔다.
4. 월 캘린더와 신고 일정을 첫 화면에서 노출한다.
5. 한 행 입력과 자동수집을 병행해 연결되지 않는 현금·간이영수증을 보완한다.
6. 전자신고파일 생성과 실제 제출을 구분해 사용자가 마지막 제출 주체임을 알 수 있게 한다.

## 7. 제품 설계 시 주의점

- 이지샵의 정보구조와 문제 해결 방식은 벤치마킹하되 화면·문구·아이콘·코드·데이터를 복제하지 않는다.
- 금융·홈택스 자격증명은 직접 저장보다 정식 API/중계사업자와 토큰화 방식부터 검토한다.
- 세무 신고의 자동 생성과 대리 제출은 법적 성격이 다르다. 서비스가 직접 세무대리를 표방하거나 사용자 승인 없이 제출하면 안 된다.
- 실제 화면에서 사업·직원·금액 정보가 표시됐지만 본 보고서에는 계정 식별정보와 원데이터를 남기지 않았다.
