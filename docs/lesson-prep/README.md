# 선생님용 수업 준비·관리 — 현황 표와 「수업 준비 › 학습지」 1차 설계

> 2026-11-22. 대표 지시: 선생님용 수업 준비·관리 서비스의 **구성과 흐름**을 본보기로, F2R 영어 학원용 화면을 기존 기능 위에 만든다.
> 본보기는 다른 과목(수학) 서비스의 공개 자료를 정리한 분석 자료이며, **기능 목록과 흐름만** 참고한다.

## 2. 1차 구현 — 수업 준비 › 학습지

### 화면 (Thymeleaf SSR 빈 틀 + JS, `worksheets.css`)

조사 자료의 화면 구조를 따른다: **위 메뉴(홈·수업 준비·수업·학원 관리) + 왼쪽 메뉴(학습지·자료실·지문 학습지·단어·교재)**. 로고·색·문구·문항은 F2R 것이고, F2R에 아직 자료가 없는 메뉴는 「예정」으로 둔다(공통 틀 `fragments/_prep_shell.html`).

| 주소 | 하는 일 |
|---|---|
| `/dashboard/worksheets` | 학습지 목록 표: 타입·학년·학습지명(문항 수·난이도·유형·범위 요약)·만든 날·만든 사람·배정·미리보기·출제하기·더보기. 구분 4개(우리 학원 / 내 학습지 / 즐겨찾기 / 휴지통), 타입 거르기, 검색 |
| `/dashboard/worksheets/library` | 자료실: 왼쪽 묶음(학교·학년 또는 단원) → 오른쪽 단원 단추 + 자료 표(미리보기, 이 자료로 학습지 만들기) |
| `/dashboard/worksheets/edit[?id=]` | 만들기·수정. **STEP 1** 왼쪽 범위 트리(학교·학년 → Lesson → 회차 / 단원 → 1·2부) + 오른쪽 문제 옵션(문항 수·난이도·문제 유형·유형별 고르게, 조건에 맞는 문항 수) → **STEP 2** 왼쪽 시험지 미리보기 + 오른쪽 문제 목록(통계·순서·바꾸기·빼기)·문제 추가·디자인 설정(이름·머리말·1단/2단·자료 상태) |
| `/dashboard/worksheets/view?id=` | 시험지 보기·인쇄(정답 함께 선택) + 오른쪽 출제하기(학생·반 배정, 배정 상태) |

- 휴대폰 폭(375px)에서는 왼쪽 메뉴가 위로 올라가고 두 칸이 한 줄로 쌓인다. 가로로 넘치지 않는다. 캡처: [captures/](captures/).
- 난이도 조건은 내신 문항(배점 기준)에만 걸리고, 난이도가 없는 어법 문항은 조건과 무관하게 남는다.

### 문항 출처 (새 문항을 만들지 않는다)

| 출처 | 어디서 읽나 | 문항 주소 | 유형 | 난이도 |
|---|---|---|---|---|
| 내신 예상문제 | `tp_exams`(kind=NAESIN·PUBLISHED) + `tp_questions` | `NAESIN:{question_id}` | 해설 첫 줄의 발문에 든 낱말로 나눔: 서술형·영작 / 어법 / 어휘 / 대화 / 독해 / 기타 | 배점: 2점 이하 하, 3점 중, 4점 이상 상 |
| 예비고1 어법 | `PreHighGrammarBank`(단원 1·2부, 마무리 종합) | `GRAMMAR:{시험 키}:{번호}` | 어법 | 없음(난이도 조건을 걸면 빠짐) |

학습지는 문항 내용을 복사하지 않고 주소만 적는다. 출처에서 문항이 없어지면 그 문항은 빠지고, 화면에 「없어진 문항 N개」를 알린다.

### 자료 (V1137)

`easy_worksheets`(학습지 + 목록용 타입·학년·요약·단 수) · `easy_worksheet_items`(문항 주소·순서) · `easy_worksheet_favorites`(선생님별 즐겨찾기) · `easy_worksheet_assignments`(학생별 배정·상태). 칸 설명은 [DOMAIN.md](../DOMAIN.md), API는 [API.md](../API.md) 「수업 준비 › 학습지」.

### CRUD 범위와 삭제 정책

| 대상 | 만들기 | 읽기 | 고치기 | 지우기 |
|---|---|---|---|---|
| 학습지 | 원장(TUTOR)·관리자(ADMIN) | 같은 사업체의 원장·관리자. 숨김은 만든 사람·관리자만 | 만든 사람·관리자 | **휴지통(soft delete, `deleted_at`)** → 휴지통에서 복구 또는 영구 삭제. 만든 사람·관리자만 |
| 학습지 문항 | 저장할 때 통째로 | 학습지와 같음 | 저장할 때 통째로 바꿈 | 학습지를 영구 삭제하면 함께 삭제(cascade) |
| 즐겨찾기 | 본인 | 본인 | — | 본인(끄기 = 행 삭제) |
| 배정 | 관리자 | 관리자(목록의 배정 **수**는 원장도 봄) | 상태 바꾸기: 관리자 | 빼기 = `removed_at`만 채움(행은 남김). 다시 배정하면 시작 전으로 |

- **영구 삭제는 참조 차단**: 배정 중인 학생이 한 명이라도 있으면 거절한다. 배정을 먼저 빼야 한다.
- 휴지통으로 보내도 배정은 그대로 두고, 복구하면 다시 보인다. 휴지통에 있는 학습지는 고치기·배정이 안 된다.
- 사업체 권한은 기존 `EasyTutorAccessService.requireAllowedBusiness`(관리자 = 활성 사업체 전부, 원장 = 내 학원에 연결된 사업체)를 그대로 쓴다. 다른 사업체의 학습지 번호는 「없는 학습지」로 답한다.
- 배정을 관리자 전용으로 둔 이유: 학생 명단(`easy_students`)이 사업체별로 나뉘어 있지 않고, 학생부·출결도 지금 관리자 전용이다. 같은 기준을 따랐다.
