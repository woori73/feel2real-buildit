# MASTER OPERATING PRINCIPLES

**SOURCE OF TRUTH — 사용자 명시 변경 전까지 고정**

## DAILY START HARD GATE

ChatGPT, Qoder, OpenCode, Claude, Freebuck/Freebuff 및 모든 후속 에이전트는 **작업 지시를 작성하거나 작업을 시작하기 전에** 이 문서를 읽는다.

- EASY 작업: `docs/operating-principles/EASY_LEDGER_OPERATING_PRINCIPLES.md`
- NewStart 지피지기 Agent/RAG 작업: `docs/operating-principles/NEWSTART_JIPIJIGI_AGENT_OPERATING_PRINCIPLES.md`

사용자가 명시적으로 변경하지 않는 한 에이전트나 ChatGPT가 원칙을 임의로 재설계하거나 우선순위를 변경하지 않는다. 정확도·안전성·효율을 이유로 핵심 실행보다 분석·검증·테스트·dedupe·source census·parser 개선 등의 새 게이트를 앞에 삽입하지 않는다.

원칙과 기존 지시·코드·handoff가 충돌하면 이 원칙을 우선하고 충돌 사실을 보고한다. 작업 완료는 활동량이 아니라 각 원칙 문서의 완료 기준으로 판정한다.

## 변경 관리

원칙 변경은 사용자의 명시적 지시가 있을 때만 한다. 에이전트가 임의로 의미를 변경하거나 순서를 뒤집지 않는다.
