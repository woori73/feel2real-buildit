## 0. 이번 6회의 정의

- 목표: 실제 압구정중2 기출 사고방식+난도 유지 + 기존 1~5회와 실질 중복 0.
- 무엇을 물을 것인가 = 실제 압구정중2 기출 DNA (1순위).
- 무엇으로 만들 것인가 = 현재 5·6과 학교자료 (L5 본문A/B/C, More Reading 1/2, L6 본문B, Word List, Grammar).
- 무엇을 피할 것인가 = 기존 1~5회 (특히 4·5회 전면 확보분).
- 어떻게 인쇄할 것인가 = GitHub 공통 편집 표준 + 오늘 확정 Layout Standard.

## 1. 공통 제작 원칙 (준용)

- 전 문항 객관식 ①~⑤, 서답형 DNA는 객관식 통합형으로 변환 ("조건을 모두 만족하는 문장은?", "옳은 것의 개수는?").
- 10문항 단위 제작→검수→STOP→승인 후 다음 Batch. 70문항 일괄 생성 금지.
- 각 문항 독립 재풀이 + 정답 유일성 + 오답 성립 검사. "제작하면서 확인"으로 대체 금지.
- USER APPROVAL = PENDING 유지. 스스로 FINAL 선언 금지.

## 3. 기존 1~5회 중복 방지 원칙

- 확보 상태: 4회 70문항(문제지 FINAL + 출제근거 FINAL + Q01~Q70 분할) 확보, 5회 70문항(문제지 + 정답해설 + 편집검증) 확보. 1~3회 원본 미확보 → 1~3회는 NOT SECURED로 명시, 4·5회 기준으로 REPEAT 판정 + 1~3회 발견 시 Blueprint 재대조 조건부.
- 중복 판정은 문장일치가 아니라 사고과정 일치로 판정. 발문만 바꾼 복제, 빈칸위치만 이동, 인명·숫자 변경은 가짜 변형으로 탈락.
- 과사용 주의 (4·5회 합산): 문장삽입 7회, 순서배열 8회, 요약(A)(B) 11회, 영영풀이 10회, 어법옳은문장 14회, 내용일치계열 20회+. 6회는 동일 DNA라도 발문구조를 반드시 바꾼다.
- 기존 지문 재사용하면서 질문만 교체 금지. 기출 선택지 거의 그대로 사용 금지.

## 4. 이번 6회 변형 전략

- TRANSFORM (동일 DNA 다른 유형): 영영정의→본문단어 정의판단+문맥적절성 / 순서→인과·수치결합 / 요약→어법포함 3빈칸 / 간접의문→직접↔간접 양방향 오류찾기 / 수동→능동·수동 의미판별.
- INTEGRATED (DNA 2개+ 결합): 어휘+내용일치 / 문법+본문의미 / 지칭+삽입 / 수치+추론 / 순서+요약 / 개수세기+공통지문 / 영영+paraphrase+문맥 / so~that+어색+변환.
- ADVANCED (사고 1단계 상승): 문법가능+문맥불가 오답 혼합 / 2단계 추론(사실→적용) / 3조건 동시만족 개수세기 / 표 짝짓기+진위판단 결합.
- 분포 목표: 기본변형 ~25%, 실전변형 ~50%, 통합/고난도 ~25%. 기계적 비율맞춤 금지, DNA 우선.
- 금지: 사람·장소·숫자만 변경, 선택지순서변경, 정답번호변경, paraphrase 수준, 문제은행식 개념확인형("수동태란?", "관계대명사를 고르시오").

## 5. 공통지문 설계 원칙

- 70문항 독립 나열 금지. [1~4][5~7][8~11][12~15][16~19][20~23] 등 2~4문항 Group 적극 설계, 전 문항의 60%+를 Group 소속으로.
- 형식: `[11~13] 다음 글을 읽고 물음에 답하시오.` → 전체지문 → 11,12,13 연속. `[공통지문]` 표기 학생지 노출 금지.
- 같은 지문 문항마다 반복 출력 금지. Group 번호 분산 금지(31/36/38 금지, 31/32/33 필수).
- Group 내 유형 중복 금지: 같은 지문에서 내용일치+추론불가+어법+요약을 섞는다.

## 6. 정답 설계 원칙

- Blueprint 단계에서 ①~⑤ 각 14개(±2)로 설계. 긴 연속 동일정답 금지, 눈에 띄는 패턴 금지.
- 우선순위: 정답유일성 > 문항자연스러움 > 정답분포. 분포 맞추려 선택지 기계적 재배열 금지.
- 오답은 attractive하게: 본문 단어 그대로 + 조건 1개 위배 / 문법은 맞고 의미는 틀림 / 시간·주체·수치 뒤집기.
- <보기> 개수세기·짝짓기표는 정답 근거를 해설에 전부 명시.

## 7. HTML/인쇄 편집 원칙 (공통 표준 그대로)

- FORMAT MASTER: `신구중2_2026_2학기_중간고사_4회_70문항_문제지_8PAGE_FINAL_v15_BROWSER_VERIFIED.html` 복제, 새 디자인 금지. 목표 A4 8페이지 2단.
- 철학: "문항 간 충분한 여백 + 페이지 하단 활용" 동시만족. 다닥다닥 FAIL, 하단 과잉공백 FAIL.
- 좌우 column 독립 계산. 페이지 전체 단일 qgap 금지, space-between 남발 금지, nth-child 임시CSS 누적 금지, overflow:hidden 금지, 과도축소 금지.
- qblock(발문+지문+보기+①~⑤) 중간 분리 금지, ⑤만 넘기기 금지. 잘리면 block 전체를 다음 column/페이지로.
- <보기>는 box 내부에 a/b/c/d/e 전부 포함, 제목 상단 가운데, 다음줄부터 항목, 보기-선택지 간격 확보.
- ⓐⓑⓒ/(A)(B) 조합은 `/` 나열이 아니라 table 정렬. 열머리-단어 시작선 일치.
- `밑줄 친` 발문이면 실제 `<u>` 대응 필수, 번호는 단어 바로 옆. 불필요한 밑줄 제거.
- 번호 이동 시 문제지 data-qnum+화면번호+빠른정답+문항해설+검수MD 동시 동기화.
- 최종 판정 = Browser Print. Chrome/Chromium A4 실제 확인, 미실시 시 `BROWSER PRINT QA = NOT VERIFIED`. 확인할 것: 좌/우 마지막문항, ⑤, 긴보기, 표, 공통지문 끝, 전환점, footer, 하단여백, 다닥다닥 여부.
