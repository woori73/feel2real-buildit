## Q11 — 실제 기출 11번 유형: 빈칸 (공통지문 기반)

- ① What inspired the architect? → 본문 앞 문장에서 이미 답함

- ⑤ How did he build it? → 본문에서 다루지 않음

## Q13 — 실제 기출 13번 유형: 문장 순서 배열
**기출 Reference**: 13번 (3점) "(A)에 들어갈 내용을 문맥상 가장 자연스럽게 배열한 것은?"
**9-17 Source**: p.111 (추측 → 반전 → 확인)
**변형**: (A) Look at the roof closely / (B) Many people think of waves or a sailing boat / (C) The inspiration came from an orange
**정답**: ④ (B) → (C) → (A)

### ①~⑤ 검증
- ① (A)→(B)→(C): 지붕 확인 → 추측 → 정답 (순서 틀림)
- ② (A)→(C)→(B): 지붕 확인 → 정답 → 추측 (순서 틀림)
- ③ (C)→(A)→(B): 정답 → 지붕 확인 → 추측 (순서 틀림)
- ④ **(B)→(C)→(A)**: 추측 → 정답 → 확인 ✓
- ⑤ (C)→(B)→(A): 정답 → 추측 → 확인 (순서 틀림)

**정답 유일성**: ✓ | **PASS**

- ③ **DDP 우주선 모양이므로 자연과 무관** → 본문 "자연 곡선 where city people could enjoy"와 모순 ✗

## Q15 — 실제 기출 15번 유형: 빈칸 (A) 내용 추론
**기출 Reference**: 15번 (3점) "(A)에 들어갈 내용으로 가장 적절한 것은?"
**9-17 Source**: p.111 "this is not so obvious"
**변형**: (A) 위치에 문맥 연결 문장 빈칸
**정답**: ④ 오페라하우스의 영감은 명확하지 않다

### ①~⑤ 검증
- ① 외관 독특: 본문 흐름과 무관
- ② 건축가 자연 모방: 앞 문장에서 이미 언급
- ③ 파도 모양 유명: 본문 "not waves"로 반박됨
- ④ **영감은 명확하지 않다** → "this is not so obvious"와 정확히 대응 ✓
- ⑤ Utzon 유명: 본문 흐름과 무관

**정답 유일성**: ✓ | **PASS**

## Q16 — 실제 기출 16번 유형: ⓐ~ⓔ 대체 표현 부적절
**기출 Reference**: 16번 (3점) "ⓐ~ⓔ를 대체한 표현으로 적절하지 않은 것은?"
**9-17 Source**: p.111 easily/not so obvious/take/guess/came from
**변형**: 지문 내 5개 어휘에 대체 표현 제시
**정답**: ③ ⓒ: took a shape from nature (원문과 동일, 대체 아님)

### ①~⑤ 검증
- ① ⓐ easily → clearly ✓
- ② ⓑ not so obvious → hard to notice ✓
- ③ ⓒ **took a shape from nature** → 원문 그대로, 대체 표현 아님 ✗
- ④ ⓓ guess → imagine ✓
- ⑤ ⓔ came from an orange → came from an orange (원문과 동일하지만 본문에서 "the inspiration came from an orange"라서 의미상 대체 가능)

**정답 유일성**: ✓ | **PASS**

## Q17 — 실제 기출 17번 유형: 표/수칙 읽기

**변형**: 설계 수칙 표 구성, 본문과 다른 항목 1개 선정
**정답**: ③ check (지붕을 자세히 보고 오렌지 껍질 확인 → 본문은 "Look at the roof closely" 후 "Can you see the peels?" 질문 형태)

- ③ **check**: 지붕 자세히 보고 껍질 확인 → 본문은 질문 형태로 "Can you see the peels?"로 확인 유도, 수칙형 진술과 다름 ✗
- ④ light: 주황빛 비추면 껍질 선명 ✓

## Q18 — 실제 기출 18번 유형: 대화 ⓐ~ⓔ 의미 차이

- ④ ⓓ for the blind: 수혜자 대상 (blind)
- ⑤ ⓐ/ⓑ 결합: 각각 의미 다름

## Q19 — 실제 기출 19번 유형: 대화 (A)(B) 짝짓기

**9-17 Source**: Listening 2 + p.112 so that
**변형**: 자원봉사 롤플레이 대화 (A)(B) 빈칸
**정답**: ⑤ (A) 읽어드리겠습니다 / (B) 크게 읽으세요 (문맥 불일치)

### ①~⑤ 검증
- ① (A) 읽어드리겠습니다 / (B) 천천히 읽으세요 ✓
- ② (A) 안내해드리겠습니다 / (B) 7번 방으로 가세요 ✓
- ③ (A) 봉사일정표 드리겠습니다 / (B) 시간 맞춰 오세요 ✓
- ④ (A) 녹음실 안내하겠습니다 / (B) 천천히 또렷이 읽으세요 ✓
- ⑤ **(A) 읽어드리겠습니다 / (B) 크게 읽으세요** → "Make sure you read slowly and clearly"에서 "크게"는 본문 근거 없음 ✗
