## Q11-Q20 Blueprint (9-17 Source 적용)

### Q11 — 실제 기출 11번 유형: 빈칸 (공통지문 기반)
- **기출 Reference**: 11번 (3점) "ⓐ에 들어갈 말로 가장 적절한 것은?"
- **기출 구조**: 공통지문 내 ⓐ 빈칸, 의문사 선택
- **9-17 Source**: p.111 "Can you guess what inspired him?" + p.110 tag question "don't they?"
- **변형**: p.111 오페라하우스 지문 + tag question 빈칸
- **출제 포인트**: 태그 의문사 선택 (don't they / didn't he / isn't it)
- **예상 정답**: ④ don't they
- **난이도**: 중

### Q12 — 실제 기출 12번 유형: ⓐ~ⓔ 어법 오류
- **기출 Reference**: 12번 (4점) "ⓐ~ⓔ 중 어법상 틀린 것은?"
- **기출 구조**: 지문 내 ⓐ~ⓔ 직접 밑줄, 5지선다
- **9-17 Source**: p.110 Sagrada Familia + p.112 DDP + Language Use so that
- **변형**: p.110-112 통합 지문 + so that 구문 포함, ⓐ~ⓔ 밑줄
- **출제 포인트**: 
  - ⓐ look like (수일치)
  - ⓑ brought (과거시제)
  - ⓒ so that + 주어 + could (목적)
  - ⓓ designed (과거분사/수동태)
  - ⓔ tourist attraction (명사구)
- **예상 정답**: ① ⓐ (looks like → look like)
- **난이도**: 중상

### Q13 — 실제 기출 13번 유형: 문장 순서 배열
- **기출 Reference**: 13번 (3점) "(A)에 들어갈 내용을 문맥상 가장 자연스럽게 배열한 것은?"
- **기출 구조**: 3개 문장 (A)(B)(C) 순서 배열, 5개 조합 선택
- **9-17 Source**: p.111 오페라하우스 영감 과정 (추측 → 반전 → 확인)
- **변형**: p.111 지문 내 3문장 추출 (Many people think waves/boat → inspiration came from orange → Look at roof closely)
- **출제 포인트**: 내용 순서 논리 (추측 → 사실 → 확인)
- **예상 정답**: ④ (B) → (C) → (A)
- **난이도**: 중

### Q14 — 실제 기출 14번 유형: 내용 구성 판단 (ㄱ~ㅁ)
- **기출 Reference**: 14번 (4점) "판사의 판결을 구성할 때 ㄱ~ㅁ 중 적절하지 않은 것은?"
- **기출 구조**: 시각자료(판결문) + 본문 정보 결합, 5개 진술 중 부적절 1개
- **9-17 Source**: p.112 DDP (spaceship 외관 vs nature 기원) + p.110 Sagrada Familia
- **변형**: 두 건물 정보 결합, 5개 진술 구성
- **출제 포인트**: 본문 사실 vs 외관 선입견 대조
- **예상 정답**: ③ DDP는 우주선 모양이므로 자연과 무관하다 (본문과 모순)
- **난이도**: 중

### Q15 — 실제 기출 15번 유형: 빈칸 (A) 내용 추론
- **기출 Reference**: 15번 (3점) "(A)에 들어갈 내용으로 가장 적절한 것은?"
- **기출 구조**: 지문 내 (A) 빈칸, 5개 선택지
- **9-17 Source**: p.111 "In the first two examples, we can easily see what inspired the architect. But in the next example... this is not so obvious."
- **변형**: p.111 오페라하우스 도입부 빈칸 (A) 구성
- **출제 포인트**: 문맥상 자연스러운 연결 (But 전환어 앞뒤 관계)
- **예상 정답**: ④ 오페라하우스의 영감은 명확하지 않다
- **난이도**: 중

### Q16 — 실제 기출 16번 유형: ⓐ~ⓔ 대체 표현 부적절
- **기출 Reference**: 16번 (3점) "ⓐ~ⓔ를 대체한 표현으로 적절하지 않은 것은?"
- **기출 구조**: 지문 내 ⓐ~ⓔ 밑줄, 대체 표현 5개 중 부적절 1개
- **9-17 Source**: p.110-111 (assigned → allocated, clearly → obviously, dig → excavate, vacation, expected)
- **변형**: p.110-111 핵심 어휘 5개에 대체 표현 제시
- **출제 포인트**: 
  - ⓐ assigned → allocated ✓
  - ⓑ clearly → obviously ✓
  - ⓒ dig → excavate ✓
  - ⓓ vacation (vacation ≠ dig) ✗
  - ⓔ expected ✓
- **예상 정답**: ④ vacation
- **난이도**: 중

### Q17 — 실제 기출 17번 유형: 표/수칙 읽기
- **기출 Reference**: 17번 (2점) "작업 수칙 중 적절하지 않은 것은?"
- **기출 구조**: 표/리스트 형태 수칙 제시, 5개 항목 중 부적절 1개
- **9-17 Source**: p.109 egg building (strong enough to protect contents) + p.112 DDP (tourist attraction) + Language Use so that
- **변형**: 건물 설계 수칙 표 구성 (task, size, notice, object, reward)
- **출제 포인트**: 본문 정보 vs 수칙 내용 대조
- **예상 정답**: ④ object: 품성 기르기 (본문은 자연의 아름다움 구현)
- **난이도**: 하중

### Q18 — 실제 기출 18번 유형: 대화 ⓐ~ⓔ 의미 차이

- **출제 포인트**: for의 용법 구분 (목적어/수혜자/목적/대상)
