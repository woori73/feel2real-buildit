## Q31 / 단어 사용 영작 (take, enjoy)

- Source: p.112 "The architect took the curved lines from nature so that city people could enjoy them."
- 검증: 지정 단어 2개 모두 사용 시 원문 구조가 유일. took(과거) + enjoy(원형) 형태 고정. 모범답안 외 성립 답안 없음.
- PASS

## Q32 / so that 구문 (주어+조동사 필수)

- Source: Language Use "He spoke loudly so that everyone could hear him."
- 검증: "들리도록" 목적 의미에 so that + everyone + could 구조 유일. to부정사 답안은 요령(주어·조동사 필수)으로 배제.
- PASS

## Q33 / 부가의문문

- Source: p.110 "They look like trees, don't they?"
- 검증: 복수 주어 + 긍정문 → don't they 유일. isn't it / doesn't it 등은 주어·시제 불일치로 불가.
- PASS

## Q34 / enough to

## Q37 / 현재완료

- Source: p.110 "Nature has inspired many architects around the world."
- 검증: has + 과거분사 구조 유일. 과거시제 inspired 단독은 요령(현재완료)으로 배제.

## Q38 / Do you mind if ~

- Source: Listening 2 "do you mind if I bring my little brother?"
- 검증: Do you mind if + 주어 + 동사원형 구조 유일. May I / Can I 변형은 요령으로 배제.
- PASS

## Q39 / 가정법 과거

- Source: p.112 "If you were an architect, what would you choose from nature?"
- 검증: were + would + choose 원형 구조 유일. If you are ... will 변형은 요령(were/would)으로 배제.
- PASS

## Q40 / that절 + But 전환 2문장

- Source: p.111 "Many people think that it is the waves in the ocean or a sailing boat. But interestingly, the inspiration came from an orange."
- 검증: that 명사절 + But 대조 2문장 구조. interestingly 부사 포함 여부는 채점 요소 아님(핵심 구조 일치로 판정). sailing boat 병기 없어도 ① 파도 진술 ② 오렌지 반전 핵심 충족.
- PASS (모범답안은 핵심 구조 포함 최소형)
