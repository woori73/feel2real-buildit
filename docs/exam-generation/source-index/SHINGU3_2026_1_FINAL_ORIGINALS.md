## Production/validation rules
1. 이 인덱스만 보고 원본을 판독했다고 주장하지 않는다. 가능한 환경에서는 반드시 7장의 원본 사진 또는 검증된 원문 전사본을 직접 판독한다.
2. 원본 사진의 학생 필기, 동그라미, 교정 흔적은 정답 근거로 단독 사용하지 않는다. 모든 문항은 독립 재풀이한다.
3. 기출은 **출제 DNA**, 학교 학습지/교재는 **문항 내용 Source**, FORMAT MASTER는 **HTML/CSS 편집** 근거로 분리한다.
4. 신구중3 새 회차 제작 전 `진우1~진우7` 전체를 다시 대조하고, 기존 제작 회차와 중복 여부를 검사한다.
5. 공통지문은 해당 문항들과 연속 배치하며, 지문이 앞 페이지에 떨어지고 문항만 다음 페이지로 넘어가는 편집을 피한다.
6. 번호 순서, 공통지문 Group, 선택지 잘림, 페이지 하단 overflow는 실제 브라우저 인쇄 화면에서 검증한다.

8. 원본 사진을 실제로 볼 수 없는 Agent는 `ORIGINAL IMAGE QA = NOT VERIFIED`라고 기록한다.
