## Production rules
1. 문제 제작 전 이 인덱스만 읽고 기출을 판독했다고 주장하지 않는다. 가능한 환경에서는 반드시 6장의 원본 사진 또는 검증된 원문 전사본을 직접 판독한다.
2. 기출은 **출제 DNA 근거**, 학교 학습지는 **문항 내용 Source**, FORMAT MASTER는 **HTML/CSS 편집 근거**로 분리한다.
3. 원본에서 확인되지 않은 유형을 압구정중 기출형이라고 임의로 표시하지 않는다.
4. 원본 필기·채점 흔적은 학생의 표시일 수 있으므로 정답 근거로 단독 사용하지 않는다. 문항을 독립 재풀이하여 검증한다.
5. 원본 사진 판독이 불가능한 Agent는 `ORIGINAL IMAGE QA = NOT VERIFIED`라고 기록한다.
6. 향후 압구정중2 문제 제작 시 기존 회차와 중복 검사를 함께 수행한다.
7. 사용자 명시 승인 전 `FINAL` 또는 `승인완료`를 선언하지 않는다.
