## Production/validation rules
1. 이 인덱스만으로 원본 판독을 대신하지 않는다. 가능한 환경에서는 반드시 8장의 원본 사진 또는 검증된 원문 전사본을 직접 판독한다.
2. 사진에 남은 학생 답, 교사 채점, 동그라미, 필기, 수정 흔적은 정답 근거로 단독 사용하지 않는다. 문항은 독립 재풀이한다.
3. 신사중3에서는 단순 암기형보다 `본문/정의/상황을 읽고 다른 사례에 적용`, `복수정답`, `조건부 영작`이 실제 기출에서 중요하므로 제작 시 이를 출제 DNA로 반영한다.
4. 기출은 **출제 DNA**, 학교 학습지·교재는 **문항 내용 Source**, FORMAT MASTER는 **HTML/CSS 편집** 근거로 분리한다.
5. 새 회차 제작 전 8쪽 전체를 다시 대조하고 기존 신사중3 제작 회차와 중복 검사를 한다.
6. 공통지문은 해당 문제들과 연속 배치하고, 지문과 첫 문항이 페이지 경계에서 부자연스럽게 분리되지 않게 한다.
7. 복수정답 문항은 발문에 `정답 2개` 등 원본 DNA에 맞는 안내가 명확해야 하며, 독립 재풀이로 정확히 두 개만 성립하는지 검증한다.
8. 서답형을 제작하는 회차라면 조건(단어 수, 필수어, 문법 구조, 완전한 문장)을 HTML에서 눈에 띄는 박스로 보존한다.
9. 번호 순서, 선택지 잘림, 공통지문 Group, 페이지 하단 overflow는 실제 브라우저 인쇄 화면으로 검증한다. DOM/CSS 검사만으로 `PAGE DENSITY = PASS`를 선언하지 않는다.
10. 원본 사진을 실제로 볼 수 없는 Agent는 `ORIGINAL IMAGE QA = NOT VERIFIED`라고 기록한다.
11. 사용자 명시 승인 전 최종 승인 상태를 선언하지 않는다.
