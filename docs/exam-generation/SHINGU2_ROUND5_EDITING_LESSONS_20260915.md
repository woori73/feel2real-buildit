## 1. FORMAT MASTER

신구중2 문제지의 시각·인쇄 기준은 다음 4회 문제지다.

`신구중2_2026_2학기_중간고사_4회_70문항_문제지_8PAGE_FINAL_v15_BROWSER_VERIFIED.html`

새 디자인을 임의로 만들지 않는다. 가능하면 MASTER의 실제 HTML/CSS를 먼저 읽고 다음을 기준으로 삼는다.

- A4 2단
- body 약 9.5pt / line-height 약 1.42
- page 210×297mm
- page padding 약 `12mm 11mm 10mm 11mm`
- column gap 약 7mm
- qblock은 중간에서 분리하지 않음
- 발문·지문·선택지·보기 박스의 실제 DOM 구조를 HTML 텍스트로 유지
- 페이지별 문항 개수를 기계적으로 고정하지 않고 실제 렌더 높이에 따라 이동

## 2. 가장 중요한 교훈 — 페이지는 문항 개수가 아니라 실제 높이로 편집

신구중2 5회에서 반복된 실패는 특정 페이지/컬럼에 문항 수를 미리 고정하거나, 큰 `qgap`, `space-between`, `nth-of-type` 임시 CSS로 빈 공간을 메우려 한 것이다.

다음 제작부터 금지한다.

- 페이지마다 문항 개수를 먼저 정하고 억지로 넣기
- `95px`, `190px` 같은 큰 강제 간격으로 페이지를 채우기
- 하단이 잘리는데 `overflow:hidden`으로 숨기기
- 앞 페이지가 크게 비는데 다음 문항을 다음 페이지에 그대로 두기
- 잘림을 해결하려고 글씨부터 축소하기
- 수정할 때마다 페이지별 임시 CSS를 누적하기

올바른 순서:

1. 왼쪽 단 위→아래, 그다음 오른쪽 단 위→아래로 자연스럽게 이어 붙인다.
2. 다음 qblock 전체가 safe bottom 안에 들어가면 현재 단에 둔다.
3. 하단을 침범하면 qblock 전체를 다음 단으로 옮긴다.
4. 한 단에 여백이 많이 남으면 다음 문항을 먼저 끌어올릴 수 있는지 확인한다.
5. 더 이상 문항을 올릴 수 없는데 공간이 남을 때만 문항 간격을 조금 넓혀 가독성을 높인다.
6. 실제 Chrome/Chromium 인쇄 렌더로 마지막 선택지까지 보이는지 확인한다.

**페이지 빈 공간과 하단 잘림을 동시에 해결해야 한다. 둘 중 하나만 해결하면 PASS가 아니다.**

## 3. 공통지문 구조

`[공통지문]`이라는 이름은 인쇄물에서 사용하지 않는다.

범위가 있는 지문은 다음처럼 표시한다.

`[6-8] 다음 글을 읽고 물음에 답하시오.`

그 다음에 **지문 전체가 나오고**, 그 뒤에 해당 범위의 첫 문항이 시작되어야 한다.

예:

```text
[6-8] 다음 글을 읽고 물음에 답하시오.
<지문>
6. 발문
① ...
...
```

공통지문 그룹은 반드시 연속 배치한다. 신구중2 5회 최종 편집 과정에서 사용한 그룹 표기는 다음과 같다.

- `[6-8]`
- `[11-14]`
- `[15-17]`
- `[21-22]`
- `[31-38]`

그룹 안내 또는 지문이 페이지/단 하단에서 잘리면 그대로 두지 않는다. 앞 문항 아래 공간 또는 다음 단으로 **블록 전체를 이동**한다.

특히 `[15-17]`은 Q14 다음에 불필요한 큰 공백 없이 바로 이어지도록 편집했다. 이 원칙을 다른 그룹에도 동일 적용한다.

## 4. 발문과 지문 순서

독립 문항은 발문의 의미를 먼저 읽고 구조를 결정한다. 문자열 일괄치환 금지.

신구중2 5회에서 확정한 사례:

- Q2 발문: `다음 글에서 영영풀이에 해당하는 단어 중 찾을 수 없는 것은?`
- Q2에는 발문 뒤에 별도의 `다음 글을 읽고 ...` 문구를 중복 삽입하지 않는다.
- Q2 지문의 불필요한 밑줄과 ⓒ 표기는 삭제했다.
- 공통지문을 참조하는 후속 문항은 실제로 같은 지문을 참조할 때만 `윗글`을 사용한다.
- 지문 안의 ⓐ/ⓑ/ⓒ를 묻는 문항은 해당 기호가 실제 지문에 존재하는지 반드시 확인한다. 발문만 보고 추정하지 않는다.

## 5. 문항 유형은 실제 학교시험 DNA에 맞춘다

문법 개념을 직접 묻는 교과서식 개념 확인 문제는 피한다.

신구중2 5회 Q5에서 기존의 단순 수동태 개념 판별형을 폐기하고, 실제 시험형에 가까운 **ⓐ~ⓒ 어법 짝짓기형**으로 교체했다.

예시 구조:

```text
5. 다음 글의 ⓐ~ⓒ에 들어갈 말로 어법상 알맞은 것끼리 짝지은 것은?
<문장/지문>

       ⓐ              ⓑ              ⓒ
①  ...             ...             ...
②  ...             ...             ...
③  ...             ...             ...
④  ...             ...             ...
⑤  ...             ...             ...
```

Q5 수정본에서는 수동태의 `be + p.p.`뿐 아니라 주어와 be동사의 수일치까지 함께 판단하게 했다.

**다음 제작에서는 '수동태란 무엇인가', '수동태 문장을 고르시오' 같은 개념 확인형을 기계적으로 만들지 말고 실제 기출의 어법 판단 형식을 우선한다.**

## 6. 조합형 선택지 표기

조합형 선택지는 `/`로 한 줄에 길게 나열하지 않는다.

### ⓐ·ⓑ·ⓒ 유형

신구중2 5회 Q5와 Q30처럼 상단에 ⓐ·ⓑ·ⓒ를 두고 아래에 ①~⑤와 대응 단어를 열로 정렬한다.

```text
       ⓐ        ⓑ        ⓒ
①     word      word      word
②     word      word      word
③     word      word      word
④     word      word      word
⑤     word      word      word
```

### (A)·(B) 유형

Q27처럼 상단에 `(A)`, `(B)`를 두고 아래에 번호와 대응 단어를 둔다.

```text
       (A)       (B)
①     word      word
②     word      word
③     word      word
④     word      word
⑤     word      word
```

표는 HTML table 또는 동등하게 정렬이 보장되는 DOM 구조를 사용한다. 열 머리글과 선택지 단어의 시작선이 맞아야 한다.

## 7. 보기 박스

`<보기>` 안의 a/b/c/d/e 항목은 반드시 **실제 테두리 안에 모두 포함**되어야 한다.

DOM상 관련되어 있다는 것만으로 PASS하지 않는다. 화면에서 박스 바깥으로 항목이 빠져나오면 실패다.

- `<보기>` 제목은 박스 상단
- a/b/c/d/e는 다음 줄부터
- 보기 항목을 `.cond-box` 밖의 sibling으로 두지 않는다.
- 보기와 선택지 사이에는 읽기 좋은 간격을 둔다.
- 공간 부족을 이유로 보기 글씨만 지나치게 축소하지 않는다.

## 8. 문항 위치 변경 사례와 원칙

신구중2 5회에서 실제로 다음과 같은 재배치를 수행했다.

- Q20 계열 문항이 해당 공통지문의 마지막 문항이 되도록 이동하고 번호/정답해설을 함께 동기화했다.
- Q11과 Q12의 화면 순서가 뒤집힌 편집은 실패로 판정했다. **DOM과 화면 모두 Q1→Q40 순서를 유지**해야 한다.
- Q23이 4페이지 왼쪽 단 하단에서 잘려서 오른쪽 단 맨 위로 이동했다.
  - 4페이지 왼쪽: Q19 → Q20 → `[21-22]` 지문 → Q21 → Q22
  - 4페이지 오른쪽: Q23 → Q24 → Q25 → Q26
- `[15-17]` 지문 안내가 잘린 경우 Q14 바로 아래로 이동했다.

**하단 침범이 예상되면 다음 문항을 다음 단 맨 위로 옮긴다. 문항을 중간에서 자르지 않는다.**

## 9. 특수 편집

- 화살표와 그 설명 문장이 붙어 가독성이 떨어지면 화살표/설명 부분을 다음 줄로 내린다.
- 발문이 요구하지 않는 선택지 밑줄은 제거한다.
- `밑줄 친`이라고 묻는 경우에만 실제 지문/선택지 밑줄이 정확히 대응하는지 확인한다.
- 한 문항의 선택지 일부만 다음 페이지/단으로 잘려 나가는 상태는 절대 허용하지 않는다.

## 10. 문제 번호를 이동하면 정답해설도 같은 작업에서 수정

문항 이동 때문에 번호가 바뀌는 경우 문제지만 고치고 끝내지 않는다.

같은 작업에서 반드시:

1. 문제지 `data-qnum`과 화면 번호 갱신
2. 빠른 정답 번호 갱신
3. 문항별 정답·해설 번호 갱신
4. 정답값이 현재 선택지 내용을 가리키는지 재검증
5. 검수 MD의 그룹 범위와 문항 번호 갱신

문항 **위치만** 바뀌고 번호/선택지 내용이 그대로인 경우 정답값은 유지하되, 검수 기록에 위치 변경을 남긴다.

문항 내용이 바뀐 경우에는 기존 해설을 재사용하지 않는다. 예: 신구중2 5회 Q5는 문제 자체를 수동태 어법 짝짓기형으로 교체했으므로 해설도 새 문항 근거로 다시 작성했다.

- 문항 또는 선택지 일부 잘림
