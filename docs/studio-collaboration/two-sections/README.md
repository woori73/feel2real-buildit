# Studio 제작 자료 / 검수·승인

2026-10-25 감독 지시. main `745b5cf127f316120785c581b7c7a1b5a18d27a7`에서 분리한 작업이다. 홈페이지 #901·#902와 영화 파일은 변경하지 않는다. 운영 배포·병합·기존 자료 정리는 실행하지 않는다.

## 기존 운영 상태

개편 전 운영 메뉴는 11개다. 별도 ‘2개 섹션 간소화’ PR/커밋은 확인되지 않았다. 기존 #898은 미디어 재생 기능이며 이 개편이 아니다. 운영 브라우저에서 `agent_studio.js?v=20261024`, 프로젝트 `ai-agent-part1`, ‘검수·승인’ 권한을 확인했다.

운영 계정에서 서수니 웹 상태창(HOLO-SUNI-WEB-FINAL), 세븐 홀로그램(HOLO-SEVEN-ENTRANCE-FINAL-CANDIDATE), EP01 S01–S05 v11과 최신 원본 파일을 조회했다. 기본 EP01 필터가 공통 자료를 가리고, 기존 revision 검색은 파일명·자료 키·버전을 검색하지 않는다. 원본 보관함은 별도 긴 목록이며 연결되지 않은 업로드는 제작 자료 목록에 나타나지 않았다.

## 변경

- 기본 메뉴는 제작 자료 / 검수·승인 두 개다. 원본·제작 버전은 제작 자료에서 함께 검색하고, 문서·각본·합성 패키지는 접힌 별도 묶음에 둔다. 최근 시청 영상과 검수 화면의 최신 승인 영상 / 검수 영상을 큰 플레이어로 보여 준다. 승인 영상이 없으면 명확히 표시한다.
- 기본 회차는 전체다. 공통·회차 미등록, 1~14화, 파일 종류, 자료 유형, 최신/모든 버전, 승인 상태를 조합한다. 제목·파일명·자료 키·버전·SHA·본문·대사·연출 검색을 지원한다.
- 새 읽기 API `/api/studio/catalog`은 기존 프로젝트 권한을 먼저 검사하고, 연결된 revision과 미연결 원본을 합쳐 최신순 페이지 조회한다. 원본 업로드에 회차나 승인 상태를 추정해 기록하지 않는다. 미연결 파일은 ‘공통·회차 미등록 / 검수 상태 미등록’으로 표시한다.
- 최신 모드에서도 현재 승인본과 최신 후보를 함께 표시한다. 이전 작업본은 ‘모든 버전’에서 그대로 조회한다. 파일 이름이 같은 경우도 SHA/버전별 원본은 보존한다.
- 업로드 후 목록을 자동 갱신한다. 버전 작성 후 새 자료 등록 시 이전 parentId가 남던 문제도 수정했다.
- 원본 업로드, 공동 기억, 캐릭터, 콘티, 전후 비교, 검수표, 승인 이력, 프로젝트 접근 관리 기능은 두 섹션 내부의 접힌 도구로 재배치했다. 별도 채팅 화면은 기본 흐름에 노출하지 않는다.
- 영상은 기존 Range 스트림·네이티브 재생/일시정지/전체 화면을 재사용한다. 자동 재생 없이 metadata만 로드하고, 다른 영상을 재생하거나 범위를 바꾸면 기존 재생을 멈춘다. 이미지 지연 로딩, 40개씩 목록 표시, 문서 접기를 적용했다.

## 보존·권한

DB 마이그레이션, 데이터 UPDATE/DELETE, S3/EC2 파일 정리, 승인 포인터 변경은 없다. 기존 URL/API, 원본/SHA, AI 작업 기억, 모든 버전·검수/승인/감사 기록, MCP 업로드/조회는 유지한다. ADMIN·modu 접근 판정과 VIEWER/EDITOR/APPROVER 권한은 기존 서버 검증을 그대로 사용한다. REVIEW는 작업 상태이며 승인 권한을 주지 않는다. UI 메뉴 통합이 서버 권한을 넓히지 않는다.
