## 3. 핵심 사실 스냅샷 (2026-09-20 기준 공식 안내)

- 지원대상 사업영위 기간: 2020년 4월 ~ 2025년 6월 (휴업·폐업 포함, 폐업 법인 신청 불가)
- 부실차주: 3개월 이상 연체 / 부실우려차주: 10~89일 연체 또는 10일 미만 + 별도 요건
- 한도: 총 15억원 (담보 10억 + 무담보 5억, 각각 초과 시 대상 제외)
- 원금조정: 부실차주 무담보 순부채 0~80%, 취약계층 최대 90%
- 거치 최대 3년(신용 1년), 상환 최장 20년(신용 10년)
- 신청취소: 매입형 신청일 익월 15일까지 / 중개형 확정 전까지, 취소 후 90일 재신청 불가
- 추심중단: 신청 익일 통지, 협약기관에 한함
- 공공정보: 부실차주 약정 시 등록, 1년 성실상환 시 해제
- 콜센터 외 전화·문자 없음 (사칭 주의)
