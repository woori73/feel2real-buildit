## 11. 전자책 / 감사회원 상단 노출안

1. **고정공지 순서를 교체** — 현재 1번이 카톡 단톡방(3287)입니다. **3198(전자책→감사회원)을 1번 슬롯으로**, 3287/4446을 2·3번으로. 카페 관리에서 전체 공지 지정 순서만 바꾸면 되는 변경으로, 글 수정은 필요 없습니다.
2. **3198을 "구매 절차 글"에서 "감사회원 관문 글"로 보강** — 현재 본문은 스마트스토어 결제 화면 설명에 집중되고 감사회원 전환은 마지막 주의사항 한 줄입니다. 상단에 3단 구조를 배치:
   `① 전자책 구매(스토어 링크) → ② 쪽지(성함+닉네임) → ③ 감사회원 = 초보가이드 + 지피지기 Agent 전용`
   그리고 **③에 NewStart `/newstart/thanks-guide` 링크 추가**(현재 이 글의 외부 링크는 smartstore 1종뿐).
3. **모바일 HOME 노출 확보** — `전체공지` 탭을 tapped 상태가 아닌 사용자에게는 고정공지가 0건이므로(§8), 카페 HOME 최상단에 **전자책/감사회원 안내를 이미지 카드 1장**(§15 가능 범위) 또는 **게시판 최상단 고정** 형태로 배치.
4. **카톡 의존 축소** — 4446의 "비번 수시변경"은 모바일 마찰이 큽니다. NewStart `/newstart/chat`(회원 채팅)이 이미 존재하므로, 단톡방 안내는 보조 경로로 내리고 1차 경로를 NewStart로 표기.
5. **감사회원 전용 정책은 변경 대상 아님** — `/newstart/thanks-guide`는 로그인 필요(302 확인), 지피지기 Agent는 감사회원 전용(랜딩에 `감사회원 전용` 배지 표시 확인). 본 안은 **노출 순서와 링크 추가만** 제안하고 정책·권한 변경은 포함하지 않습니다.

**카페 적용 방향 (390px)**
1. **색** — 현재 카페 식별 밴드는 네이버 기본 **초록** + 대문 사진은 **파랑 탁자** → NewStart와 무관해 보입니다. 카페 아이콘/썸네일을 `#1558d6` 단색 배경 + 흰 싹 아이콘으로 교체하면 초록 밴드와 충돌하지 않으면서 브랜드 연결이 생깁니다.
2. **타이포** — 카페 본문 글꼴은 네이버 지정이라 변경 불가. **이미지 카드(배너) 안에서만** Pretendard/Noto Sans KR 700 헤딩 + `#101828` 본문 + `#1558d6` CTA로 렌더한 PNG를 씁니다.
3. **카드** — 배너 이미지에 14px 라운드 + `#eef3ff` 배경 + 흰 카드 + 알약 태그(`감사회원 전용` = `--ns-tag-warm` 계열)를 재현하면 NewStart와 같은 서비스로 읽힙니다.

5. **문구 톤 통일** — NewStart 랜딩이 "정리하고, 비공개로 상담받으세요"의 1인칭·동사형이므로 카페 카드도 `[내 상황 1:1 비공개상담]` / `전자책 구매하고 감사회원 되기` 처럼 **1인칭 + 동사 시작**으로 맞춤(공개면에 '무료', 로그인 홍보 문구 금지 원칙 유지).
6. **대문 이미지 교체** — 현재 대문은 무관한 소품 사진. 390px에서 대문이 첫 화면의 약 40%를 점유하므로, "부실차주 · 추심 · 새출발기금"을 한 줄로 박은 배너로 교체하면 §8의 ①번 결함이 즉시 해소됩니다.

## 15. 네이버 카페에서 실제 구현 가능한 범위

**직접 확인(실측)된 것**
- 게시판 이름 변경 / 순서 변경 / menuId 유지 — 현행 15개 평면 메뉴가 관리 설정 산물이며 menuId 결번(8,10,12,17~21)이 과거 편집 흔적 → **변경 가능**
- **전체 공지 3건 지정 및 순서** — PC HOME `.board-notice.type_main` 3행, 모바일 `?tab=notice` 동일 3건 → **고정 개수 3, 순서 제어 가능**
- 카페 아이콘·대문(썸네일) 이미지 — `cafeinfo` API의 `pcThumbnailUrl` / `mobileThumbnailUrl` 별도 필드 → **교체 가능**(현재 두 필드 값 동일)
- 카페소개 문구 — `introduction` 필드 → **수정 가능**
- 게시글 본문 내 이미지·외부 링크 카드(스마트스토어 미리보기 카드 390px 렌더 확인) → **배너 이미지 카드 + 링크 삽입 가능**
- 게시판별 읽기 권한(초보가이드가 감사회원 등급 기준으로 운영 중) → **등급별 접근 제어 가능**

**네이버 카페가 제공하지 않는 것으로 확인/판단되는 것 (가정 금지 항목)**
- 카페 HOME에 **커스텀 HTML/CSS 주입 불가** — HOME DOM은 네이버 SPA가 생성(고정공지 3행 + 피드만 존재)
- **색 테마 커스터마이징** — 모바일 식별 밴드 초록/상단 파랑은 네이버 고정. 카페 관리에 색상 지정 흔적 없음
- HOME 카드·배너의 **자유 위치 레이아웃**(NewStart식 카드 그리드) 불가 → 이미지 1장 or 게시판 목록으로만 구현

- 고정공지 **3건 초과** 노출 미확인 → 4번째를 HOME에 띄우는 방법은 검증 필요
- 카페 검색 결과 노출 순서 제어 불가
