## 1. 새출발기금 개요

### 정의
코로나19로 피해를 입은 자영업자·소상공인의 채무조정을 지원하는 프로그램. 2022년 10월 출범.

### 법적 근거
- 금융위원회 공고 (2022.8.29)
- 새출발기금 주식회사 설립: 한국자산관리공사(캠코) 100% 출자
- 금융회사 협약: 자율 협약 (새출발기금 협약)

### 신복위 채무조정과의 차이 (공식 Q&A)

| 구분 | 신복위 채무조정 | 새출발기금 |
|------|----------------|------------|
| **대상** | 개인 신용채무 위주 | 자영업자·소상공인 사업자대출·담보채무·보증채무 |
| **법인** | 불가 | 법인 소상공인 포함 |
| **담보·보증채무** | 99.9% 신용채무, 담보채무 협의 곤란 | 담보·보증채무 87% 비중 반영 |
| **채권자 동의** | 과반수 동의 필요 | 협약으로 표준화, 신속 처리 |
| **처리 속도** | 개별 협상 | 표준화로 신속 처리 |

## 3. 채무조정 지원 내용 (공식)

### 부실차주 (90일 이상 연체)

| 항목 | 내용 | 출처 |
|------|------|------|
| **원금 조정** | 순부채(채무-자산) 기준 0~80% 감면 | 공식 홈페이지 |
| **취약계층** | 순부채 최대 90% (기초수급자, 중증장애인, 70세 이상 저소득 고령자) | 공식 홈페이지 |
| **저소득층 확대** | 총 채무 1억 이하, 취약계층 부실차주 신용대출: 90% 감면, 거치 3년·상환 20년 | 공식 홈페이지 |
| **거치 기간** | 최대 3년 (신용대출 1년) | 공식 홈페이지 |
| **상환 기간** | 최장 20년 분할상환 (신용대출 10년) | 공식 홈페이지 |
| **담보채무** | 부실우려차주와 동일 (금리 조정만) | 공식 홈페이지 |

### 부실우려차주 (30~89일 연체 또는 연체 우려)

| 항목 | 내용 | 출처 |
|------|------|------|
| **원금 조정** | 없음 | 공식 홈페이지 |
| **금리 조정** | 단일 금리 적용 (상환기간별 차등) | 공식 홈페이지 |
| **금리 상한** | 연 9% (제2금융권 조달금리 4~6% 이상) | 공식 홈페이지 |
| **상환 기간별 금리** | 3년 이하: 3%대 후반 / 3~5년: 4% 중반 / 5년 이상: 4% 후반 | 공식 홈페이지 |
| **담보채무** | 동일 방식 적용 | 공식 홈페이지 |

## 4. 신청 절차 (공식)

| 단계 | 내용 | 처리기간 |
|------|------|----------|
| 1. 온라인 신청 | 새출발기금.kr → 추가자격심사·신청 | 즉시 |
| 2. 증빙서류 제출 | 신청자 유형별 서류 제출 | - |
| 3. 서류 검토 | 제출자료 검토 | - |
| 4. 대상 여부 안내 | 수용 여부 확정 | - |
| 5. 채무조정 약정 | 채권자 변동(금융회사→새출발기금/캠코) | 2개월 내 |
