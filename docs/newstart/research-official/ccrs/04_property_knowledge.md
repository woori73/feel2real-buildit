## 2. 자산별 평가 방식 (공식)

### 2-1. 부동산

| 평가 요소 | 새출발기금 | 개인워크아웃 | 출처 |
|-----------|------------|--------------|------|
| **시가 산정** | KB시세 우선, 없으면 공시지가 | KB시세/공시지가 | 양쪽 공식 |
| **담보대출 차감** | 선순위 담보대출 잔액 전액 차감 | 선순위 담보대출 잔액 차감 | 양쪽 공식 |
| **지역공제** | 약 2,500만 원 (지역별 차등) | 약 2,500만 원 | 양쪽 공식 |
| **공동명의** | 지분율 적용 (배우자 50% 등) | 지분율 적용 | 양쪽 공식 |
| **근저당 설정액** | 채권최고액 기준 아님, 실제 잔액 | 실제 잔액 기준 | 양쪽 공식 |

### 계산식 (공통)
```
부동산 순재산 = 시가 - 선순위 담보대출 잔액 - 지역공제
공동명의 시: 본인 지분율 × (시가 - 담보대출 - 지역공제)
```

### 예외·특례
| 상황 | 처리 |
|------|------|
| **시세 없는 빌라/단독** | 공시지가 또는 실거래가 1건 기준 |
| **경매 진행 중** | 경매 최저가 또는 감정가 |
| **가압류/가처분** | 권리 침해 정도에 따라 차감 여부 결정 |
| **재개발/재건축** | 관리처분계획인가 시 분양권 평가 |

### 2-2. 자동차

| 평가 요소 | 새출발기금 | 개인워크아웃 | 출처 |
|-----------|------------|--------------|------|
| **시가 4,000만 원 이하** | 재산가액 0원 처리 | 재산가액 0원 처리 | 양쪽 공식 |
| **시가 4,000만 원 초과** | 시가 - 4,000만 원 | 시가 - 4,000만 원 | 양쪽 공식 |
| **영업용 차량** | 생계유지 필요성 인정 → 0원 가능 | 생계형 인정 → 0원 가능 | 양쪽 공식 |
| **차량 담보대출** | 담보대출 잔액 차감 후 잔여 시가 평가 | 담보대출 잔액 차감 | 양쪽 공식 |
| **공동명의** | 지분율 적용 | 지분율 적용 | 양쪽 공식 |
| **오토바이/이륜차** | 4,000만 원 이하 동일 기준 | 4,000만 원 이하 동일 | 양쪽 공식 |

### 중고차 시가 산정 (공통)
- **기준**: 보험개발원 차량기준가액, 카히스토리, 중고차 시세 사이트
- **감가율**: 연식·주행거리·사고이력 반영

## 4. 재산 평가 충돌·미해결 영역

| 영역 | 새출발기금 | 개인워크아웃 | 상태 |
|------|------------|--------------|------|
| **가상자산** | 2026.1월~ 5대 거래소 의무 반영 | 반영 기준 없음 | **CONFLICT** |
| **비상장주식** | 국세청 홈택스 의무화 (직접 사업 제외) | 별도 규정 없음 | **CONFLICT** |
| **가상자산 거래소** | 5대 거래소(업비트,빗썸,코인원,코빗,고팍스) 의무 제출 | 제출 기준 없음 | UNKNOWN |
| **사해행위 조사** | 전담반+신용정보법 개정으로 일괄 확보 | 제한적 조사만 | **CONFLICT** |
| **증여/매각 재산** | 신청 전 1년 내 증여·매각 재산 환산 포함 | 증여세 납부 내역 등으로 추정 | CONFLICT |
| **해외 자산** | 행정정보공동이용망 미포국 미반영 | 동일 | UNKNOWN |

## 5. 재산 평가 프로세스 (공식)

### 새출발기금 평가 프로세스

| 단계 | 내용 | 담당 |
|------|------|------|
| 1. 신청인 제출 | 재산목록표, 증빙서류 제출 | 신청인 |
| 2. 행정정보 연계 | 행정정보공동이용망 조회 (부동산, 자동차, 건강보험 등) | 새출발기금 |
| 3. 금융정보 조회 | 금융정보공동이용망 (예금, 대출, 보험 등) | 새출발기금/캠코 |
| 4. 가상자산 조회 | 5대 거래소 회원 여부 + 잔고증명서 | 새출발기금/거래소 |
| 5. 비상장주식 | 국세청 홈택스 조회 (직접 사업 법인 제외) | 새출발기금/국세청 |
| 6. 사해행위 조사 | 전담반 운영, 신용정보법 개정으로 일괄 확보 | 캠코 전담반 |
| 7. 최종 평가 | 순부채 = 총채무 - 순재산 산정 | 심사위원회 |

|------|------|------|
| 1. 신청인 제출 | 재산목록, 증빙서류 | 신청인 |
| 2. 행정정보 연계 | 부동산, 자동차, 건강보험료 등 | 신복위 |
| 3. 금융정보 조회 | 예금, 대출, 보험 등 | 신복위 |
