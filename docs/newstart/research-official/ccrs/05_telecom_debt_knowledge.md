# 통신채무 지식 (Telecom Debt Knowledge) - 공식 근거 기반

## 출처
- 신용회복위원회 공식 홈페이지
- 과학기술정보통신부 (과기정통부)
- 한국통신사업자연합회 (KTOA)
- 금융위원회/금융감독원
- 통신비밀보호법, 전기통신사업법

---

## 1. 통신채무 정의 및 분류

### 정의
이동통신, 유선전화, 인터넷, IPTV 등 통신서비스 이용에 따른 요금 미납으로 발생한 채무.

### 통신채무 유형 분류 (공식)

| 유형 | 상세 | 채권자 |
|------|------|--------|
| **이동통신요금** | 음성통화, 데이터, 문자요금 | SKT, KT, LG U+ |
| **유선전화요금** | 시내/시외/국제전화 요금 | KT, SK브로드밴드, LG U+ 등 |
| **인터넷/IPTV** | 초고속인터넷, IPTV, 결합상품 | KT, SKB, LG U+, 케이블TV |
| **단말기 할부금** | 단말기 구매 시 할부금 (단말기대금채권) | 제조사/이통사/캐피탈 |
| **소액결제** | 휴대폰 소액결제, 콘텐츠이용료 | 이통사/결제대행사 |
| **정보이용료** | 콘텐츠/앱 구매, 게임아이템 구매 | 이통사/콘텐츠제공사 |
| **단말기보험료** | 단말기 파손/분실 보험료 | 보험사/이통사 |
| **로밍요금** | 해외로밍 음성/데이터 요금 | 이통사 |

## 2. 통신채무의 채무조정 처리 (공식)

### 신용회복위원회 개인워크아웃 (CCRS 공식)

| 구분 | 처리 방식 | 출처 |
|------|-----------|------|
| **협약가입 통신사** | 채무조정 대상 포함 (SKT, KT, LG U+) | CCRS 공식 |
| **협약 미가입 통신사** | **채무조정 제외** | CCRS 공식 |
| **단말기 할부금** | 단말기 담보대출 성격 → 담보대출로 처리 | CCRS 공식 |
| **소액결제/정보이용료** | 일반 무담보채무로 처리 | CCRS 공식 |
| **미납요금 연체이자** | 연체이자 전액 감면 (개인워크아웃) | CCRS 공식 |

### 협약가입 통신사 현황 (2024 기준)

| 통신사 | 협약 가입 여부 | 비고 |
|--------|---------------|------|
| **SK텔레콤** | 가입 | 이동통신 3사 모두 가입 |
| **KT** | 가입 | 이동통신 3사 모두 가입 |
| **LG U+** | 가입 | 이동통신 3사 모두 가입 |
| **SK브로드밴드** | 가입 | 유선/인터넷 |
| **KT (유선)** | 가입 | 유선/인터넷 |
| **LG U+ (유선)** | 가입 | 유선/인터넷 |
| **케이블TV 사업자** | 부분 가입 | 지역별 상이 |
| **알뜰폰(MVNO)** | 대부분 미가입 | 대다수 미가입 |

## 3. 새출발기금에서의 통신채무 처리

### 공식 규정 (새출발기금 홈페이지, 금융위)

| 구분 | 처리 방식 | 비고 |
|------|-----------|------|
| **통신요금 미납** | 일반 무담보채무로 처리 | 공식 홈페이지 |
| **단말기 할부금** | 단말기 담보대출 → 담보채무로 처리 | 공식 홈페이지 |
| **단말기 담보대출** | 담보권 실행 후 잔여채무만 조정 | 공식 홈페이지 |
| **소액결제/정보이용료** | 일반 무담보채무로 포함 | 공식 홈페이지 |
| **통신사 협약** | 별도 통신사 협약 없음 (일반 금융회사와 동일) | 공식 홈페이지 |

### 제외·제한 사항

| 제외 사유 | 상세 |
|-----------|------|
| **협약 미가입 통신사** | 채무조정 제외 (개인워크아웃과 동일) |
| **단말기 담보대출** | 담보권 실행 후 잔여채무만 조정 |
| **단말기 할부금** | 담보채무로 분류 → 원금감면 제외 |
| **연체 전 소액결제** | 연체 발생 전 미납분은 일반 채무로 처리 |

## 3. 통신채무 연체 단계별 처리 (공식)

### 통신사 자체 연체 관리 (과기정통부 가이드라인)

| 연체 기간 | 조치 사항 | 법적 근거 |
|-----------|-----------|-----------|
| **1~30일** | 문자/전화 안내, 연체이자 부과 (약정금리) | 전기통신사업법 |
| **31~60일** | 발신 정지 (수신만 가능), 독촉장 발송 | 전기통신사업법 |
| **61~90일** | 수발신 정지, 신용정보회사 연체정보 등록 | 신용정보법 |
| **90일 이상** | 채권 매각·추심 위임, 신용불량자 등록 | 신용정보법, 채권추심법 |

### 신용정보 등록 기준 (신용정보법)

| 등록 정보 | 등록 시점 | 보존 기간 |
|-----------|-----------|-----------|
| **단기연체** (30일↑) | 30일 경과 시 | 해제 후 3년 |
| **장기연체** (90일↑) | 90일 경과 시 | 해제 후 5년 |
| **채무불이행** | 채무불이행 확정 시 | 해제 후 5~10년 |

## 4. 통신채무와 다른 채무조정 제도 비교

| 제도 | 통신채무 처리 | 비고 |
|------|---------------|------|
| **신복위 개인워크아웃** | 협약가입 통신사만 포함 (SKT, KT, LG U+) | 협약 미가입 제외 |
| **새출발기금** | 일반 무담보채무로 처리, 단말기할부는 담보채무 | 통신사 협약 없음 |
| **신복위 프리워크아웃** | 연체 30일 이하, 협약 통신사만 | 개인워크아웃과 동일 |
| **법원 개인회생** | 모든 통신채무 포함 (채권자 동의 불필요) | 법원 결정로 확정 |
| **법원 파산·면책** | 모든 채무 포함 (통신채무 포함) | 면책 결정로 확정 |
| **금융회사 자체 조정** | 통신사 자체 분할납부 프로그램 운영 | 통신사 자체 프로그램 |

## 5. 단말기 할부금·담보대출 특수 처리

### 단말기 할부금 (공식)

| 구분 | 처리 방식 | 출처 |
|------|-----------|------|
| **성격** | 단말기 구매 대금 분할납부 → **할부금융채권** | 금융위 가이드라인 |
| **담보 여부** | 단말기 자체 담보 → **담보채권** | 금융위 가이드라인 |
| **개인워크아웃** | 담보채권 → 담보권 실행 후 잔여채무만 조정 | CCRS 공식 |
| **새출발기금** | 담보채무로 분류 → 원금감면 제외, 금리조정만 | 공식 홈페이지 |
| **개인회생** | 담보채권 → 담보권 존속, 별도 변제 | 채무자회생법 |
| **파산·면책** | 담보권 존속, 별제권 행사 | 채무자회생법 |

### 단말기 담보대출 (공식)

| 구분 | 처리 | 출처 |
|------|------|------|
| **성격** | 단말기 담보 제공 대출 → **담보대출** | 금융위 |
| **담보권 실행** | 단말기 매각/경매 → 잔여채무만 조정 | 양쪽 공식 |
| **새출발기금** | 부실우려차주와 동일 (금리 조정만) | 공식 홈페이지 |
| **개인워크아웃** | 담보권 실행 후 잔여채무만 조정 | CCRS 공식 |

### 제외·제한 (공식)

| 제외 사유 | 상세 |
|-----------|------|
| **협약 미가입 PG사/콘텐츠사** | 채무조정 제외 (개인워크아웃) |
| **해외 결제** | 해외 가맹점 결제건 별도 확인 필요 |
| **게임아이템/확률형** | 청소년 보호법상 제한 가능성 |

| 통신사 | 프로그램명 | 주요 내용 |
|--------|------------|-----------|
