# 신용회복위원회 개인워크아웃 공식 규정 (2024-2025 현재)

## 출처
- 신용회복위원회 공식 홈페이지: https://www.ccrs.or.kr
- 정부24: https://www.gov.kr/portal/service/serviceInfo/PTR000051014
- 신용회복위원회 공식 가이드북

## 1. 개인워크아웃 개요

### 정의
신용회복위원회의 사적 채무조정 제도 중 하나로, 금융기관 채무가 90일 이상 연체된 개인 또는 개인사업자를 대상으로 상환기간 연장, 분할상환, 이자율 조정 등을 지원하는 제도.

### 법적 근거
- 신용회복위원회 설립근거: 신용정보의 이용 및 보호에 관한 법률
- 채무조정 협약: 신용회복지원협약 (금융회사 자율 협약)

---

## 2. 신청 자격 (공식 기준)

### 기본 요건 (모두 충족해야 함)

| 요건 | 세부 기준 | 출처 |
|------|-----------|------|
| **연체 기간** | 협약가입 금융회사 채무 90일 이상 연체 | CCRS 공식, 정부24 |
| **총 채무액** | 15억 원 이하 (무담보 5억 + 담보 10억) | CCRS 공식, 정부24 |
| **최근 대출** | 최근 6개월 내 신규대출이 총 채무원금의 30% 미만 | CCRS 공식, 로톡 |
| **상환 능력** | 재산·수입으로 채무 전액 변제 불가능, 최저생계비 이상 소득 | CCRS 공식, 로톡 |
| **채무 종류** | 협약가입 금융회사 채무 (무담보 위주) | CCRS 공식 |

### 예외·특례 대상

| 특례 대상 | 적용 기준 | 감면율 |
|-----------|-----------|--------|
| **중소기업인** | 총 채무 30억 원 이하 (무담보 10억 + 담보 20억) | 상각채권 최대 70% |
| **34세 이하 미취업청년, 대학생** | 무담보 5억, 담보 10억 이하 | 상각채권 최대 70% |
| **재외동포** | 총 채무 15억 이하 | 일반 기준 적용 |
| **사회취약계층** (기초수급자, 중증장애인, 70세 이상 고령자) | - | 상각채권 최대 90% |

## 3. 제외 채무 (공식)

### 채무조정 제외 대상 (CCRS 공식)

1. **법인(기업) 채무** - 개인 채무에만 적용
2. **사기·횡령 등 고의 부실 채무**
3. **이미 개인회생·파산 절차 진행 중**
4. **채무총액 15억 원 초과** (개인워크아웃 기준)
5. **협약 비가입 금융회사 채무**
4. **채권금융회사와 합의된 채무**
5. **보증기관 구상채무** (대위변제 전 - 대위변제 후 포함 가능)
6. **담보대출** (부동산, 자동차 등 담보 매각·경매로 담보권 소멸 전)

## 4. 지원 내용 (공식)

### 프리워크아웃 (신속채무조정) - 연체 30일 이하

| 항목 | 내용 |
|------|------|
| **연체 기간** | 30일 이하 |
| **추심 중단** | 신청 다음날부터 즉시 |
| **이자율 인하** | 약정이자율의 30~50% 인하 (최고 연 15%, 최저 3.25%) |
| **상환 기간** | 최장 10년 원리금균등분할 |
| **채무 감면** | 연체이자 전액 감면 |

### 사전채무조정 - 연체 31~89일

| 항목 | 내용 |
|------|------|
| **연체 기간** | 31~89일 |
| **분할상환** | 최장 10년 |
| **이자율 인하** | 약정이자율 30~70% 인하 (조정 후 3.25~8%) |

### 개인워크아웃 - 연체 90일 이상

| 항목 | 내용 | 출처 |
|------|------|------|
| **분할상환** | 최장 10년 (주택담보대출: 거치 5년 + 35년) | 정부24 |
| **채무 감면** | 이자 전액 감면, 원금 70% 범위 감면 | 정부24 |
| **상각채권** | 최대 70% 감면 | 정부24 |
| **미상각채권** | 최대 30% 감면 | 정부24 |
| **사회취약계층** | 상각채권 90%, 미상각채권 50% | 정부24 |
| **이자·연체이자** | 전액 감면 | CCRS 공식 |
| **추심 중단** | 신청 다음날부터 본인·보증인 즉시 | CCRS 공식 |
| **단기연체 정보해제** | 개인신용평가회사 등록 단기연체정보 해제 | CCRS 공식 |

### 최저생계비 기준 (CCRS vs 개인회생)

| 구분 | 기준 | 비고 |
|------|------|------|
| **CCRS 개인워크아웃** | 중위소득 40% | CCRS 공식 |
| **법원 개인회생** | 중위소득 60% | 로톡 |

## 5. 신청 절차 (공식)

| 단계 | 내용 | 소요기간 |
|------|------|----------|
| 1. 상담 신청 | 홈페이지(ccrs.or.kr) 또는 전화 1600-5500 | 당일 |
| 2. 서류 제출 | 신분증, 채무서류, 소득증빙 등 | 1~2일 |
| 3. 채권자 동의 | 신복위 → 채권금융회사 조정안 제출 | 2~4주 |
| 4. 조정 확정·상환 | 채권자 과반수 동의 시 확정 | 즉시 |

### 필요 서류 (공식)

| 구분 | 서류 |
|------|------|
| **방문 신청** | 신용회복지원(상담)신청서, 신분증, 소득증빙서류 |
| **대리 신청 시** | 가족관계확인서류, 신청인·대리인 신분증, 인감증명서·인감도장, 위임장 |

---

## 6. 채권자 동의 요건 (공식)

- **채권금융회사 과반수 이상의 동의** 필요
- 과반수 동의 시 → 동의하지 않은 채권기관도 전부 포함 확정
- 과반수 미달 시 → 채무조정 절차 취소

---

## 7. 실효·취소·재조정 (공식)

| 구분 | 내용 |
|------|------|
| **실효** | 3개월 이상 연체 시 자동 실효 |
| **취소** | 허위 신고, 사해행위, 채권자 과반수 미동의 |
| **재조정** | 실효 후 재신청 가능 (단, 3개월 경과 후) |
| **효력부활** | 실효 후 채권자 동의로 효력 부활 가능 |
