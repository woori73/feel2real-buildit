## 1. 핵심 문구

> **"인간 지피지기 + 인공지능 = 지피지기 Agent"**

카페(사람이 남긴 사례) → NewStart(개인을 정리하고 상담하는 창구) → 지피지기 Agent(인간의 판단과 AI를 함께 쓰는 첫 실전 Agent).

## 3. 진행 방향 (방향이지 약속이 아님)

```
부실차주 라이브러리 (사람이 남긴 사례)
        ↓
NewStart (개인 채무상황 정리 · 1:1 비공개상담 · 개인화 서비스)
        ↓
인간 지피지기 + 인공지능
        ↓
지피지기 Agent   ← 지금 여기 (감사회원 + ADMIN 전용, 정책 임의 변경 금지)
        ↓
부실차주 Agent
        ↓
개인워크아웃 등 일반 채무조정 Agent
        ↓
향후 개인 AI Agent(예: Meta Muse 류)와 연결 가능한 구조
```

- 마지막 단계는 **가능성 기술**이다. 한국에서의 사용 가능 여부·연동 수단 제공 여부가 확인되기 전까지 어떤 서비스/API도 존재하는 것처럼 회원에게 알리지 않는다.
- 카페는 앞으로 **지피지기 Agent 중심**으로 계속 진화한다.
- NewStart는 ① 개인 채무상황 정리 ② 1:1 비공개상담 ③ 개인화 서비스 방향으로 연결한다.

## 4. 카페와 NewStart의 역할 분리

| 면 | 역할 | 하지 않는 것 |
|---|---|---|
| 네이버 카페 | 축적된 사례·경험의 라이브러리, 증상별 검색, 사람과 사람의 후기 | 판단 자동화, 개인정보 수집, 상담 기록 저장 |
| NewStart | 내 상황을 정리하고 사람(운영자)과 비공개로 상담하는 개인 창구, 도구(Credit4U·금감원 민원), Agent | 카페 글을 대체하는 것이 아니라 카페 글을 **내 상황으로 연결**하는 다리 |

전환 경로(설계 확정):
- **경로 A**: 카페 → NewStart 1:1 비공개상담 (`/newstart/consultations`)
- **경로 B**: 전자책 구매 → 감사회원 → 지피지기 Agent (감사회원 전용)

두 경로는 합치지 않고并行으로 유지하되, 배너·공지에서 **A를 1순위, B를 2순위**로 놓는다(2026-10-03 운영 결정).
