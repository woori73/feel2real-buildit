## 2. ACTIVE 승격 권고 (검증 통과 기준: 공식 출처 + 원문 추출 완료)

**승격 권고 18건** — 공식 PDF/포털 + 추출 완료:
- 서울대 수시(공식 원본 대조 완료)·정시(교차 검증 일치), 고려대 정시(교차 검증 일치), 연세대 수시·정시, 성균관대 수시·정시, 한양대 수시·정시, 중앙대 정시, 이화여대 수시·정시, 한국외대 수시·정시, 서강대 정시(교차 검증 일치), 고려대 수시, 경희대 정시, 경희대 수시(공식 원본 136쪽 확보, 전형별 총계 행 대조 일치)

**조건부 1건**:
- 서강대 수시 — 공식 출처이나 문서가 '논술가이드북'으로 모집요강 전체가 아님. 승격 시 자료명에 가이드북임을 명시할 것.

**DRAFT 유지 1건** (승격 금지):
- 중앙대 수시 — 사설 미러 출처, 공식 원본 미확인 (20건 중 유일한 공식 원본 미확보 건)

**필드 단위 주의**:
- 경희대 정시 `sat_minimum` — 원문 전형요약표(p.12)의 최저 값이 텍스트 추출로 확정되지 않음. 승격 전 원문 표 직접 대조로 확정하고, 확정 전에는 해당 필드를 근거로 최저 답변을 생성하지 말 것.
- 고려대 수시 — 문서가 **세종캠퍼스** 요강임 (서울캠퍼스 아님). 자료명·근거 표시에 캠퍼스를 명시할 것.
- 한양대 정시 — 원문 내 모집인원 표기 차이(611 vs 601)가 원문 자체에 존재함 (extracted notes 기록). 총량 답변 시 원문 총괄표 기준으로 통일 필요.
