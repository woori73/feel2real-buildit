# 알려진 이슈 (입시상담 검색)

## KI-1 고려대 서울캠퍼스 질문에 세종캠퍼스 자료가 검색됨 — 별도 수정 대상 (미해결)
- 증상: "고려대 서울캠퍼스 수시 전형"을 물어도 `고려대학교(세종캠퍼스) 2027학년도 수시모집요강` 출처의 전형 7건·일정이 근거로 검색된다(로컬 H2, v3.2 시드 확인).
- 현재 완화책: 근거 제목·일정 구분에 `[세종캠퍼스]` 표기 + 시스템 프롬프트의 캠퍼스 규칙(PR #835). **프롬프트는 LLM의 준수에 의존하므로 해결로 판정하지 않는다.** 실제 LLM 응답 검증도 아직 하지 못했다.
- 근본 수정안(미구현): 자료에 캠퍼스 속성을 두거나(자료 제목 파싱 `(세종캠퍼스)`), 질문의 캠퍼스 표현(서울/세종)과 근거 캠퍼스가 다르면 해당 근거를 검색 단계에서 제외하고 "해당 캠퍼스 자료 없음"으로 안내한다. 학과·전형·일정 모두에 적용. 테스트: 서울캠퍼스 질문에 세종 근거 0건, 세종캠퍼스 질문에 세종 근거 노출, 캠퍼스 미지정 질문은 표기가 붙은 근거만 반환.

## KI-2 수시·정시 근거 혼합 — 수정됨 (PR #835)
- 질문이 한쪽만 말하면 반대쪽 출처 자료를 근거에서 제외(중앙대 수시에 정시 행이 섞이던 문제). 둘 다 말하거나 미언급이면 거르지 않는다.
