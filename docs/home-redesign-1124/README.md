# 11월 24일 학교·학원 홈페이지 개편 검토본

운영 반영은 대표 승인 후 진행한다. 기존 300개 주소와 첫 일일 문항을 보존하고 학습관 입구에 학교별 내신 15편, 학부모 영어 학습 20편, 학원 선택·상담 8편, 원장용 7편을 배치했다. 첫 편성은 F2R 보유 회차와 대표가 제시한 질문에 따른 편집 판단이다. 검색량 순위로 표시하지 않는다. 외부 가맹 소개는 공개 동의를 받은 학원별로 추가한다.

## 계정 전환

운영 승인 전에는 google-accounts 프로필을 켜지 않는다. Google Cloud의 웹 OAuth 클라이언트에 /login/oauth2/code/google 및 /login/oauth2/code/google-student 경로의 HTTPS 운영 URI를 등록하고 환경에서 GOOGLE_CLIENT_ID와 GOOGLE_CLIENT_SECRET을 제공한다. 비밀은 저장소에 넣지 않는다. 신규 학생과 기존 로그인은 openid,email만 요청한다. 다른 가입 유형은 이름을 위한 profile 범위를 추가하되 사용자 사진과 OAuth 토큰을 회원 정보로 보존하지 않는다.

가입 유형 스스로 선택으로 운영자·관리자 권한을 주지 않는다. 기존 네이버·비밀번호 로그인을 유지하며 동명이인이나 공유 이메일로 자동 병합하지 않는다. 기존 사용자가 기존 방식으로 먼저 로그인하고 같은 이메일의 Google 계정을 인증하면 사용자 ID를 유지한 채 연결한다. 이메일이 없거나 맞지 않는 계정은 소유 확인과 이메일 정정 전까지 기존 방식으로 사용한다. 만 14세 미만은 법정대리인 동의가 실제 확인되기 전 개인정보 입력·신규 계정 생성을 보류한다.

account-impact.sql은 운영 DB에서 회원 원문 없이 기존 회원 수와 이메일 누락·중복 영향 집단을 세는 SELECT다. 중복·누락·네이버 집단은 서로 배타적인 전체 분류가 아니다. 운영 집계가 없으면 추정치를 발표하지 않는다.

## 자료와 검증

학교 범위는 F2R의 해당 학년도 학교별 예측 회차 소개에 근거하며 학교 공지를 대체하지 않는다. 시험명은 대비 유형 표시다. 보존한 SAT 8개와 TOEFL 4개 사례의 문항·답안과 자체 작성 이력을 확인했다. 모든 공식 문제은행과의 전수 일치를 검사한 결과로 해석할 수 없다. 예시는 가상 기록이며 학생 식별 정보는 포함하지 않는다.

사이트맵에는 학습관, 자료실, 개별 코너 350개와 날짜별 자료가 포함된다. 각 코너의 lastmod는 수정일이며 작성일은 페이지 본문과 구조화 데이터에 제공한다. 학습 자료·운영 기관은 HTML Microdata를 사용한다.

2026년 11월 24일 운영 관리자 대시보드 기준 전체 회원은 452명이다. 네이버 및 이메일 누락·중복 계정의 세부 집계는 운영 DB 조회가 필요하다.
