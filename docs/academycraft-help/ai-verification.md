# 도움말 AI 비서 검증 결과 (2026-10-20, 로컬 실서버)

- 대상: 이 브랜치 jar + 로컬 MySQL, **운영 기본 설정**(`ai-official-statuses=REVIEWED`, REVIEW 허용 override 없음).
- 비서의 성격: **사용법 안내 비서**. 학원 데이터를 조회하거나 업무를 실행하지 않는다(코드에 DB·쓰기 호출 없음).

## 권한·접근 매트릭스 (실서버)
| 호출 | 결과 |
|---|---|
| 비로그인 `GET /help/academycraft*` | 302 로그인 안내(`?login=required&returnUrl=`) |
| 비로그인 `POST /api/help/academycraft/ask` | 401 |
| STUDENT 로그인 페이지 / API | 302 / 401 |
| ADMIN: getting-started·students·admin-guide·tutor-guide·ai-assistant | 전부 200 |
| TUTOR: 같은 5개 | admin-guide만 404, 나머지 200 |

## 단위 테스트로 고정한 항목 (`HelpAssistantTest` 등)
- REVIEW/DRAFT 문서는 답변 본문·근거 목록에 나오지 않는다(합성 카탈로그: REVIEW 문서 1 + REVIEWED 1).
- 다른 학원·명단·연락처·인원수·"오늘 결석한 학생" 요청은 `DATA_LOOKUP`으로 거절하고 "조회하지 않습니다"를 명시한다.
- 쓰기·삭제·수정 요청은 실행하지 않았다고 명시하며 "완료했습니다/삭제했습니다/등록했습니다" 표현이 없다.
- 표현 변형(신입생·원생·수업 개설·출석 체크·알림장·공지 지우기·학부모 상담)이 올바른 문서를 찾는다.
- 범위 밖 질문(점심 메뉴·비트코인·파이썬·영어 단어)은 근거 없음으로 답하고 추측하지 않는다.
- 답변 텍스트에 `**`, `](` 링크 기호가 남지 않는다. 문서 화면의 링크는 `/help/academycraft/*` 내부 경로만 렌더링한다.
- ADMIN/TUTOR 권한 차이("강사도 반을 만들 수 있나요?")는 "원장 역할만 가능합니다"로 답한다. TUTOR에게 ADMIN 전용 문서는 근거로 제공되지 않는다.
