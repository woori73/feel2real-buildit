## 3. 구조
- 단일 출처: `src/main/resources/help/academycraft/*.md` (front matter: id·slug·audience·visibility·status·featureState·appliesTo·lastVerified·source). HTML 화면과 AI 지식이 같은 파일을 읽어 불일치가 없다.
- 화면: `GET /help/academycraft`, `/help/academycraft/{slug}` (ADMIN·TUTOR 로그인 필수, 비로그인은 로그인 안내로 이동). 권한 전용 문서는 다른 역할에 404.
- AI: `POST /api/help/academycraft/ask` — BM25(한글 2-gram) 검색 + 증거 임계값 + 상태/권한 게이트. LLM·DB·쓰기 호출 없음(= 학원 데이터 접근 자체가 없어 다른 학원 데이터 혼입 불가, 기존 P1-a/P1-b 승인 경로와 무관).
- 공식 근거 게이트: `buildit.help.academycraft.ai-official-statuses` 기본 `REVIEWED`. 현재 모든 문서가 `REVIEW`이므로 **기본 설정에서는 AI가 근거 없음으로 답한다.** 검토 승인 후 문서 status를 `REVIEWED`로 올려야 AI가 사용한다. (검증은 `REVIEW,REVIEWED`로 허용해 수행)
- 안전장치: 쓰기 요청("해줘")은 직접 처리 안내로 전환, 데이터 조회 요청(타 학원·명단·연락처 등) 거절, 근거 부족 시 추측 금지, 미배포 기능은 `[개발 완료·미배포]` 라벨 강제, 질문 300자·사용자당 분당 20회 제한.
