## 1. 검수 방법
1. 문서의 모든 `[버튼·메뉴]` 라벨을 AcademyCraft 프런트(`frontend/`)와 BuildIt 대시보드 템플릿에서 대조 → 불일치 없음(`[반·수업 관리]` 등은 도움말 링크 문구).
2. 운영 배포 코드(`543cdfc8`)와 main의 프런트 차이는 `CHAT-01`뿐(P1-a 변경) → 일반 화면은 로컬 실행 결과를 운영 동작의 근거로 사용.
3. 로컬 BuildIt(게이트웨이)+AcademyCraft+MySQL에서 ADMIN(원장 연결)·TUTOR(일반 강사 연결) 계정으로 실제 API를 실행하고, 화면은 PC 1440px·모바일 390px로 촬영.
4. **운영 서버 화면·데이터는 접근할 수 없어 대조하지 못했다.** 따라서 "운영 중"은 "운영 배포된 코드(543cdfc8)에 포함된 기능"을 뜻하며, 운영 화면과의 일치는 미검증이다.

## 6. 구조·보안 요약
- 단일 출처 `src/main/resources/help/academycraft/*.md`(front matter: id·서비스·분류·적용버전·대상 역할·공개범위·검증상태·수정일·출처). 화면과 AI가 같은 파일을 읽는다.
- 접근: `/help/academycraft*`·`/api/help/academycraft/**` = ADMIN·TUTOR만. 역할 전용 문서는 타 역할 404.
- AI 비서는 `status=REVIEWED`만 근거로 사용(`buildit.help.academycraft.ai-official-statuses`, 기본 REVIEWED). DB·LLM·쓰기 호출이 없어 기존 P1-a/P1-b 승인 경로를 우회하는 새 실행 경로가 없고, 테넌트 데이터가 답변에 섞일 수 없다.
- 사용자당 분당 20회, 질문 300자 제한.

## 7. 미검증 사항 · 운영 적용 시 주의
- 운영 서버 화면·데이터와의 대조, 실제 운영 ADMIN/TUTOR 계정 검증은 하지 않았다.
- 출결 시각 한국 시간대, 외부 알림 도착, 모바일 실기기 동작은 미검증.
- 강사가 다른 사람의 공지를 삭제할 수 있다(현재 동작). 제품 정책 확인 필요 — 문서에는 주의로 표기.
- AI 비서는 키워드 검색이라 표현이 크게 다른 질문은 "근거 없음"이 될 수 있다(오답보다 안전). 질문 로그 기반 보강은 별도 승인 후.
- 게시 전: (1) 운영 화면과 한 번 더 대조, (2) AI Agent·주간 시간표 배포 시 문서 상태/적용버전 갱신, (3) 홈페이지 게시·운영 DB 지식 등록은 별도 승인.
