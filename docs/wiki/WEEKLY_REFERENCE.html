3. 어법

4. 어휘
①target처럼 실제 대상 단어에 동일한 단일 밑줄을 적용한다.
빈칸
원문의 정확한 위치에 을 둔다.
순서/삽입
제시문은 일반 지문과 같은 크기와 굵기이며 볼드 처리하지 않는다.
13~14 공통지문
공통지문은 한 번만 제시하고 그 아래 두 문항을 연속 배치한다. 선택지는 충분한 가로 간격을 둔다.

문항 순서: 1 함축 의미 → 2 제목 → 3 어법 → 4 어휘 → 5~8 빈칸 → 9~10 순서 → 11~12 삽입 → 13~14 공통지문.
