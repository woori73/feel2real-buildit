# BUILD IT 오답 모의고사 제작 기준 (Wrong Mock Standard)

> Canonical source for 오답 모의고사 production (OpenCode/외부 LLM 공용).
> `GET /problem-generator/wiki/api/wrong-mock/ready`로 가져온 READY 회차의
> 원본 사진·제목 metadata와 함께 읽고, 아래 규칙대로 20문항 문제지와 간략해설을 만든다.
> 사진 제목·사진 내용·제작 규칙을 임의로 섞거나 추측하지 않는다.

## 기본 체제

- 한 회차는 **20문항**이다(예: 오답 24회).
- 회차 번호와 사진은 선생님이 직접 등록한 그대로 사용한다. 시스템이 임의로
  사진을 다른 회차로 이동하거나 다음 회차 문제를 끌어오지 않는다.
- 사진 개수와 문항 개수를 1:1이라고 가정하지 않는다. 한 사진에 여러 문항이
  있거나 한 문항이 여러 사진에 걸쳐 있을 수 있다.
- 새 문제지는 **1~20번으로 재번호 부여**한다. 원래 기출 번호를 새 시험의
  문제번호로 사용하지 않는다.
- 사진에 표시된 **정답을 읽어 사용**한다.
- 원문 문제 구조를 최대한 정확하게 복원한다.

## 문제지 조판

- 제목은 `오답 {N}회` 형식이다(예: 오답 24회).
- A4 세로, **2단 구성**, 불필요한 여백 최소화, 페이지를 최대한 활용한다.
- 지문/문항/선택지 잘림 금지. 문항 전체(번호+발문+지문+선택지)는 하나의 조판
  단위로 취급하며 부자연스럽게 분리하지 않는다.
- 문제번호 위에 **작은 출처**를 표시한다. 사진 제목 metadata에서 간략 출처만
  추출한다. 예: 원본 제목 `2021년 고3 3월 서울특별시교육청 학력평가 31번 빈칸`
  → 문제지 표시 `2021년 고3 3월 서울교육청`.
- 완성 HTML은 script 없이 저장되며, 저장된 바이트가 곧 보기/다운로드 정본이다.

## 간략해설 기준 Template

- `BUILD_IT_오답_23회_간략해설_A4_FINAL` 계열 디자인을 유지한다. 디자인을 새로
  만들지 않으며, 24회 이후도 동일 계열을 계승한다.
- **첫 페이지**: `오답 {N}회 · 정답 & 간략 해설` + 해당 20문항에서 추출한
  **전체 어휘**를 배치한다. 어휘는 단어시험용으로 **왼쪽 영어 / 오른쪽 한국어
  의미** 형식으로 구성하고 한 페이지를 최대한 활용한다.
- **이후**: 빠른 정답 1~20, 그리고 각 문제별 다음을 제공한다.
  - 문제번호 + 유형
  - 정답
  - 핵심어 1
  - 핵심어 2
  - RELATION = 주제
  - SKILL
  - 왜 이게 답인가

## 등록 계약 (사람 업로드 = OpenCode 자동 등록)

- 문제지와 간략해설은 `PUT /problem-generator/wiki/api/wrong-mock/rounds/{id}/artifacts`
  (`{paperHtml?, paperName?, explHtml?, explName?}`) 하나로 등록·교체한다.
- 두 artifact가 모두 갖춰지면 회차는 자동으로 제작완료가 된다.
- 등록 전 상태가 제작대기(READY)이고 편집이 잠겨 있으면(편집 OFF) 먼저
  `POST .../edit-lock` (`{locked:false}`)으로 편집 ON 전환이 필요하다.

## 최종 검수 체크

1. 20문항이며 1~20번으로 재번호 부여했는가?
2. 제목이 `오답 {N}회`인가?
3. A4 세로 / 2단 / 여백 최소 / 페이지 활용 최대인가?
4. 지문·문항·선택지가 잘리지 않았는가?
5. 문제번호 위에 작은 출처가 있는가(원래 기출 번호를 문제번호로 쓰지 않았는가)?
6. 정답이 사진 표시와 일치하는가?
7. 간략해설 첫 페이지에 정답&간략 해설 + 전체 어휘(영어/한국어)가 있는가?
8. 각 문제에 유형·정답·핵심어 2개·RELATION·SKILL·풀이가 있는가?
9. 인쇄 미리보기에서 A4 출력이 정상인가?

## 유지 원칙

- 이 MD를 오답 모의고사 제작의 공식 기준으로 관리한다. 기준이 변경되면 이
  파일을 갱신하고, 회차별 `spec_json`(`wrong_mock_rounds.spec`)도 같은 내용이다.
- `BUILD_IT_오답_23회_간략해설_A4_FINAL` HTML 자체는 기준 Template이며,
  24회 이후 해설지도 동일 계열 디자인을 유지한다.
