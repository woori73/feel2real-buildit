# 내신위키 수업 인사이트 카드 정상화 — 검증

- 원인: 기록 본문 `<p>`가 `.material-list > article`(flex 가로 행)의 직계 자식으로 meta grid `div`와 나란히 놓여, 가로 공간을 나눠 가지며 날짜 열이 한 글자 폭으로 눌림. 저장 데이터는 정상(렌더 버그).
- 수정: 독립 카드(`.insight-card`) 세로 스택 — 유형 배지+일시(한 줄, 초 제외) → 학교·학년·학기·시험(1회, 빈 값 생략) → 학생/수업 맥락 → 본문(`pre-wrap`, `overflow-wrap:anywhere`). 본문은 React 텍스트 노드(XSS 안전, 변형 없음).
- 스크린샷: pc-1280 / tablet-768 / mobile-390 (route mock 데이터: 멀티라인, 영문 혼합, 긴 단어, `<script>` 문자열, 학교 정보 없는 옛 기록). 가로 스크롤·중복·오버플로 없음, 새로고침 후 동일.
- DB·기존 기록 변경 없음.
