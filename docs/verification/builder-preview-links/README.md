# 빌더 미리보기 로고 클릭 오류 + 초기화 안내 — 검증

- **재현(수정 전)**: 전체 화면 미리보기(iframe `/tutor/academy/preview`)에서 로고(`<a href="/academies/{slug}">`)를 누르면 iframe이 공개 주소로 이동한다. 공개 전 초안은 "공개 Academy를 찾을 수 없습니다"만 보이고(before-logo-click-error.png), 공개 중이어도 미리보기가 아니라 옛 공개본으로 바뀐다. 운영에서는 이동한 문서가 프레임에서 표시되지 못해 회색 오류 화면으로 보일 수 있다.
- **수정**: 작업본 미리보기에서만 링크 클릭을 가로챈다 — 같은 페이지로 가는 링크(공개 주소·`/`)는 맨 위로 스크롤, 같은 사이트의 다른 경로는 차단, 외부는 새 탭, `#`·tel·mailto 유지.
- **검증(실제 브라우저, PC 1280·모바일 390, 공개 전 초안·공개 중 학원)**: 로고 클릭 후 URL 유지, 맨 위 스크롤, 오류 문구 없음, JS 오류 없음 (logo-fixed-*.png).
- **초기화 안내 버그**: 공개한 적 없는 초안에서 저장점 없이 '초기화'하면 비어 있는 공개본으로 되돌려 만든 디자인이 통째로 사라졌다(MySQL 테스트로 재현). 이제 안내만 하고 작업본은 바꾸지 않는다. 공개 중이면 "공개 중인 홈페이지 내용" 기준으로 복원하고 그렇게 안내한다.
