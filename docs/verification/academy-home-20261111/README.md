# 학원 홈 · 출결 · 학생 · 정보 검증 (2026-11-11)

모든 캡처와 자료는 합성 테스트 값이다(학생 `테스트가`·`신규가`·`동명나` 등, 연락처 `010-0000-00xx`, 자료는 `e2e/academy-home/make_test_docs.py`로 생성). 운영 DB·S3·운영 자료·실명은 쓰지 않았다.

## 환경

- 이 작업 브랜치 BuildIt bootJar(`local` 프로필, Flyway 전체 + V1107, `ddl-auto=validate`) + 같은 날짜 AcademyCraft 작업 브랜치 JAR(MySQL Flyway V1~V6, `frontend/` 정적 경로)
- DB: 로컬 MySQL 8.0.46 새 스키마 `f2r_unified_test`·`ac_unified_test`(작업 컨테이너에 Docker 데몬이 없어 `mysql:8.4` 대신 OS 패키지 MySQL 8.0 사용)
- 시드: `e2e/unified-assistant/fixtures.sql` → `e2e/academy-home/fixtures.sql` → `e2e/academy-home/seed.sh`(학생명단 2026 docx·pdf, 학원이사 PDF·중요 과제, 기록에 붙이지 않은 스캔 PDF)
- 브라우저: Playwright Chromium, 데스크톱 1440×1000, 휴대폰 iPhone 13 에뮬레이션, `Asia/Seoul`

## 결과 (`node e2e/academy-home/run.cjs`, 새 DB에서 18/18 통과)

`results.json` 참조. 데스크톱·휴대폰 각각:

1. 학원 홈 첫 화면: 학원명(다중 학원 관리자는 선택 상자만), 재원생 n명 링크, 진행 중/다음 수업 배너, 오늘 수업 시간순, 학생 챙기기, 이번 주 중점 업무. 고정 메뉴·승인 카운터·캐릭터·플로팅 버튼·첨부·재무 KPI 없음, 가로 스크롤 없음
2. 홈 재원생 수 = 학생 명단 `재원생 전체 n명` = 명단 행 수
3. 배너 「출결부 열기」 → `ATT-03?classId=&date=` 자동 조회(배너 수강생 수 = 출결부 인원) → 행에서 출석(휴대폰은 지각)+메모 저장 → 새로고침 후 유지
4. 정정: 닫힌 상태로 시작, 사유 없이 저장 불가(필수 입력), 사유 입력 후 정정 → 새로고침 후 「정정됨」

그 밖:

5. 학생 상세(소속 반·상담 표시) → 한 폼에서 학교 수정 → 새로고침 후 유지
6. 반 필터 인원 < 전체 인원, 목록 수 = 반 필터 인원
7. 강사 연결 계정: 홈 표시, 중점 업무는 노출 안 함, 학생 수정은 「권한」 안내(403)
8. 학원 전환: 숫자가 바뀌고 빈 학원은 「오늘 등록된 수업이 없습니다」·재원생 1명, 다시 원래 학원
9. stats 500 → 「재원생 조회 실패」, 403 → 「재원생 조회 권한 없음」(0명 표시 안 함)
10. `/dashboard#ai` → `/dashboard/assistant#ai`, `/dashboard?ask=` → 비서 입력칸만 채움, `/dashboard#all` → 홈
11. 키보드 Tab으로 상단 메뉴·재원생 링크·출결부 열기 도달
12. 정보(데스크톱·휴대폰): 학생명단 docx 본문 → 열 제목 표, 학원이사 PDF → 1쪽·2쪽 순서, 스캔 PDF → OCR 필요 사유만(지어낸 본문 없음), 긴 파일명 줄바꿈, 가로 스크롤 없음
13. 명단 반영: 보류 행 학생 연결 → 기존 +1, 비활성 동명 학생 행 제외 → 제외 +1, 추가 후보 1명 → 초안 → 승인 → 새 레코드 ID로 연결(기존 +1, 추가 후보 0), 새로고침·재대조해도 같은 수(중복 없음), stats `studentCount` +1 = `/students` 고유 인원

## 확인하지 못한 것

- 운영 자료(원장이 실제 올린 파일)로 원문 → 연결 레코드 → 정보 본문 대조: 운영 DB·S3에 접근하지 않았다. 배포 후 관리자 계정으로 `/dashboard/info`에서 확인 필요.
- 실제 휴대폰 기기·iOS Safari(에뮬레이션만), 화면 낭독기.
- 글자 인식(OCR): 서비스에 OCR이 없어 스캔·이미지는 원본 확인만 제공한다.
- AcademyCraft 서버 시각: 이 환경 JVM은 UTC라 출결 기록 시각이 UTC로 보였다(`docs/attendance-timezone.md` 기존 이슈, 이번 변경 범위 밖).
