# 홈 첫 화면·맞춤문제 서비스 정리 화면 확인 (2026-11-01, 2차)

`home-redesign-20261101`(1차 밝은 개편) 위에 사용자 요청을 반영한 뒤 찍은 화면이다.

## 바뀐 것

- 배너를 줄이고 오른쪽에 서수니·세븐이 나오는 20초 홍보 영상과 「1장 무료 신청」·「맞춤문제 신청」 버튼을 둔다. 배너는 3초마다 넘어간다.
- 맞춤문제 배너는 압구정중3 기말 적중 사례(실제 시험 13번 ↔ 시험 전 예상문제 7회 15번)를 보여 준다. 다른 배너는 실제 화면(위키·복습 게임·트레일러 포스터)을 쓴다.
- 배너 아래 입시상담 AI(서수니 상담사, `/admissions/guide`) 버튼.
- 영어 교육 카드 4개: 맞춤문제(홍보 영상의 세븐 장면) · 모의고사 위키 · 영어 복습 게임(실제 화면) · New iBT(`/testprep`). 지문 복습 문제·문법 문제은행 카드는 뺐다.
- 맞춤문제 2만원 서비스(신청·적중 사례·제작 과정·활용 사례·블로그·이용료와 무통장입금·문의·이용 방법)를 한 영역(`#service`)으로 모았다.
- 상단 메뉴에 대시보드를 넣고, 빌드잇 차트·대시보드는 페이지 맨 아래로 옮겼다.
- 화면을 따라 움직이는 바로가기: 「AI 비서」(서수니·세븐 동그란 사진) + 「맞춤문제 신청」. 960px 이하는 화면 아래 고정 막대.
- 신청 화면(`/exam-service`, 보호자 확인, 정책)을 홈과 같은 밝은 색으로.

## 찍은 방법

실제 Thymeleaf 템플릿 렌더 + 저장소 정적 파일, Pretendard v1.3.9, 계좌 공개 상태, 배너 자동 넘김 멈춤. 빌드잇 차트 TOP5는 화면 확인용 예시 3건이다.

## 확인한 것

- 6개 폭 모두 가로 넘침 0, 상단 로고·메뉴·버튼 겹침 없음(대체 글꼴 포함, 상단 링크는 1401px 이상에서만 보이고 그 아래는 바로가기 줄).
- 첫 화면 안에 「맞춤문제 1장 무료 신청」이 보이고, 휴대폰 아래 고정 막대에 가리지 않음. 홍보 영상은 모든 폭에서 첫 화면 안에서 시작.
- 배너 4장 높이가 같다(넘길 때 아래 내용이 움직이지 않음).
