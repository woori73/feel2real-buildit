# 빌더(대화형) 초기화·새 홈페이지·변경 기록 정리 — 검증

## 기능 분리
| 기능 | 버튼 | 범위 | 서버 |
|---|---|---|---|
| 새 홈페이지 만들기 | 새 홈페이지 | 새 요청으로 새 초안(디자인+문구)을 작업본에 한 번의 수정으로 적용. 공개본·버전 기록·저장점 유지 | `POST /restart` |
| 수정 내용 초기화 | 수정 초기화 | 저장하지 않은 변경만 취소 → 마지막 저장 상태(없으면 공개본 기준) | `POST /reset` |
| 되돌리기/다시 실행 | 되돌리기 | 직전 변경 1단계. 초기화·새 홈페이지도 되돌릴 수 있음 | `POST /undo`·`/redo` |

## 실제 브라우저(Playwright, 로컬 앱+MySQL, TUTOR 계정) 결과 — e2e3
저장 표시, 수정 반영, "저장 안 됨" 표시, 초기화 범위 안내, 초기화=마지막 저장 복원, 되돌리기(초기화 취소)와 독립, 게시 후 공개 URL 200, 새 홈페이지 패널(기존 대화·미리보기 숨김, 안내 문구), 새로고침 시 대기 상태 미복원, 새 홈페이지 적용(ENGLISH→ARTS), 이전 대화 접힘·새로고침 후에도 경계 유지, 공개본은 게시 전까지 불변, 되돌리기로 새 홈페이지 취소, 모바일 390 — 모두 PASS, JS 오류 0.
