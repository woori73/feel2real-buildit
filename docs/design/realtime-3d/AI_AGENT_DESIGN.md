# Feel2Real AI Agent 공통 공간 디자인

홈·대시보드는 동일 GLB·카메라·영상 소유권을 공유한다. Studio는 영상과 자료 열람을 우선하며 이 팔레트와 패널 규칙만 사용한다. Studio에서 Three.js 번들을 로드하거나 자료 카드마다 WebGL 문맥을 만들지 않는다.

| 공통 요소 | 기준 |
|---|---|
| 배경·표면 | `--f2r-space-bg` #050d17 / surface #0a1928 |
| 텍스트·경계 | text #c7e7f7 / border #284253 |
| 대기 | idle #5de1ff |
| 듣기·말하기 | active #bb8aff |
| 분석 | thinking #ffca77 |
| 완료·오류 | done #7df0b2 / error #ff9999 |
| 패널 | 얇은 경계, 반투명 딥네이비, 6px 모서리, 명확한 포커스 |
| 동작 | 44px 이상 터치 영역, 상태 문구와 색상 함께 표시 |
| 모션 | 부드러운 카메라 감쇠, 최대 30fps, reduced-motion은 2D |
| 영상 | 승인 얼굴·음성·재생 제어를 기존 코드가 소유; Studio는 16:9 플레이어 |

CSS 토큰의 단일 원본은 `static/css/f2r_spatial.css`이며 Three.js 상태 조명도 해당 변수를 읽는다. 서비스 선택 버튼의 이름·기존 이벤트·접근 권한은 유지한다. 색으로 승인 여부를 추정하지 않으며 서버의 승인 상태를 표시한다.

모바일은 좁은 시야에서도 6개 패널을 유지하고 대화 입력을 가리지 않는다. WebGL 미지원·저사양·데이터 절약 모드에서는 기존 2D를 제공한다. Studio 메뉴는 ‘결과물 보기 / 자료 올리기’에 적용 가능한 경량 DOM 스타일로 제한한다. 이 문서는 Studio 백엔드 구현 완료를 의미하지 않는다.
