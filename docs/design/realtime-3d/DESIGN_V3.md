# PR #902 디자인·모바일 개선 v3

2026-10-25 / ChatGPT Work 직접 제작. GPU·WebGL 성능 시험은 사용자 방침에 따라 보류하며 반복하지 않았다. PR Draft 유지, 병합·운영 배포 없음.

## 구현 결과

- 기존 Three.js·GLB·VideoTexture 구현을 유지한다. PC는 실제 메시와 연결된 입체 패널 6개를 유지하고, 작은 무대(너비 600px 미만)는 같은 버튼을 아래 3열·2행 도크로 배치한다. 좁은 화면에서 불필요한 3D 패널 메시만 숨기고 중앙 무대·링·연구시설은 유지한다.
- 기존 버튼 노드·접근 가능한 이름·이벤트를 재사용한다. 2D 전환 시 원래 부모와 순서로 복원한다. 좁은 무대에서는 배경 패널 Raycaster를 끄고 눈에 보이는 도크 버튼으로 선택한다.
- 영상 평면을 8.4×4.8로 확대해 원본 1344×768 비율을 유지한다. 아래쪽과 양 끝 배경만 알파로 연결하고 얼굴 중심 RGB·승인 원본 파일·음성은 수정하지 않는다. VideoTexture·포스터 재질은 depthWrite=false로 투명 배경이 뒤쪽 구조를 가리지 않도록 한다.
- 시설 조명은 낮은 밝기의 고정 재질로 분리하고 링·상호작용 요소에 상태 색을 집중한다. WebGL의 PBR 재질에는 ACES 톤 매핑을 적용하되 승인 영상은 toneMapped=false를 유지한다.
- 모바일 홈 대화 영역은 내부 스크롤로 제한해 입력·보내기 버튼이 화면 안에 보인다. 대시보드 업무 안내 중에는 무대를 소폭 줄여 학년 선택 등의 대화 버튼 공간을 확보한다.
- PC 패널 버튼은 카메라가 움직여도 헤더·하단 이름표를 피해 무대 경계 안에 배치한다. 터치·키보드 포커스 표시를 유지한다.
- WebGL 미지원 시 기존 2D를 유지한다. SVG는 명시적인 디자인 검수 모드에서만 사용하며 이 모드는 WebGL 문맥 생성을 시도하지 않는다.

- 홈: AI 영어교육→/grammar-items·/wiki, 예상문제→기존 카카오 의뢰·적중 사례, 모의고사위키→/wiki, 업무→기존 대시보드 전달, AI AGENT→/ai-agent-studio, 홈페이지→/builder. 여섯 버튼을 실제 클릭해 기존 안내·액션을 확인했다.

- 대시보드: 학생 등록(검수학생 입력→학년 선택), 출결(확인/기록), 상담(격리 자료에 학생 없음 안내), 학습자료(유형 선택), 공지(제목 입력), 운영 현황(목 응답). 운영 DB에 연결하거나 실제 업무를 저장하지 않았다.
- 390px 학생 등록 단계의 11개 선택 버튼(9개 학년·건너뛰기·그만두기)이 대화 스크롤 영역 안에 모두 들어오는 것을 확인했다.
- 기존 비서 선택·승인 인사 영상·고정 음성·대화·서비스 API 코드는 변경하지 않았다. 세븐·서수니 선택 기능과 원래 자료 누락 대체 표시를 유지한다.
