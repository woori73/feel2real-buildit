# 내신 실전 연습 (`/naesintest`)

압구정중 2학년 2학기 기말 대비 F2R 예상문제를 실제 시험처럼 시간을 재어 풀고, 제출 뒤 문항별로 채점해 틀린 문제를 해설로 복습하는 화면.

## 요구(2026-11-15)
- 1회 40문항, 시간 20분(문항당 30초). 원본이 70문항인 종합 11~13회는 원본대로 70문항 35분.
- 풀이 중에는 해설을 보여 주지 않는다(실제 시험 환경).
- 제출 후 문항별 채점, 틀린 문제 해설로 복습.
- TestPrep(New iBT / Digital SAT)과 분리된 별도 주소 `feel2real.co.kr/naesintest`, 한국 학교 시험 느낌의 화면.

## 구조
- 데이터·응시·채점은 TESTPREP(`tp_exams`/`tp_questions`/`tp_attempts`)와 `/api/testprep/**`를 그대로 쓴다(`kind='NAESIN'`). 새 표는 없고 `tp_questions.points`만 추가(V1115).
- 화면: `NaesinTestPageController` + `templates/naesintest/{home,run,review}.html` + `static/js/naesin_{common,home,run,review}.js` + `static/css/naesin.css`.
- 문항은 원본 PDF를 문항 단위로 자른 그림(webp)이다. 밑줄·<보기> 상자·Ⓐ~Ⓓ 표시를 원본 그대로 보여 주기 위해서다. 그림 경로는 `/naesin/...webp`만 허용한다(`NT.imgPath`).
- 접근: 목록은 공개, 시험·채점 화면과 문항 그림은 로그인 회원(STUDENT/TUTOR/ADMIN).

## 화면
- 목록: 시험지 머리 표(과목·학년·범위·회차), 응시 안내, 범위별(Lesson 7 / Lesson 8 / Lesson 7·8 종합 / Final) 표. 로그인 회원에게는 회차별 최근 점수와 이어 풀기를 보여 준다.
- 시험: 시험지 머리 표에 남은 시간. 왼쪽 시험지(문항 그림 폭 480px(글자 크기를 OMR 답안지와 비슷하게), 공통 지문, 문항 아래 실제 OMR 한 줄 모양의 답란: 번호 칸 + 세로 타원 1~5), 오른쪽 OMR 답안지(분홍빨강 인쇄, 사인펜처럼 검게 칠함, 번호 누르면 이동). 좁은 화면에서는 답안지가 아래에서 올라온다. 숫자 1~5·좌우 화살표 지원. 실제 OMR처럼 칠한 칸을 다시 눌러도 지워지지 않는다(바꾸려면 다른 칸). 답은 바로 저장(`PUT …/answers`), 시간이 끝나면 자동 제출. 저장과 제출 요청은 한 줄로 세워 하나씩 보낸다(같은 문항 동시 저장 방지).
- 채점: 빨간 펜 점수(맞힌 배점/만점), 문항별 ○/╱ 표, “틀린 문제/전체” 전환, 문항마다 내 답·정답·배점·해설(정답 줄, 풀이, 근거, 어법 포인트).

## 시간 계산
서버 마감은 7200초로 두고, 화면은 `경과 = 7200 − 서버 남은 시간`으로 시작 시각을 되살린 뒤 `문항 수 × 30초`에서 뺀다. 새로 고침하거나 나갔다 와도 시간이 이어진다.

## 발음부호 문항 수정(2026-11-15, V1117)
- 정답 보기가 강세 위치만 틀린 24문항을 "강세는 맞고 발음부호 하나가 틀린" 보기로 바꿨다(정답 번호·배점 그대로). 문항 그림을 다시 만들고 해설 첫 단락을 고쳤다.
- 원본 PDF(문제지·정답 해설)도 같은 내용으로 고쳐 사용자에게 전달했다.

## 학교별 페이지·이용 범위·안내(2026-11-15)
- `/naesintest`는 학교 고르기 + 서비스 안내(광고·사업계획서에도 쓰는 설명). 이용 방법 5단계마다 실제 화면 그림(`static/img/naesintest/step-*.webp`), 휴대폰 화면 3장(`mobile-*.webp`). 모든 화면 위쪽에 F2R영어 로고. 학교는 `NaesinTestPageController.SCHOOLS`와 `naesin_common.js`의 SCHOOLS에 함께 등록한다. 문제가 없는 학교는 준비 중.
- 학교별 회차 목록은 `/naesintest/school/{slug}`. 시험·채점 화면의 목록 단추는 그 학교 페이지로 돌아간다.
- 일반 회원은 1회만(서버 403, 2회부터 시작 단추는 '재원생 전용'), 관리자·압구정에듀홀릭 재원생은 전 회차.

## 모두 고르기 문항(2026-11-18)
- "~을 모두 고르면?" 문항은 `task_type='NAESIN_MC5_MULTI'`, 정답은 `answer_key='B,D'`처럼 쉼표로 잇는다.
- 시험 화면: 답란·OMR 답안지에서 칸을 여러 개 칠할 수 있고, 칠한 칸을 다시 누르면 지워진다(한 개 고르기 문항은 기존대로 다시 눌러도 지워지지 않음). 답은 기호 순서대로 `B,D`로 저장한다. 답란 아래에 "답을 모두 칠하세요" 안내가 나온다.
- 채점: 고른 묶음과 정답 묶음이 순서와 상관없이 같아야 정답(하나라도 빠지거나 더 고르면 오답). `TestPrepService.isMultiChoiceCorrect`.
- 채점 화면: 내 답·정답을 `②, ④`처럼 보여 준다.

## 예비고1 디지털 수능 영어 모의고사 2부 — 고1 실전 독해 모의고사 1~22회(2026-11-20)
- `/naesintest/pre-high` 2부 표: 회차마다 `열기`. 관리자 계정에만 `PDF`(전체 문제지 내려받기, `/api/admin/pre-high-english/part2/{n}/paper.pdf`) 칸이 보인다(2026-11-20 관리자 전용으로 변경). 원본은 고1 사설 모의고사 10회의 18~45번을 수능 논리로 바꾼 F2R 변형문제(다른 세션 2차례 감수).
- 문항 발문 옆 출처 표기, 문제지 표지의 '원본:' 줄, 2부 목록의 'OO 변형' 문구는 넣지 않는다(이미 변형한 문항, 2026-11-20). round.json의 source는 내부 기록용으로만 남긴다. 해설의 [유형 전략] 아래에 문항마다 '이 문항의 단서' 한 줄이 있다.
- 흐름은 1부와 같다: 독해(28문항, 45분, 화면 번호 18~45) → 독해 제출 → 어휘 50문항(영어 단어를 보고 뜻 5지선다, 문항당 5초) → 채점. 2부 채점 화면은 처음부터 전체 문항을 보여 준다(1부는 틀린 문항만).
- 채점 뒤 문항마다 문제지 그림 위에 정답 근거를 노란색(`evidence`)으로, 정답 선택지·밑줄을 파란 테두리(`answer`)로 표시하고, 그 아래에 해설지(정답·유형 전략·풀이 과정·정답 근거·어법 포인트·오답 분석·어휘)를 붙인다.
- 근거 좌표는 제작 스크립트가 문항 그림과 같은 화면에서 해설이 인용한 영어 구절의 위치를 재어 만든다(가로·세로 1/10000). 어휘 50문항은 그 회차 해설 어휘에서 고르고 오답 뜻은 같은 회차의 다른 낱말 뜻이다.
- 자료: `src/main/resources/prehigh-part2/r01~r22/`(정적 공개 경로가 아님). `PreHighPart2Store`가 읽고 검증한다(28문항·50단어·좌표 범위).

- 11~22회(2026-11-20 추가): 고1 학력평가 12회분(2019~2021년)의 18~45번을 같은 방식(수능 논리 변형·유형 전략 해설·노란 근거·어휘 50문항)으로 바꾼 F2R 변형문제. 문제지·해설지·목록에 원본(출처)은 적지 않는다. 다른 세션 2차례 감수.
- 문제지 배치: 단 나누기를 한꺼번에 정해(반쯤 빈 단을 피함) 8쪽 이하로 만들고, 41~42 지문과 문항, 43~45 장문은 각각 한 쪽에 둔다. 문항 하나만 있는 단은 문항 안 간격을 넓혀 채운다(MEMO 줄 없음).

## 예비고1 디지털 수능 영어 모의고사 6부 — 고2 실전 독해 모의고사 1회(2026-11-22)
