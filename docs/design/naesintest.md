# 내신 실전 연습 (`/naesintest`)

압구정중 2학년 2학기 기말 대비 F2R 예상문제를 실제 시험처럼 시간을 재어 풀고, 제출 뒤 문항별로 채점해 틀린 문제를 해설로 복습하는 화면.

## 요구(2026-11-15)
- 1회 40문항, 시간 20분(문항당 30초). 원본이 70문항인 종합 11~13회는 원본대로 70문항 35분.
- 풀이 중에는 해설을 보여 주지 않는다(실제 시험 환경).
- 제출 후 문항별 채점, 틀린 문제 해설로 복습.
- TestPrep(New iBT / Digital SAT)과 분리된 별도 주소 `feel2real.co.kr/naesintest`, 한국 학교 시험 느낌의 화면.

## 구조
- 데이터·응시·채점은 TESTPREP(`tp_exams`/`tp_questions`/`tp_attempts`)와 `/api/testprep/**`를 그대로 쓴다(`kind='NAESIN'`). 새 표는 없고 `tp_questions.points`만 추가(V1115).
- 화면: `NaesinTestPageController` + `templates/naesintest/{home,run,review}.html` + `static/js/naesin_{common,home,run,review}.js` + `static/css/naesin.css`.
- 문항은 원본 PDF를 문항 단위로 자른 그림(webp)이다. 밑줄·<보기> 상자·Ⓐ~Ⓓ 표시를 원본 그대로 보여 주기 위해서다. 그림 경로는 `/naesin/...webp`만 허용한다(`NT.imgPath`).
- 접근: 목록은 공개, 시험·채점 화면과 문항 그림은 로그인 회원(STUDENT/TUTOR/ADMIN).

## 화면
- 목록: 시험지 머리 표(과목·학년·범위·회차), 응시 안내, 범위별(Lesson 7 / Lesson 8 / Lesson 7·8 종합 / Final) 표. 로그인 회원에게는 회차별 최근 점수와 이어 풀기를 보여 준다.
- 시험: 시험지 머리 표에 남은 시간. 왼쪽 시험지(문항 그림은 실제 시험지 크기 358px, 공통 지문, 문항 아래 실제 OMR 한 줄 모양의 답란: 번호 칸 + 세로 타원 1~5), 오른쪽 OMR 답안지(분홍빨강 인쇄, 사인펜처럼 검게 칠함, 번호 누르면 이동). 좁은 화면에서는 답안지가 아래에서 올라온다. 숫자 1~5·좌우 화살표 지원. 실제 OMR처럼 칠한 칸을 다시 눌러도 지워지지 않는다(바꾸려면 다른 칸). 답은 바로 저장(`PUT …/answers`), 시간이 끝나면 자동 제출. 저장과 제출 요청은 한 줄로 세워 하나씩 보낸다(같은 문항 동시 저장 방지).
- 채점: 빨간 펜 점수(맞힌 배점/만점), 문항별 ○/╱ 표, “틀린 문제/전체” 전환, 문항마다 내 답·정답·배점·해설(정답 줄, 풀이, 근거, 어법 포인트).

## 시간 계산
서버 마감은 7200초로 두고, 화면은 `경과 = 7200 − 서버 남은 시간`으로 시작 시각을 되살린 뒤 `문항 수 × 30초`에서 뺀다. 새로 고침하거나 나갔다 와도 시간이 이어진다.
