# F2R AI 운영 대시보드 (`/dashboard`)

ADMIN·TUTOR 공용 통합 대시보드를 캐릭터 비서(세븐·서수니)가 대화하며 업무를 안내하는 운영 화면으로 바꾼 구조와 자료 규칙.

## 화면

| 화면 | 진입 | 내용 |
|---|---|---|
| AI 대화 (기본) | `/dashboard`, `/dashboard#ai` | 캐릭터 + 홀로그램 업무 선택 → 말풍선 → 대화 → 입력창(한 화면, 대화만 안에서 스크롤) |
| 전체 대시보드 | 상단 `전체 대시보드`, `/dashboard#all` | 학원 업무 메뉴, 핵심 지표, 상세 위젯, AI 업무 지휘창(자료 분석·직접 입력·목록·감사로그) |

- 첫 화면에는 캐릭터·인사/상태·대화·입력창만 둔다. 업무 상태(승인 대기 건수 등)·사업체 선택·사용법 안내·AI AGENT 제작협업실·F2R 서비스 목록·캐릭터 자료 올리기(ADMIN)는 `메뉴`(오른쪽 시트)에 있고, 1280px 이상 PC에서는 오른쪽에 늘 펼쳐 둔다.
- 색: 배경 `#081426` · 패널 `#122944` · 대기/안내 `#5DE1FF` · 대화/창작 `#BB8AFF` · 분석/확인 `#FFCA77` · 완료 `#7DF0B2`. 캐릭터 테두리·상태 표시·말풍선 테두리가 상태 색을 따른다.
- 좌측 `F2R` 로고는 홈(`/`)으로 이동한다. 입력 중인 내용이 있으면 기존 `service_home_navigation.js` 확인창이 뜬다.
- 메뉴의 `AI AGENT 제작협업실` 링크는 PR #892 구현(`data-studio-entry`, `studio_entry_link.js`, `/api/studio-access`)을 그대로 쓴다. 기본 hidden이며 ADMIN·modu만 보인다.
- `사용법 안내`는 언제 눌러도 1단계부터 다시 열린다(화면 위쪽에 뜬다).
- 대화·초안·승인·저장은 기존 `unified_assistant.js` + `/api/dashboard/assistant/v1`을 그대로 쓴다.

## 캐릭터 대화 콘솔

| 상태 | 언제 | 영상 |
|---|---|---|
| 대기 | 처음, 응답 표시가 끝난 뒤 | `idle.mp4` |
| 듣는 중 | 입력창에 글을 쓰는 동안 | `idle.mp4` + 테두리 표시 |
| 생각 중 | 보낸 뒤 응답을 기다리는 동안, 승인 실행 중 | `think.mp4` + 스캔선 |
| 답변 표시 중 | 응답을 캐릭터 아래에 표시하는 동안 | `idle.mp4` (음성 미연결 시 말하는 영상을 쓰지 않음) |
| 업무 완료 | 승인한 초안이 저장 검증 완료로 바뀐 직후 | `idle.mp4` + 완료 테두리 |

- 영상은 두 개의 `<video>`를 번갈아 써서 다음 영상이 재생 준비된 뒤 겹쳐 바꾼다. 같은 녹화본에서 자른 구간만 쓰므로 얼굴이 갑자기 바뀌지 않는다.
- 응답 말풍선에는 관련 서비스 열기 버튼과 `… 초안 확인하고 승인` 버튼이 붙는다. 승인 버튼은 대화 기록의 실제 초안 카드로 이동하며, 실행은 카드의 기존 승인 버튼으로만 한다.
- 캐릭터 위 표시: 승인 대기·처리 완료·확인 필요 건수(대화 기록 카드 상태에서 계산), 연결된 서비스, 정본 승인 상태.
- 비서를 바꿔도 대화 기록·업무 학원·사업체·진행 건수는 그대로 둔다(화면 연출만 바뀜).
- 모바일은 화면 높이(`100dvh`, `interactive-widget=resizes-content`) 안에 캐릭터·말풍선·대화·입력창을 배치한다. 키보드가 열려 높이가 560px 아래로 줄면 캐릭터 무대를 접고 입력창 옆 작은 얼굴로 대신한다.

## 홀로그램 업무 선택과 단계별 안내 (`f2r_agent_flows.js`)

캐릭터 양옆의 홀로그램 버튼을 누르거나, 세부 내용 없이 "학생 등록하고 싶어"처럼 말하면 비서가 한 번에 하나씩 묻는다. 새 업무 기능을 만들지 않고 기존 API로 연결한다.

| 버튼 | 묻는 순서 | 연결 |
|---|---|---|
| 학생 등록 | 이름 → 학년(선택) → 학교 → 학부모 이름 → 연락처(건너뛰기 가능) → 확인 | `POST /drafts` `STUDENT_CREATE` 초안 → 기존 승인 카드 |
| 출결 | 확인/기록 → 학생(이름 검색·목록) → [기록] 출결 구분 → 메모 | 확인: `/conversation` "학생 ID n 출결 조회해줘"(조회만) · 기록: `ATTENDANCE_RECORD` 초안 |
| 상담 기록 | 학생 → 제목 → 내용 → 확인 | `CONSULT_CREATE` 초안 |
| 학습자료 | 학습자료/시험자료/전체 | 기존 `/tutor/conversation/materials` 화면 링크(강사 계정) |
| 공지 초안 | 제목 → 내용 | `/conversation` 공지 초안(저장·발송 없음) |
| 운영 현황 | — | `/conversation` "학원 운영과 재무 현황 보여줘" |

- 이름·ID·`항목:` 형식이 이미 들어 있는 요청은 기존 대화 분석(`/conversation`)으로 보낸다.
- 저장은 초안 카드의 `승인하고 실행`을 눌렀을 때만 일어난다. 초안 생성·조회 실패는 숨기지 않고 `다시 시도`·`전체 대시보드에서 처리`를 보여준다.
- 첫 방문(진행 기록 미완료)에는 팝업 대신 비서가 대화로 묻는다: `AI 비서와 업무 시작` · `AI 영어교육` · `AI AGENT 제작협업실` · `나중에`. 고르면 다시 묻지 않고, 메뉴의 `처음 안내 다시 보기`로 다시 연다. 6단계 `사용법 안내`는 메뉴에서 연다(화면 위쪽에 뜸, 입력창과 겹치지 않음).
- 홈페이지에서 넘어온 요청 문장은 입력창에만 채운다(자동 전송 없음).

### 음성·립싱크 연결 지점

```js
window.F2RAgentVoice.register({
  speak(text, { agent }) { /* TTS 재생, 끝나면 resolve */ return Promise.resolve(); },
  lipSync: false  // true이고 speak.mp4가 있으면 응답 중 말하는 영상을 쓴다
});
```

### 인사 영상 (speak.mp4)

- `{seven|suni}/speak.mp4`는 음성과 입 모양을 함께 만든 **고정 대사 한 편**이다.
  - 세븐: "세븐입니다. Feel to Real에 오신 걸 환영합니다. 무엇을 도와 드릴까요?"
  - 서수니: "서수니입니다. Feel to Real에 오신 걸 환영합니다. 무엇을 도와 드릴까요?"
- 홈(`/`)과 대시보드(`/dashboard`)에 `speak.mp4`가 있으면 "{이름} 인사 듣기" 버튼이 보인다(선택한 캐릭터에 speak.mp4가 있을 때). 소리 있는 재생은 이 버튼을 누른 뒤에만 시작한다(모바일 자동재생 정책).
- 재생 중: 상태 표시 `말하는 중`, 버튼 비활성(중복 재생 없음). 끝나거나 실패하면 대기 영상(소리 없음·반복)으로 돌아간다.
- 다른 캐릭터 선택·새 질문 전송·탭 숨김·페이지 이탈 시 인사를 멈춘다. 캐릭터마다 자기 영상만 재생한다(세븐·서수니 영상이 바뀌지 않음).
- 일반 응답 문장에는 입 모양이 맞지 않으므로 `speak.mp4`를 쓰지 않는다(립싱크 어댑터 규칙 그대로).

연결 전에는 `텍스트 응답 · 음성 미연결`로 표시하고 응답 중에도 대기 영상만 쓴다.

## 캐릭터 자료: 비공개 폴더

공개 저장소에는 얼굴 자료를 두지 않는다. 운영 서버의 폴더를 `APP_AGENT_MEDIA_DIR`(= `app.agent-media.dir`)로 지정하면 로그인한 ADMIN·TUTOR에게만 `/dashboard/agent-media/**`로 제공한다.

```
{APP_AGENT_MEDIA_DIR}/
  manifest.json   {"seven":{"status":"CANDIDATE"},"suni":{"status":"REFERENCE_APPROVED"}}
  seven/  idle.mp4  think.mp4  poster.jpg  front.webp  half.webp   speak.mp4(세븐 인사 영상)
  suni/   idle.mp4  think.mp4  poster.jpg  front.webp  half.webp   speak.mp4(서수니 인사 영상)
```

| status | 화면 표시 | 의미 |
|---|---|---|
| `APPROVED` | 표시 없음 | 대표가 정본으로 승인한 자료 |
| `REFERENCE_APPROVED` | 승인 얼굴 기준 · 영상 확정 전 | 승인된 얼굴을 기준으로 만든 후보(서수니 현재 상태) |
| `CANDIDATE` | 외형 승인 전 후보 | 외형 자체가 승인 전(세븐 현재 상태). manifest 누락·오타도 이 값 |
| `MISSING` | 캐릭터 자료 미연결 | 파일 없음 → H-07/SUNI 표식 |

자료 묶음: `F2R_AGENT_DASHBOARD_V2.zip`의 `agent-media-private/`(Reactor Helios 녹화 재사용, 추가 생성 없음).

### 운영 서버 설치

1. 배포(`Deploy to EC2`)가 `/home/ec2-user/agent-media`(ec2-user, 750)를 만들고, `/etc/f2r/env`에 `APP_AGENT_MEDIA_DIR`이 없을 때만 그 경로를 기록한다(env는 배포 백업·실패 시 복원 대상).
2. ADMIN이 대시보드 `메뉴 → 캐릭터 자료 (관리자)`에서 자료 묶음 ZIP을 올린다(`POST /api/dashboard/agent-media/package`). 저장소·S3를 거치지 않는다.
3. 승인 상태는 묶음 안의 manifest 그대로 쓰며, 알 수 없는 값은 `CANDIDATE`로 낮춘다.

### 홈페이지(로그인 전) 공개

홈 첫 화면(`public/landing.html`, `f2r_home_agent.js`)도 같은 캐릭터 무대·홀로그램 버튼·대화창을 쓴다. 로그인 전에는 "안내 모드"로 공개 서비스만 안내한다. 캐릭터 영상은 로그인한 ADMIN·TUTOR에게만 비공개 경로로 보이고, 로그인 전 공개는 `APP_AGENT_MEDIA_PUBLIC_AGENTS`(예: `suni`)에 적은 캐릭터만이다(기본 비어 있음 → 표식).
