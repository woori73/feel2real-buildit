# 내신 시험지 제작원칙

> 적용 대상: 압구정에듀홀릭 내신 wiki에서 제작하는 중·고등학교 내신 예상문제 HTML 및 인쇄용 시험지
> 목적: 실제 학교 시험지에 가까운 가독성, A4 인쇄 안정성, 화면/인쇄 일치성 확보

## 1. 문제 표기
1. 문제 번호 옆에 점수를 쓰지 않는다.
2. 문제 번호 다음에 바로 발문을 쓴다.
   - 권장: `1. 다음 빈칸에 들어갈 말로 가장 적절한 것은?`
   - 금지: `1. [3점]` 후 다음 줄에 발문
3. 시험지 본문에 제작 과정, Digital Twin 활용 설명, 출제 근거 등의 유의사항을 노출하지 않는다.
4. 제작자 표기는 `압구정에듀홀릭 내신 wiki`로 통일한다.

## 2. 선택지
1. 짧은 단어형 선택지는 한 줄 가로 배열을 우선한다.
2. 선택지 사이에는 충분한 간격을 둔다.
3. 긴 문장형 선택지는 억지로 한 줄에 넣지 않고 세로 배열한다.
4. 화면과 인쇄에서 선택지 배열이 불필요하게 달라지지 않게 한다.
5. 선택지 번호와 내용은 하나의 atomic unit으로 취급한다. `⑤ ordinary`처럼 번호와 내용이 서로 다른 줄로 분리되어서는 안 된다.
6. 가로 공간이 부족하면 선택지 전체를 다음 줄로 이동한다. 구현 시 각 선택지에 `inline-block` + `white-space: nowrap`에 준하는 wrapping 보호를 적용한다.
7. 학교별 실제 기출에서 별도 근거가 없는 한 선택형은 ①~⑤의 5지선다를 기본으로 한다. 임의로 4지선다로 축소하지 않는다.

## 3. A4 페이지 우선 조판
1. CSS 자동 다단(`column-count`)만으로 시험지를 조판하지 않는다.
2. 문항 수를 기준으로 `1~10 / 11~20`처럼 강제로 좌우 분할하지 않는다.
3. 먼저 210×297mm A4 페이지를 만든다.
4. 각 A4 안에 왼쪽 단과 오른쪽 단을 별도로 둔다.
5. 흐름은 `왼쪽 단 → 오른쪽 단 → 다음 A4 왼쪽 단` 순서로 한다.
6. 각 문항의 실제 렌더링 높이를 측정해 남은 공간에 들어가는지 판단한다.
7. 문항 전체가 현재 단에 들어가지 않으면 문항 전체를 다음 단으로 이동한다.
8. 발문·지문·선택지가 서로 다른 단으로 찢어지지 않게 한다.

## 4. 섹션 전환
1. 선택형이 끝났다고 무조건 새 페이지를 만들지 않는다.
2. 현재 단에 공간이 있으면 서답형을 이어서 배치한다.
3. 섹션 제목만 페이지/단 마지막에 고립시키지 않는다.
4. 섹션 제목은 최소한 첫 문항과 함께 들어갈 수 있을 때만 출력한다.
5. 실제 문항이 하나도 없는 마지막 A4 페이지는 반드시 제거한다.
6. 마지막 페이지에 `선택형 (20문항)`, `서답형 (10문항)` 같은 제목만 남는 현상을 최종 검수에서 차단한다.

## 5. 화면과 인쇄
1. 화면에서도 A4 종이 크기와 실제 2단 구조를 미리 보여준다.
2. 인쇄에서도 동일한 페이지 DOM 구조를 사용한다.
3. 화면 전용 자동 다단과 인쇄 전용 별도 다단처럼 서로 다른 핵심 조판 방식을 사용하지 않는다.
4. `@page { size: A4 portrait; }`를 명시한다.
5. 인쇄 직전 빈 페이지와 고립된 제목을 다시 검사·제거한다.

## 6. 가독성
1. 페이지 수를 줄이려고 글씨를 과도하게 축소하지 않는다.
2. 학교 시험지 수준인 약 9~10pt를 기본 범위로 삼는다.
3. 발문은 본문보다 명확하게 구분한다.
4. 영어 지문은 충분한 행간을 확보한다.
5. 지문 박스는 얇은 선·적절한 여백 정도로 단정하게 처리한다.
6. 웹 카드식 그림자, 과도한 색상, 둥근 장식은 인쇄 시험지에서 지양한다.

## 7. 서답형
1. 실제 답안을 쓸 수 있는 공간을 확보한다.
2. 영작·서술형은 예상 답안 길이에 따라 작성 공간을 다르게 배정한다.
3. 문제지에는 정답·해설·출제 근거를 노출하지 않는다.
4. 정답·해설지는 문제지와 분리한다.

## 8. 문항 DOM·형식 계약
1. 발문과 지문/대화/보기 자료를 DOM에서 분리한다.
2. 권장 구조는 `qblock → qhead(qnum + qprompt) → passage/dialogue → choices`이다.
3. `qprompt`에는 발문만 넣고 본문이나 대화 전체를 넣지 않는다. 특히 대화 순서 배열 문제도 대화는 별도의 `passage dialogue`로 출력한다.
4. 발문에 `밑줄 친`이 있으면 실제 판단 대상에 `<u>` 또는 동등한 밑줄 DOM이 반드시 존재해야 한다.
5. `다음 밑줄 친 부분 중 어법상 옳지 않은 것은?` 유형은 원칙적으로 ①~⑤의 판단 대상 5개를 갖는다.
6. 어법 문항의 지문 내 ①~⑤와 별도 선택지의 ①~⑤는 정확히 대응해야 하며, 오답은 정확히 하나여야 한다.
7. `(A)~(D)`를 요구하는 발문이면 실제 passage/dialogue에도 (A), (B), (C), (D)가 모두 존재해야 한다.
8. 선택지 추가·삭제·순서 변경, 지문 변경, 밑줄 대상 변경, 정답 조건에 영향을 주는 발문 변경이 있으면 기존 정답을 재사용하지 않는다.
9. 변경된 문항은 독립적으로 다시 풀어 `createdAnswer`와 `verifiedAnswer`를 비교하고 일치할 때만 VERIFIED 처리한다.
10. 문제지와 정답·해설지는 문항 번호, 선택지 번호, 정답이 서로 정확히 동기화되어야 한다.

## 9. 최종 Contract Validation
최종 시험지로 확정하기 전에 전체 문항을 기계적으로 검사할 수 있는 항목은 자동 검증하고, 하나라도 실패하면 최종본으로 확정하지 않는다.

- [ ] 선택형 ①~⑤ 누락 0건 (학교별 실제 기출 근거로 다른 형식을 의도한 경우 제외)
- [ ] 선택지 번호와 선택지 내용 분리 0건
- [ ] `밑줄 친` 발문인데 실제 밑줄 DOM 없음 0건
- [ ] 어법 문항의 판단 대상 개수 오류 0건
- [ ] 어법 문항의 지문 ①~⑤ ↔ 선택지 ①~⑤ 대응 오류 0건
- [ ] `(A)~(D)` 발문 ↔ passage/dialogue 표기 불일치 0건
- [ ] `qprompt` 내부 passage/dialogue 혼입 0건
- [ ] 객관식 복수정답 또는 정답 없음 0건
- [ ] 문제지 ↔ 정답·해설 문항/정답 불일치 0건
- [ ] A4 overflow 0건
- [ ] 문항 중간 split 0건

## 10. 최종 인쇄 검수 체크리스트
- [ ] 문제 번호 옆 점수 없음
- [ ] 번호 바로 뒤에 발문
- [ ] 불필요한 유의사항 없음
- [ ] 짧은 단어 선택지 가로 정렬
- [ ] 선택지 번호와 내용이 분리되지 않음
- [ ] 긴 선택지는 가독성 우선
- [ ] 객관식 선택지 수가 학교 시험 형식과 일치하며 기본 5지선다 원칙 준수
- [ ] 발문/지문/대화 DOM 분리 정상
- [ ] 밑줄·①~⑤·(A)~(D) 표기 계약 정상
- [ ] A4 페이지 크기 고정
- [ ] 좌 → 우 → 다음 페이지 순서 정상
- [ ] 문항이 단 사이에서 분리되지 않음
- [ ] 섹션 제목만 단 끝에 고립되지 않음
- [ ] 빈 마지막 페이지 없음
- [ ] 마지막 페이지에 불필요한 선택형/서답형 제목 없음
- [ ] 화면 미리보기와 인쇄 미리보기의 문항 순서/단 구성이 동일
- [ ] 서답형 답안 공간 충분
- [ ] 제작자 `압구정에듀홀릭 내신 wiki`
- [ ] 실제 A4 인쇄 미리보기 최종 확인

## 11. 구현 우선순위
`내용 정확성 → 문항 단위 보존 → A4 페이지 안정성 → 가독성 → 페이지 수`

페이지 수를 줄이는 것보다 문항이 깨지지 않고 실제 학교 시험지처럼 읽히는 것을 우선한다.
