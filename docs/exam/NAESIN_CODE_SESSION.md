# 내신·수능 작업을 Claude 코드 세션에서 하기 (사용법 한 장)

> 2026-11-22. claude.ai 프로젝트에서 하던 내신·수능 작업을 코드 세션으로 옮겼다. 이 문서는 감독(원장)과 에이전트가 함께 보는 사용법이다.

## 한 줄로 시키기

| 이렇게 말하면 | 쓰는 스킬 | 하는 일 |
|---|---|---|
| "신구중 2학년 기말 40문항" · "압구정중3 70문항 5회" · "○○중 3회 검수" · "적중률 보고서" | `naesin-exam` | 내신위키에서 기출·필기본 조회 → 설계표 → 출제 → 독립 정답 검증 → 검수 스크립트 → A4 문제지·정답해설 |
| "신구중2 12회 내신 실전 연습에 올려" · "예비고1 모의고사 23회 추가" | `naesin-upload` | 문항 그림·마이그레이션·문서 → 로컬 확인 → PR |
| "10월 모의고사 29번 분석지" · "고1 모의고사 수능 논리로 변형" | `csat-analysis` | 분석지(IDML) · 변형문제와 풀이 전략 해설 · 수능 약점 |
| "SAT 세트 추가" · "iBT 화면 고쳐" | `testprep-update` | TestPrep(iBT·SAT) 개선·업데이트 |

빠진 값(연도·학기·회차·문항 수)은 스킬이 기본값으로 채우고 첫 줄에 밝힌다.

## 자동으로 하는 것과 감독이 하는 것

자동: 자료 조회, 설계표, 출제, 독립 정답 검증, 검수 스크립트, 시험지 조립, 로컬 확인, PR 작성.

감독 확인이 필요한 것:
- 1회 결과 승인(그 뒤에 나머지 회차 제작)
- 내신위키 저장·등록(`save_*`, `register_weekly_exam_draft`), 자료 삭제
- 홈페이지에 올리는 PR의 운영 배포(수동 GitHub Actions)
- 로그인(비밀번호는 에이전트가 넣지 않는다), 돈이 드는 일

## 검수 스크립트가 보는 것

`exam_check.py` — 통과 못 하면 시험지를 만들지 않는다.

| 구역 | 기준 |
|---|---|
| 문항 수 | 주문한 수와 같은가 |
| 배점 | 모두 양수, 합계 = 만점 |
| 정답 번호 | 한 번호가 30% 초과·10% 미만이 아닌가(20문항 이상일 때), 같은 번호 3번 연속이 없는가 |
| 지문 중복 | 같은(또는 90% 이상 같은) 지문에 같은 발문이 없는가 |
| 양식 | 저장 계약 필드, 선택지 5개·중복·빈 칸, 정답 범위, 발문 앞 점수 표기 금지, 서답형 정답 |

정답이 맞는지는 스크립트가 아니라 독립 재풀이로 확인한다.

## 문제지 편집(승인본과 같은 모양)

`exam_build.py`의 문제지는 `exam_paper.py`가 만든다. 기준은 감독이 승인한 신구중2 11회 문제지(`src/main/resources/static/naesin/singu-m2-2026-2/r11/`의 문항 그림)다.

| 항목 | 모양 |
|---|---|
| 글꼴·단 | 명조(PC의 Noto Serif KR → 바탕), 본문 10pt, A4 세로 2단, 왼쪽 단 → 오른쪽 단 → 다음 쪽 |
| 1쪽 머리 표 | 왼쪽 위 F2R 로고(학교 이름 자리) + 제목 / 과목·학년·범위 / 이름·점수 칸. 2쪽부터 위쪽 줄 머리말, 쪽 아래 `제작 : 압구정에듀홀릭 내신 wiki | 쪽 / 전체` |
| 발문 | `번호. 발문 (2점)`, 복수정답 `(정답 2개/4점)`. 않은·않는·없는·아닌·어색한·틀린·잘못된·모두에 굵은 밑줄 |
| 공통 지문 | `[12~14] 다음 글을 읽고 물음에 답하시오.`(대화는 `다음 대화를`) + 테두리 상자(제목은 가운데 굵게, `*낱말: 뜻` 각주는 상자 아래) + 묶음 문항 |
| 예문 | 발문 아래 테두리 상자(◦ 낱문장, `G:`·`B:` 대화, 한 문장). `<보 기>` 줄이 있으면 상자 위 테두리에 제목 |
| 선택지 | 짧은 낱말은 한 줄에 3개씩 가로, 문장은 세로(⇒ 줄은 들여 씀, `A:`·`B:`는 굵게), `(선택지 표: ⓐ \| ⓑ \| ⓒ)`가 있으면 밑줄 친 머리 ⓐ ⓑ ⓒ 아래 ①~⑤ 표 |
| 그림 | `[[img:…]]` 줄. 그림만 있으면 테두리 상자 안, `<보 기>` 상자가 따라오면 그림 그대로 |

단은 문제지 HTML 안의 스크립트가 브라우저에서 조각의 실제 높이를 재어 나눈다. 문항과 지문 상자는 단 사이에서 갈라지지 않고, 공통 지문은 첫 문항과 같은 쪽에 놓인다(왼쪽 단 아래에 지문, 오른쪽 단 위에 첫 문항은 허용). 공통 지문 묶음(머리말+지문+문항들)은 한 쪽에 다 들어갈 수 있으면 쪽 경계 앞에서 다음 쪽으로 넘겨 한 쪽 안에 두고(쪽수가 늘 수 있다), 한 쪽에 다 못 들어가는 긴 묶음만 쪽을 넘겨 나눈다. 빈칸 `(   )`·`( ⓐ )`은 줄 끝에서 괄호가 갈라지지 않고, 한 줄에 이어 쓴 각주(`*ban: 금지하다 **seek: 추구하다`)는 사이를 띄워 찍는다. 내신위키에 저장하는 판에는 `<i>`를 넣지 않는다(위키 화면은 `<u>`만 그린다) — 조립용 판에서 `<i>`만 뺀 판을 따로 둔다. 완성한 문제지는 크롬으로 PDF·쪽별 그림을 떠서 승인본 그림과 나란히 놓고 본다(잘림·빈 쪽·고립된 머리말·밑줄·원문자). 책·작품 제목의 기울임은 문항 데이터(지문·발문·선택지·해설)에 `<i>Fahrenheit 451</i>`처럼 `<i>`로 표시한다(문제지와 정답·해설지가 `<u>`·`<i>`만 태그로 살리고 `<보 기>` 같은 그 밖의 꺾쇠 글은 글자로 찍는다). 학교마다 다른 발문 글꼴(압구정중1은 발문이 고딕)은 아직 구분하지 않는다.

## 스크립트를 고쳤을 때

`scripts/naesin/`의 `exam_check.py`·`exam_build.py`·`exam_paper.py`와 `weekly_paper.py`를 고치면 스킬 폴더 `~/.claude/skills/naesin-exam/bin/`의 복사본도 같이 바꾼다. 스킬 폴더에는 로고 `F2R_logo_pure.svg`(`src/main/resources/static/img/`)도 스크립트 옆에 둔다(로고를 못 찾으면 문제지를 만들지 않는다).
