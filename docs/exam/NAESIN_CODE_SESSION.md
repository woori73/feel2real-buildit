# 내신·수능 작업을 Claude 코드 세션에서 하기 (사용법 한 장)

> 2026-11-22. claude.ai 프로젝트에서 하던 내신·수능 작업을 코드 세션으로 옮겼다. 이 문서는 감독(원장)과 에이전트가 함께 보는 사용법이다.

## 한 줄로 시키기

| 이렇게 말하면 | 쓰는 스킬 | 하는 일 |
|---|---|---|
| "신구중 2학년 기말 40문항" · "압구정중3 70문항 5회" · "○○중 3회 검수" · "적중률 보고서" | `naesin-exam` | 내신위키에서 기출·필기본 조회 → 설계표 → 출제 → 독립 정답 검증 → 검수 스크립트 → A4 문제지·정답해설 |
| "신구중2 12회 내신 실전 연습에 올려" · "예비고1 모의고사 23회 추가" | `naesin-upload` | 문항 그림·마이그레이션·문서 → 로컬 확인 → PR |
| "10월 모의고사 29번 분석지" · "고1 모의고사 수능 논리로 변형" | `csat-analysis` | 분석지(IDML) · 변형문제와 풀이 전략 해설 · 수능 약점 |
| "SAT 세트 추가" · "iBT 화면 고쳐" | `testprep-update` | TestPrep(iBT·SAT) 개선·업데이트 |

빠진 값(연도·학기·회차·문항 수)은 스킬이 기본값으로 채우고 첫 줄에 밝힌다.

## 어디에 무엇이 있나

| 무엇 | 어디 | Git |
|---|---|---|
| 스킬 4개 | 감독 PC `~/.claude/skills/` (저장소 `.claude/`는 Git 제외라 PC에 둔다) | 올리지 않음 |
| 검수·조립 스크립트와 테스트 | `scripts/naesin/exam_check.py`, `exam_build.py`, `test_exam_*.py` | 올림 |
| 조판·제작 원칙 | [내신_시험지_제작원칙.md](내신_시험지_제작원칙.md), [WIKI_TUTOR_BROWSER_CONTEXT.md](WIKI_TUTOR_BROWSER_CONTEXT.md) | 올림 |
| 기출·필기본·기존 문항 | 내신위키(MCP `get_final_context`) | — |
| 프로젝트에서 옮긴 자료·학교별 작업물·기출 참고 자료 | 감독 PC `Documents\naesin-workspace\` (`_claude-projects`, `_reference`, `<학교>\<학년>\<시험>`) | **올리지 않음** |

이 저장소는 공개 저장소다. 학교 시험지 원본, 학생 이름·필기·성적, 공식 시험(SAT·TOEFL·TOEIC·학력평가) 원문은 커밋하지 않는다.

## 자동으로 하는 것과 감독이 하는 것

자동: 자료 조회, 설계표, 출제, 독립 정답 검증, 검수 스크립트, 시험지 조립, 로컬 확인, PR 작성.

감독 확인이 필요한 것:
- 1회 결과 승인(그 뒤에 나머지 회차 제작)
- 내신위키 저장·등록(`save_*`, `register_weekly_exam_draft`), 자료 삭제
- 홈페이지에 올리는 PR의 운영 배포(수동 GitHub Actions)
- 로그인(비밀번호는 에이전트가 넣지 않는다), 돈이 드는 일

## 검수 스크립트가 보는 것

`exam_check.py` — 통과 못 하면 시험지를 만들지 않는다.

| 구역 | 기준 |
|---|---|
| 문항 수 | 주문한 수와 같은가 |
| 배점 | 모두 양수, 합계 = 만점 |
| 정답 번호 | 한 번호가 30% 초과·10% 미만이 아닌가(20문항 이상일 때), 같은 번호 3번 연속이 없는가 |
| 지문 중복 | 같은(또는 90% 이상 같은) 지문에 같은 발문이 없는가 |
| 양식 | 저장 계약 필드, 선택지 5개·중복·빈 칸, 정답 범위, 발문 앞 점수 표기 금지, 서답형 정답 |

A4 조판(잘림·빈 쪽·밑줄·〈보기〉)은 기존 `weekly_validate.py`와 브라우저 인쇄 미리보기로 확인한다. 정답이 맞는지는 스크립트가 아니라 독립 재풀이로 확인한다.

## 스크립트를 고쳤을 때

`scripts/naesin/`의 `exam_check.py`·`exam_build.py`와 `weekly_paper.py`를 고치면 스킬 폴더 `~/.claude/skills/naesin-exam/bin/`의 복사본도 같이 바꾼다.
